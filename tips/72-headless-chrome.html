How To Run Your Tests Headlessly with Chrome

Intro​

This is a guest post from Chris Kenst.

When we run our tests on a Continuous Integration (CI) server, there is usually no display for the browser to open a window in. We need the browser to run without one.

A Solution​

Run Chrome headless. Headless Chrome is the same Chrome, with the same rendering engine, but without a window. We turn it on with the --headless argument, and nothing else changes: the tests load pages, click, type and take screenshots as usual.

Since Chrome 132, --headless runs the full Chrome browser. The older headless mode is now a separate program, chrome-headless-shell, which starts faster but is not exactly Chrome (Playwright uses it by default).

A headless Chrome tells websites what it is: its user agent says HeadlessChrome instead of Chrome. The examples check it to show that the browser runs headless.

Expected Behavior​

  • Chrome starts without a window
  • The test loads the page and checks the title
  • The test prints the user agent, which says HeadlessChrome
  • Chrome closes

Summary​

Headless Chrome is the simplest way to run browser tests on a machine without a display: it needs no extra tools, it comes with Chrome, and it renders pages like the Chrome our users have. To see what the browser does while you write or debug a test, remove the --headless argument.

Happy Testing!
