How to Test Two Users at Once

A chat, a shared document or a multiplayer game only works when one user sees what another user does. One test can start two browsers, one for each user, and check that a message sent by one user reaches the other.

How to Print a Page to PDF

Invoices, tickets and reports are often printed or saved as PDF. The test can print the page to a PDF, without the print dialog, to check the printed version or to keep it as a record of the run.

How to Check Screenshots with Sauce Labs Visual

Comparing screenshots in the test code means keeping baselines for every browser and operating system, and reviewing the differences by hand. Sauce Labs Visual stores the baselines, compares the snapshots, and shows the changes for review.

How to Compare Screenshots of an Element

A button that moves a few pixels, a wrong color, or a missing logo pass every functional check. A test that compares screenshots of an element, pixel by pixel, notices them.

How To Run Your Tests Headlessly with Chrome

A Continuous Integration (CI) server usually has no display for the browser to open a window in. Chrome can run headless (without a window), so the tests run there with no extra tools.

How to Reuse a Login Across Tests

Logging in through the form at the start of every test makes the suite slow, and every test fails when the login page has a problem. The test suite can log in once, keep the session cookie, and start each test already logged in.
