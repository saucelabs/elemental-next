## Code Walkthrough

### The Tests

Both tests visit the page first (lines 3 to 5) and click the button that opens a JavaScript confirmation. We find the
button by its role and name (`getByRole`).

Playwright dismisses dialogs on its own unless we handle them. So before clicking, we listen for the `dialog` event
once (`page.once`):

- Lines 7 to 12 accept the confirmation, and the page says `You clicked: Ok`.
- Lines 14 to 19 dismiss it, and the page says `You clicked: Cancel`.

The listener has to be there before the click, because the dialog opens during the click.
