## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox, loads the page, and clicks the second button (`buttons[1]`, since the list
starts at `0`). The `afterEach` hook quits the browser.

### The Tests

Both tests wait for the alert to be present with `driver.wait(until.alertIsPresent(), 5000)`, which returns the
alert. Then the first test accepts it (`popup.accept()`) and the second one dismisses it (`popup.dismiss()`).
Finally, they assert the result displayed on the page.
