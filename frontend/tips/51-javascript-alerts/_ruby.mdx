## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox, loads the page, and clicks the second button (`find_elements(...)[1]`, since the
list starts at `0`). The `teardown` method quits the browser. The `run` method wraps each test with them.

### The Tests

`alert` waits for the alert to be present: it keeps trying to switch to it (`@driver.switch_to.alert`) until it
shows up, and returns it. Then the first test accepts it (`accept`) and the second one dismisses it (`dismiss`).
Finally, they assert the result displayed on the page.
