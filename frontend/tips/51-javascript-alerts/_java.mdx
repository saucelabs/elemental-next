## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox, loads the page, and clicks the second button (`findElements(...).get(1)`,
since the list starts at `0`). The `afterEach` method quits the browser.

### The Tests

`alert()` waits for the alert to be present with `ExpectedConditions.alertIsPresent()`, which switches to it and
returns it. Then `acceptConfirmation` accepts it (`accept()`) and `dismissConfirmation` dismisses it (`dismiss()`).
Finally, they assert the result displayed on the page.
