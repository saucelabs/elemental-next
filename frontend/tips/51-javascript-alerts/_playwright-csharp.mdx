## Code Walkthrough

### The Tests

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Both tests visit
the page first (the `[TestInitialize]` method on lines 11 to 15) and click the button that opens a JavaScript
confirmation. We find the button by its role and name (`GetByRole`).

Playwright dismisses dialogs on its own unless we handle them. So before clicking, we add a handler to the
`Page.Dialog` event:

- Lines 17 to 24 accept the confirmation, and the page says `You clicked: Ok`.
- Lines 26 to 33 dismiss it, and the page says `You clicked: Cancel`.

The handler has to be there before the click, because the dialog opens during the click.
