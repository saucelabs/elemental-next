## Code Walkthrough

### Setup

The `beforeEach` hook (lines 4 to 6) visits the page with the alerts before each test.

### The Tests

Each test clicks the button that opens a JavaScript confirmation. We find the button by its text with WebdriverIO's
`tag=text` selector (`button=Click for JS Confirm`).

The confirmation blocks the page until someone answers it, so we tell WebdriverIO what to do before we click. With a
WebDriver BiDi session (the default in WebdriverIO 10), the browser sends a `dialog` event when a dialog opens.
`browser.once('dialog')` handles the next one: the first test (lines 8 to 13) accepts it and the second test (lines 15
to 20) dismisses it.

Then we check the result on the page: `You clicked: Ok` or `You clicked: Cancel`.
