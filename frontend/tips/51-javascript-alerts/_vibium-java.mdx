## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in Vibium's classes to drive the browser, and JUnit to run the tests.

### Setup and Teardown

The `beforeEach` method (lines 17 to 22) starts the browser, gets its first page (tab), and visits the page with the
alerts. The `afterEach` method (lines 24 to 29) closes the browser.

### The Tests

The "Click for JS Confirm" button opens a confirmation with OK and Cancel buttons. We find the button by its role and
text (`new SelectorOptions().role("button").text(...)`), one of Vibium's semantic locators.

Vibium lets us know when the page opens a dialog with `page.onDialog`. We set the handler before clicking.

- Lines 31 to 37 accept the confirmation (OK) and check that the page says `You clicked: Ok`.
- Lines 39 to 45 dismiss it (Cancel) and check that the page says `You clicked: Cancel`.
