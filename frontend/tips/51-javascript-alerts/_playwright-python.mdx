## Code Walkthrough

### The Tests

Both tests visit the page first (the fixture on lines 5 to 7) and click the button that opens a JavaScript
confirmation. We find the button by its role and name (`get_by_role`).

Playwright dismisses dialogs on its own unless we handle them. So before clicking, we listen for the `dialog` event
once (`page.once`):

- Lines 10 to 14 accept the confirmation, and the page says `You clicked: Ok`.
- Lines 17 to 21 dismiss it, and the page says `You clicked: Cancel`.

The listener has to be there before the click, because the dialog opens during the click.
