## Code Walkthrough

### Setup and Teardown

The `driver` fixture launches Firefox, loads the page, and clicks the second button (`find_elements(...)[1]`, since
the list starts at `0`) before `yield`ing the driver to the test. Once the test is done, it quits the browser.

### The Tests

Both tests wait for the alert to be present with `WebDriverWait(driver, 5).until(EC.alert_is_present())`, which
returns the alert. Then the first test accepts it (`popup.accept()`) and the second one dismisses it
(`popup.dismiss()`). Finally, they assert the result displayed on the page.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
