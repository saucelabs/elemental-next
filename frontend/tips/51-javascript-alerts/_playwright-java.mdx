## Code Walkthrough

### The Tests

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Both tests visit the page first (the
`@BeforeEach` method on lines 14 to 17) and click the button that opens a JavaScript confirmation. We find the button by
its role and name (`getByRole`).

Playwright dismisses dialogs on its own unless we handle them. So before clicking, we add a handler with `onDialog`:

- Lines 20 to 25 accept the confirmation, and the page says `You clicked: Ok`.
- Lines 28 to 33 dismiss it, and the page says `You clicked: Cancel`.

The handler has to be there before the click, because the dialog opens during the click.
