## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) launches Firefox, loads the page, and clicks the second button
(`FindElements(...)[1]`, since the list starts at `0`). The `TearDown()` method (marked with `[TestCleanup]`) closes
the browser.

### The Tests

`Alert()` waits for the alert to be present: it keeps trying to switch to it (`d.SwitchTo().Alert()`), ignoring the
`NoAlertPresentException` thrown until it shows up, and returns it. Then `AcceptConfirmation` accepts it (`Accept()`)
and `DismissConfirmation` dismisses it (`Dismiss()`). Finally, they assert the result displayed on the page.
