## Code Walkthrough

### Importing Libraries

Lines 3 to 19 pull in Selenide, the Sauce Labs Visual client (`VisualApi`, `CheckOptions`, `DataCenter` and
`DiffStatus`), JUnit and Selenium. Line 22 is the address of Sauce Labs in the US West data center.

### Setup and Teardown

The `setUp` method (lines 26 to 48) skips the test when the Sauce Labs credentials are not set. Otherwise, it tells
Selenide to start the latest Chrome on Windows 11 on Sauce Labs (`Configuration.remote` and `browserCapabilities`),
and opens the page, which starts the browser. Then it creates the Visual client for Selenide's driver
(`getWebDriver()`, a `RemoteWebDriver`) with `VisualApi.Builder`, in the same data center, and a Visual build, which
groups the snapshots of the test run. The `tearDown` method (lines 50 to 53) closes the browser.

### The Test

Lines 55 to 66 are the test itself. `sauceVisualCheck` takes a snapshot named "Newsletter card" from the Sauce Labs
session. `setClipSelector` keeps only the card.

`sauceVisualResults` waits for Sauce Labs to compare the snapshots, and returns the number of snapshots in each status.
The test prints the link to the build and checks that no comparison had an error (statuses without snapshots are not
in the map, so it uses `getOrDefault`). The client finishes the build when the tests end.
