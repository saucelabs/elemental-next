## Code Walkthrough

### Importing Libraries

Line 1 pulls in the WebdriverIO globals (`browser`, `$` and `expect`).

### The Test

Lines 4 to 16 are the test itself.

When we right click the box on the page, it opens a JavaScript alert. The alert blocks the page until someone answers
it, so we get ready for it before the click. Lines 7 to 12 create a promise that waits for the next `dialog` event
(sent by the browser in a WebDriver BiDi session, the default in WebdriverIO 10). When the alert opens, we keep its
text and accept it.

Line 13 right clicks the box: `click` takes a `button` option, and `'right'` opens the context menu.

Finally, we wait for the promise and check the text of the alert.
