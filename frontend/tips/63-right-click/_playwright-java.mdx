## Code Walkthrough

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 16 to 28 are the test. Right
clicking the box on the page opens a JavaScript alert with a message.

The alert blocks the page until someone closes it, and the click doesn't end until then. So before the click, we add a
handler with `onDialog` (lines 21 to 24): it saves the message and accepts the alert. Then we right click with
`MouseButton.RIGHT` and check the message.
