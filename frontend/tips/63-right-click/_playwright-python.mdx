## Code Walkthrough

### The Test

Lines 4 to 16 are the test. Right clicking the box on the page opens a JavaScript alert with a message.

The alert blocks the page until someone closes it, and the click doesn't end until then. So before the click, we
listen for the `dialog` event once (lines 9 to 13): the listener saves the message and accepts the alert. Then we
right click with `click(button='right')` and check the message.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
