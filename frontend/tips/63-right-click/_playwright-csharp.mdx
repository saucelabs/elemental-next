## Code Walkthrough

### The Test

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 12 to 26 are
the test. Right clicking the box on the page opens a JavaScript alert with a message.

The alert blocks the page until someone closes it, and the click doesn't end until then. So before the click, we add a
handler to the `Page.Dialog` event (lines 17 to 22): it saves the message and accepts the alert. Then we right click
with `MouseButton.Right` and check the message.

### Executing the Test
