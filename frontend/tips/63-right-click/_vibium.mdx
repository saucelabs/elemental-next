## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Test

Lines 17 to 30 are the test itself.

The page has a box that opens a JavaScript alert when we right click on it. Vibium can't right click yet, so we fire
the `contextmenu` event (the event a right click sends) on the box with `dispatchEvent`. The page handles it the same
way.

Before that, lines 20 to 25 set a handler with `page.onDialog`. When the alert opens, the handler keeps its message
and accepts it. Then we check the message.
