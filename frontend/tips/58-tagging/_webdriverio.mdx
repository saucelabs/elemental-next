## Code Walkthrough

### Tagging the Tests

WebdriverIO runs the tests with Mocha, which has no tags of its own. A simple way to tag a test is to add the tag to
its name, like `@smoke` (line 4) or `@wip` (line 10).

The `@wip` test is not finished yet, so it fails. We don't want it to run with the rest.

### Running the Tagged Tests

Mocha's `grep` option runs only the tests whose name matches. WebdriverIO lets us pass Mocha options from the command
line, so the `test` script in `package.json` runs `wdio run ./wdio.conf.ts --mochaOpts.grep @smoke`. Only the
`@smoke` test runs, and the `@wip` test is left out.

To run a different group of tests, change the tag (e.g., `--mochaOpts.grep @wip`). To run every test except a tag,
add `--mochaOpts.invert`.
