## Code Walkthrough

### Tagging

In JUnit, we apply tags with the `@Tag` annotation (e.g., `@Tag("smoke")`).

### Filtering

Maven Surefire runs only the tests with the tags we give it in `groups` (and skips the ones in `excludedGroups`). We
set `<groups>smoke</groups>` in the `pom.xml`, so `mvn test` runs only the smoke tests. You can also choose the tags
from the command-line (e.g., `mvn test -Dgroups=wip`, or a tag expression like `-Dgroups="!wip"`).
