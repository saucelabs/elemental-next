## Code Walkthrough

### Tagging the Tests

MSTest tags tests with categories: we add them as attributes (`[TestCategory("smoke")]`). A test can have more than
one category. The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property.

- Lines 11 to 17 are a quick test in the `smoke` category.
- Lines 19 to 26 are a test that is not finished yet, so it fails. It is in the `wip` category.

### Running Only Some Tests

`dotnet test --filter TestCategory=smoke` runs only the tests of a category. To not type it every time, we put the
filter in a run settings file, and the project file points to it (`RunSettingsFilePath`). So `dotnet test` runs only
the first test. `--filter TestCategory!=wip` would run every test except the unfinished one.
