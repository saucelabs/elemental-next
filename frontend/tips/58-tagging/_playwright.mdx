## Code Walkthrough

### Tagging the Tests

Playwright Test has tags: we add them in the details of a test (`{tag: '@smoke'}`). A test can have more than one
tag (`{tag: ['@smoke', '@login']}`).

- Lines 3 to 6 are a quick test that we tag as `@smoke`.
- Lines 9 to 12 are a test that is not finished yet, so it fails. We tag it as `@wip`.

### Running Only Some Tests

`--grep` runs only the tests that match, and it looks at the tags too. The `test` script in `package.json` runs
`playwright test --grep @smoke`, so only the first test runs. `--grep-invert @wip` would run every test except the
unfinished one.
