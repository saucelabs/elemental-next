## Code Walkthrough

### Tagging

In MSTest, tags are called categories. We apply them with the `[TestCategory]` attribute (e.g.,
`[TestCategory("smoke")]`).

### Filtering

`dotnet test` filters tests with `--filter` (e.g., `--filter TestCategory=smoke`, or `--filter TestCategory!=wip`).
To run only the smoke tests by default, we set the filter in `smoke.runsettings` (`TestCaseFilter`), and the project
file points to it with `RunSettingsFilePath`.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`csharp.csproj` in this case).
