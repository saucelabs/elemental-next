### The Tests

We tag each test by adding a word to its name: `@smoke` for the test on line 17, and `@wip` for the test on line 23,
which is not finished yet and fails.

Mocha's `--grep` option runs only the tests whose name matches. The `test` script in `package.json` uses
`--grep @smoke`, so only the first test runs. To run every test except the `@wip` ones, use `--grep @wip --invert`.
