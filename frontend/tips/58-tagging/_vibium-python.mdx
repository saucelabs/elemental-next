### The Tests

We tag each test with a pytest marker: `smoke` for the test on lines 12 to 15, and `wip` for the test on lines 18 to
22, which is not finished yet and fails.

pytest's `-m` option runs only the tests with a marker. `pytest.ini` declares the markers and sets `-m smoke`, so only
the first test runs. To run every test except the `wip` ones, use `-m "not wip"`.
