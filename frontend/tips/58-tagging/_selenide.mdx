## Code Walkthrough

### Tagging the Tests

JUnit's `@Tag` annotation puts a test in a group. Lines 11 to 16 tag a test that checks the title of the page as
`smoke`. Lines 19 to 24 tag a test that is not finished yet (it fails) as `wip`.

### Running Only Some Tests

Line 41 of the `pom.xml` tells Maven Surefire to run only the tests tagged as `smoke`, so `mvn test` doesn't run the
`wip` test.

To run another group without changing the `pom.xml`, pass it on the command-line, e.g., `mvn test -Dgroups=wip`. To
leave a group out, use `excludedGroups` (e.g., `-DexcludedGroups=wip`).
