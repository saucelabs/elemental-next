## Code Walkthrough

### Tagging the Tests

pytest tags tests with marks: we add them as decorators (`@pytest.mark.smoke`). A test can have more than one mark.

- Lines 5 to 8 are a quick test that we mark as `smoke`.
- Lines 12 to 15 are a test that is not finished yet, so it fails. We mark it as `wip`.

### Running Only Some Tests

`-m` runs only the tests with a mark. In `pytest.ini`, we declare the marks (pytest warns about unknown ones), and
`addopts = -m smoke` runs only the first test. `-m "not wip"` would run every test except the unfinished one.
