## Code Walkthrough

### Tagging the Tests

JUnit tags tests with `@Tag("smoke")`. A test can have more than one tag. `@UsePlaywright` gives each test a fresh
browser tab in its `Page` parameter.

- Lines 13 to 18 are a quick test tagged as `smoke`.
- Lines 20 to 26 are a test that is not finished yet, so it fails. It is tagged as `wip`.

### Running Only Some Tests

`mvn test -Dgroups=smoke` runs only the tests with a tag. To not type it every time, we set `groups` in the
configuration of Maven Surefire (the plugin that runs the tests) in the `pom.xml` file. So `mvn test` runs only the
first test. `-DexcludedGroups=wip` would run every test except the unfinished one.
