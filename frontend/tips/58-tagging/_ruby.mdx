## Code Walkthrough

### Tagging

In RSpec, tags are metadata on a spec (or a group of specs). The simplest form is a symbol after the description
(e.g., `it 'has the right title', :smoke do`). Tags can also be key/value pairs (e.g., `speed: 'slow'`).

### Filtering

`--tag` runs only the specs with that tag (e.g., `--tag smoke`), and a `~` in front of the tag name ignores them
instead (e.g., `--tag ~wip`). We put `--tag smoke` in the `.rspec` file, which RSpec reads on every run, so
`bundle exec rspec` (or `ruby run_specs.rb`) runs only the smoke specs.
