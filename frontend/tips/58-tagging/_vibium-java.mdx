### Importing Libraries

Lines 3 to 10 pull in Vibium's classes to drive the browser, and JUnit to run the tests.

### Setup and Teardown

The `beforeEach` method (lines 16 to 20) starts the browser and gets its first page (tab). The `afterEach` method
(lines 22 to 27) closes the browser.

### The Tests

We tag each test with JUnit's `@Tag`: `smoke` for the test on lines 29 to 34, and `wip` for the test on lines 36 to
42, which is not finished yet and fails.

Maven Surefire, which runs the tests, can run only the tests with a tag. `<groups>smoke</groups>` in the `pom.xml`
file sets it, so only the first test runs. To leave out only the `wip` tests instead, use
`<excludedGroups>wip</excludedGroups>`.
