### Importing Libraries

The `beforeEach` method (lines 10 to 12) starts Firefox, and the `afterEach` method (lines 14 to 16) quits it.

### The Test

Lines 18 to 28 are the test itself. It loads the page and prints it with `printPage`, in landscape. It returns the PDF
in base64, which the test decodes into a `Buffer`. It checks that the result starts with `%PDF-`, as every PDF file
does, and saves it as `tables.pdf` in a temporary folder. It prints where, so you can open it.
