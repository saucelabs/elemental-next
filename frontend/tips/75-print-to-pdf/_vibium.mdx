## Code Walkthrough

### Importing Libraries

Lines 1 to 5 pull in `assert`, Node's `fs`, `os` and `path` modules to save the PDF, and Vibium's `browser`.

### Setup and Teardown

After creating a `describe` to group our tests, lines 11 to 18 start and stop the browser.

The `beforeEach` method runs before each test. It starts the browser with `browser.start()` and gets its first page
(tab) with `bro.page()`. The `afterEach` method runs after each test and closes the browser with `bro.stop()`.

### The Test

Lines 20 to 30 are the test itself. It loads the page and prints it with `page.pdf()`, which returns the PDF. Vibium
has no print options yet, so the PDF is in portrait. It checks that the result starts with `%PDF-`, as every PDF file
does, and saves it as `tables.pdf` in a temporary folder. It prints where, so you can open it.
