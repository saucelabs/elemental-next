## Code Walkthrough

### Importing Libraries

Lines 3 to 14 pull in Vibium, Java's file classes, and JUnit.

### Setup and Teardown

The `beforeEach` method (lines 20 to 24) runs before each test. It starts the browser with `Vibium.start()` and gets
its first page (tab) with `browser.page()`. The `afterEach` method (lines 26 to 31) runs after each test and closes
the browser with `browser.stop()`.

### The Test

Lines 33 to 44 are the test itself. It loads the page and prints it with `page.pdf()`, which returns the PDF. Vibium
has no print options yet, so the PDF is in portrait. It checks that the result starts with `%PDF-`, as every PDF file
does, and saves it as `tables.pdf` in a temporary folder. It prints where, so you can open it.
