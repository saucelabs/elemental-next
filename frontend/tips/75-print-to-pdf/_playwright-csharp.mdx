## Code Walkthrough

### Importing Libraries

Lines 1 to 8 pull in the file and text classes of .NET, LINQ, Playwright, its MSTest integration, and MSTest.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends. There is no
setup or teardown code to write.

### The Test

Lines 15 to 26 are the test itself. It loads the page and prints it with `PdfAsync`, in landscape, into a temporary
folder. Playwright saves the PDF in the path we give it, and returns it too. The test checks that it starts with
`%PDF-`, as every PDF file does, and prints where it is. `pdf` works in Chromium, headless, as Playwright Test runs it
by default.
