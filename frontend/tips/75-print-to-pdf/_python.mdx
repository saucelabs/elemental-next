## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in `base64` to decode the PDF, `pytest`, Selenium's `webdriver`, and its `PrintOptions`.

### Setup and Teardown

Lines 7 to 11 are a fixture that starts Firefox, gives it to the test, and quits it at the end. The test also takes
pytest's `tmp_path` fixture, a temporary folder for the PDF.

### The Test

Lines 14 to 25 are the test itself. It loads the page, sets the orientation to landscape in `PrintOptions`, and prints
the page with `print_page`, which returns the PDF in base64. The test decodes it. It checks that the result starts
with `%PDF-`, as every PDF file does, and saves it as `tables.pdf` in a temporary folder. It prints where, so you can
open it.

### Executing the Test

Before executing the test, we need to install the required libraries with `pip install -r requirements.txt`.
