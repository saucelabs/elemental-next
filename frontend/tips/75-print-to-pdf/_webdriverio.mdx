### The Test

Lines 7 to 17 are the test itself. It loads the page, and `browser.savePDF` prints it in landscape, saves it as
`tables.pdf` in a temporary folder, and returns the PDF. The test checks that it starts with `%PDF-`, as every PDF
file does, and prints where it is.
