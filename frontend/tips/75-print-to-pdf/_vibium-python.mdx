## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` and Vibium's `browser`.

### Setup and Teardown

Lines 5 to 9 are a pytest fixture that starts and stops the browser. It starts the browser with `browser.start()` and
gives the test its first page (tab) with `bro.page()`. After the test runs, the code after `yield` closes the browser
with `bro.stop()`. The test also takes pytest's `tmp_path` fixture, a temporary folder for the PDF.

### The Test

Lines 12 to 21 are the test itself. It loads the page and prints it with `page.pdf()`, which returns the PDF. Vibium
has no print options yet, so the PDF is in portrait. It checks that the result starts with `%PDF-`, as every PDF file
does, and saves it as `tables.pdf` in a temporary folder. It prints where, so you can open it.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
