`PrintOptions`.

### Setup and Teardown

Selenide starts the browser when the test opens the first page, and closes it when the tests end. There is no setup or
teardown code to write.

### The Test

Lines 19 to 33 are the test itself. It opens the page, sets the orientation to landscape in `PrintOptions`, and prints
the page with `print`, from Selenide's driver (`getWebDriver()`) as a `PrintsPage`. It returns a `Pdf`, with the PDF
in base64, which the test decodes. It checks that the result starts with `%PDF-`, as every PDF file does, and saves it
as `tables.pdf` in a temporary folder. It prints where, so you can open it.
