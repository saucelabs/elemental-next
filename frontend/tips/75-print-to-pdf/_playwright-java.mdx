## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in Playwright's `Page` and JUnit extension, Java's file classes, and JUnit.

### Setup and Teardown

Line 13 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives
each test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup
or teardown code to write.

### The Test

Lines 16 to 26 are the test itself. It loads the page and prints it with `page.pdf`, in landscape, into a temporary
folder. Playwright saves the PDF in the path we give it, and returns it too. The test checks that it starts with
`%PDF-`, as every PDF file does, and prints where it is. `pdf` works in Chromium, headless, as Playwright Test runs it
by default.
