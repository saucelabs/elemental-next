## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect` from `@playwright/test`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. There is no setup or teardown code to write.

### The Test

Lines 3 to 13 are the test itself. It loads the page and prints it with `page.pdf`, in landscape, into the output
folder of the test (`testInfo.outputPath`). Playwright saves the PDF in the path we give it, and returns it too. The
test checks that it starts with `%PDF-`, as every PDF file does, and prints where it is. `pdf` works in Chromium,
headless, as Playwright Test runs it by default.
