## Code Walkthrough

### Example 1: Files Behind Basic Auth

Lines 5 to 16 group the first test, and line 6 sets the basic auth credentials (`httpCredentials`) for it.

The test (lines 8 to 15) visits the page with the files and gets the full URL (`href`) of the first link with
`evaluate`, which runs a function in the browser on the element.

Playwright comes with an HTTP client, `page.request`, and it uses the same credentials as the browser. So we send a
`HEAD` request for the file and check that it answers with status `200`. We don't need to add the credentials
ourselves.

### Example 2: A Page Behind a Form Login

Lines 18 to 23 log in with the form and wait for the success message. The site keeps the session in a cookie.

`page.request` also shares the cookies of the browser, so a `GET` request for `/secure` answers with `200`. We set
`maxRedirects: 0` so that a redirect to the login page would show up as a `302`.

To check that the page is really protected, we create a new request context (`playwright.request.newContext()`)
without any cookies. The same request now answers with `302` (a redirect to the login page).
