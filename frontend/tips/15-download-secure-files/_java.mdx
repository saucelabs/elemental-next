## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it. For the HTTP
requests we use the `HttpClient` that comes with Java, which doesn't follow redirects by default.

### Files Behind Basic Auth

`filesBehindBasicAuth` loads the secure downloads page with the credentials in the URL and collects the `href` of
every link (`getDomAttribute("href")` returns the relative path as written in the page). Then, for each link, it
sends a `HEAD` request with a Basic `Authorization` header (the credentials encoded in Base64) and asserts that the
response status is `200`.
The file names can have spaces and other characters that aren't allowed in a URL, so we build the URL with the `URI`
constructor that takes its parts (`new URI("https", host, path, null)`), which encodes them.

### Page Behind a Form Login

`pageBehindFormLogin` logs in through the form and waits for the success message. Then it grabs the session cookie
with `driver.manage().getCookieNamed("rack.session")` and sends it in a `Cookie` header when requesting `/secure`,
which returns `200`. Without the cookie, the same request is redirected to the login page (`302`).
