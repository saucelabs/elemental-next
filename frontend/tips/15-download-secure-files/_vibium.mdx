## Code Walkthrough

### Setup and Teardown

The `beforeEach` method (lines 10 to 13) starts the browser and gets its first page (tab). The `afterEach` method
(lines 15 to 17) closes the browser.

### Example 1: Files Behind Basic Auth

Lines 19 to 30 are the first test.

Basic auth sends the credentials in the `Authorization` header of each request. We build that header with `Buffer`
and add it to the page with `page.setHeaders`. Then we visit the page with the files and get the full URL of the
first link.

`fetch` doesn't know about the browser, so we send the same header with it. We send a `HEAD` request for the file and
check that it answers with status `200`.

### Example 2: A Page Behind a Form Login

Lines 32 to 49 log in with the form and wait for the success message. The site keeps the session in a cookie called
`rack.session`.

We get the cookies of the page's context with `page.context.cookies()` and send that one in the `Cookie` header of a
request for `/secure`. With the cookie, it answers with `200`. Without it, it answers with `302` (a redirect to the
login page). We set `redirect: 'manual'` so that `fetch` doesn't follow the redirect.
