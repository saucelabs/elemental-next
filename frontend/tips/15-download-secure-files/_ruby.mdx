## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward. We also add a small
`request` helper that sends a request with `Net::HTTP` from the standard library, which doesn't follow redirects.

### Files Behind Basic Auth

The first `run` block loads the secure downloads page with the credentials in the URL and gets the `href` of the first
file (`dom_attribute('href')` returns the relative path as written in the page). Then it sends a `HEAD` request with the
same credentials (`head.basic_auth('admin', 'admin')`) and asserts that the response status is `200`.
The file names can have spaces and other characters that aren't allowed in a URL, so we encode the path first
(`URI::RFC2396_PARSER.escape`).

### Page Behind a Form Login

The second `run` block logs in through the form and waits for the success message. Then it grabs the session cookie
with `@driver.manage.cookie_named('rack.session')` and sends it in a `Cookie` header when requesting `/secure`, which
returns `200`. Without the cookie, the same request is redirected to the login page (`302`).
