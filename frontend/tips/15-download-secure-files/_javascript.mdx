## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it. For the HTTP requests we
use `fetch`, which is built into Node.js.

### Files Behind Basic Auth

The first test loads the secure downloads page with the credentials in the URL and collects the `href` of every link
(`getDomAttribute("href")` returns the relative path as written in the page). Then, for each link, it sends a `HEAD`
request with a Basic `Authorization` header (the credentials encoded in Base64) and asserts that the response status
is `200`.

### Page Behind a Form Login

The second test logs in through the form and waits for the success message. Then it grabs the session cookie with
`driver.manage().getCookie("rack.session")` and sends it in a `Cookie` header when requesting `/secure`, which
returns `200`. Without the cookie, the same request is redirected to the login page (`302`). We pass
`redirect: "manual"` to `fetch` so it gives us the redirect instead of following it.
