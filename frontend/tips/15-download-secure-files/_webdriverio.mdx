## Code Walkthrough

### Example 1: Files Behind Basic Auth

Lines 7 to 18 are the first test.

We visit the page with the files, passing the credentials with the `auth` option of `browser.url`. Then we collect the
full URL of every link (the `href` property).

`fetch` doesn't know about the browser, so we build the `Authorization` header with the same credentials. We send a
`HEAD` request for each file, all at the same time with `Promise.all`, and check that each one answers with status
`200`.

### Example 2: A Page Behind a Form Login

Lines 20 to 36 log in with the form and wait for the success message. The site keeps the session in a cookie called
`rack.session`.

We get that cookie with `browser.getCookies` and send it in the `Cookie` header of a request for `/secure`. With the
cookie, it answers with `200`. Without it, it answers with `302` (a redirect to the login page). We set
`redirect: 'manual'` so that `fetch` doesn't follow the redirect.
