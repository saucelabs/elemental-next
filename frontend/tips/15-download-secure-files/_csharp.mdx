## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

We also create an `HttpClient` that doesn't follow redirects (`AllowAutoRedirect = false`) and doesn't store cookies
(`UseCookies = false`), so each request only sends what we give it.

### Files Behind Basic Auth

`FilesBehindBasicAuth` loads the secure downloads page with the credentials in the URL and gets the `href` of the first
file (`GetDomAttribute("href")` returns the relative path as written in the page). Then it sends a `HEAD` request with a
Basic `Authorization` header (the credentials encoded in Base64) and asserts that the response status is `200`.

### Page Behind a Form Login

`PageBehindFormLogin` logs in through the form and waits for the success message. Then it grabs the session cookie
with `_driver.Manage().Cookies.GetCookieNamed("rack.session")` and sends it in a `Cookie` header when requesting
`/secure`, which returns `200`. Without the cookie, the same request is redirected to the login page (`302`).
