## Code Walkthrough

### Setup and Teardown

The `setup` method (lines 10 to 15) turns on WebDriver BiDi with `web_socket_url`, and starts Chrome. The `teardown`
method (lines 17 to 19) quits the browser, and `run` (lines 21 to 26) calls them around the test.

### The Test

The test (lines 28 to 56) creates the BiDi `Network` module and adds a handler for the `:before_request` event
(lines 30 to 40), which the browser sends before each request. The handler skips the requests to other sites, and keeps the method, the URL and the start time of the others.
Then the test goes from the home page to [the second Dynamic Loading example](https://the-internet.herokuapp.com/dynamic_loading/2),
clicks Start, and waits until "Hello World!" shows up.

At the end, it writes the HAR file, `journey.har` (lines 50 and 51), and checks that the three pages are in it.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running `bundle install`
from the command-line.
