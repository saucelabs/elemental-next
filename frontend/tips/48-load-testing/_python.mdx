## Code Walkthrough

### Setup and Teardown

The `driver` fixture (lines 14 to 21) turns on WebDriver BiDi with `enable_bidi`, and starts Chrome. It `yield`s the
driver to the test, and quits the browser when the test is done.

### The Test

`test_record_user_journey` (lines 24 to 52) adds a handler for the `before_request_sent` event (lines 27 to 37),
which the browser sends before each request. The handler skips the requests to other sites, and keeps the method, the URL and the start time of the others.
Then the test goes from the home page to [the second Dynamic Loading example](https://the-internet.herokuapp.com/dynamic_loading/2),
clicks Start, and waits until "Hello World!" shows up.

At the end, it writes the HAR file, `journey.har` (lines 46 to 48), and checks that the three pages are in it.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line.
