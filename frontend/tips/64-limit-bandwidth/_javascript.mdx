## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook (lines 7 to 15) starts Chrome and limits its network with `setNetworkConditions`: every request
waits half a second (`latency`, in milliseconds), and the browser downloads at most 200 KB per second and uploads at
most 50 KB per second (`download_throughput` and `upload_throughput`, in bytes per second). The `afterEach` hook
(lines 17 to 21) quits the browser.

### The Test

The test (lines 23 to 32) loads the page and measures how long it takes. Then it checks the heading of the page, to
make sure it loaded, and that it took at least 3 seconds. On a fast connection, the page loads in 1 or 2 seconds, so
the check shows that the limits work.
