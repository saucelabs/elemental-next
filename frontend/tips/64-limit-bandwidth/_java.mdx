## Code Walkthrough

### Setup and Teardown

The `beforeEach` method (lines 15 to 24) starts Chrome and limits its network with `setNetworkConditions`: every
request waits half a second (`setLatency`), and the browser downloads at most 200 KB per second and uploads at most
50 KB per second (`setDownloadThroughput` and `setUploadThroughput`, in bytes per second). The `afterEach` method
(lines 26 to 31) quits the browser.

### The Test

`pageLoadsOnSlowNetwork` (lines 33 to 43) loads the page and measures how long it takes. Then it checks the heading
of the page, to make sure it loaded, and that it took at least 3 seconds. On a fast connection, the page loads in 1
or 2 seconds, so the check shows that the limits work.
