## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a browser tab) and its `context` (the
browser session that holds all the tabs). Playwright closes them when the test ends.

### The Test

Lines 3 to 11 are the test itself.

After visiting the first page, `context.newPage()` opens a new tab in the same context. Playwright doesn't make a
difference between a tab and a window: each one is a page object.

The new page is ready to use right away, there is no need to switch to it. We visit another page in it, check that the
context has two pages, and check the heading of the new page.
