### The Tests

Lines 4 to 13 open a new window, and lines 15 to 24 open a new tab. They only differ in the `type` option.

After visiting the first page, `browser.newWindow` opens the URL in a new window (`type: 'window'`) or tab
(`type: 'tab'`) and waits for it to load. Since WebdriverIO 10, it returns the browsing context of the new window and
doesn't switch to it. We tell TypeScript that it is a `BrowsingContext` with `as`, since older sessions return
something else.

We check that there are two windows open with `browser.browsingContexts()`, and check the heading of the new page.

WebdriverIO uses the same browser for all the tests of a file, so we close the new window at the end of each test.
