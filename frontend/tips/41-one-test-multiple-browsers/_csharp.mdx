## Code Walkthrough

### Setup and Teardown

`SetUp` receives the browser name. If the credentials are not set, it stops the test with `Assert.Inconclusive`.
Otherwise, it creates the options for that browser with a `switch` expression (all of them inherit from
`DriverOptions`), sets the version and operating system, adds the Sauce Labs options (including the browser in the
test name), and connects to Sauce Labs with a `RemoteWebDriver`. The `TearDown()` method (marked with
`[TestCleanup]`) quits the browser.

### The Test

`Title` runs once for each `[DataRow]`, receiving the browser name. It calls `SetUp` with it, loads the page, and
asserts that the title is correct.
