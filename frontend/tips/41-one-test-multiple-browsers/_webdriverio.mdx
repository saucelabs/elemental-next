## Code Walkthrough

### Configuring the Browsers

In WebdriverIO, the list of browsers is part of the configuration. The test runner runs every spec file once for each
entry in `capabilities`.

<TipCode codePath={"41-one-test-multiple-browsers/code/webdriverio/wdio.conf.ts"} language={"ts"}/>

- Line 1 lists the browsers: Chrome, Firefox and Edge.
- Lines 5 to 7 give WebdriverIO the Sauce Labs credentials (from the `SAUCE_USERNAME` and `SAUCE_ACCESS_KEY`
  environment variables) and the region, so the tests run on Sauce Labs.
- Lines 9 to 12 turn on the Sauce service (the `@wdio/sauce-service` package). It names each job on Sauce Labs and,
  when the tests end, marks the job as passed or failed. `setJobName` sets the name, with the browser of the job.
- `maxInstances: 1` (line 15) runs one browser at a time. See the next tip to run them in parallel.
- Lines 16 to 20 turn each browser into a capability: the latest version on Windows 11.

### The Test

The test (lines 4 to 7) loads the page and checks the title. The test knows nothing about the browsers: adding one is a change in the configuration only.
