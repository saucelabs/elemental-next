## Code Walkthrough

### Setup and Teardown

`setUp` receives the browser name. If the credentials are not set, `Assumptions.assumeTrue` skips the test.
Otherwise, it creates the options for that browser with a `switch` expression (all of them extend
`AbstractDriverOptions`), sets the version and operating system, adds the Sauce Labs options (including the browser
in the test name), and connects to Sauce Labs with a `RemoteWebDriver`. The `afterEach` method quits the browser.

### The Test

`title` is a `@ParameterizedTest`, so it runs once for each browser in `@ValueSource`. It calls `setUp` with the
browser, loads the page, and asserts that the title is correct.
