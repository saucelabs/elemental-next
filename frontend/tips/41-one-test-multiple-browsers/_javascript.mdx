## Code Walkthrough

### Setup and Teardown

We create a `describe` block for each browser in `BROWSERS` with a `for` loop. In each of them, the `beforeEach`
hook skips the test if the credentials are not set. Otherwise, it connects to Sauce Labs (`usingServer(SAUCE_URL)`)
with the capabilities for that browser: its name, the version and operating system, and the Sauce Labs options
(including the browser in the test name). The `afterEach` hook quits the browser.

### The Test

The test loads the page and asserts that the title is correct. It doesn't know which browser it is running on.
