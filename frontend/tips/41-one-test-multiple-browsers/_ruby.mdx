## Code Walkthrough

### Setup and Teardown

If the credentials are not set, the script prints a message and exits without running the test.

`setup` receives the browser name. It creates the options for that browser (`Selenium::WebDriver::Options.send(browser)`
calls `Options.chrome`, `Options.firefox`, and so on), sets the version and operating system, adds the Sauce Labs
options (including the browser in the test name), and connects to Sauce Labs. `teardown` quits the browser.

`run` loops over `BROWSERS`, running `setup`, the test, and `teardown` for each of them.

### The Test

The test loads the page and asserts that the title is correct. It doesn't know which browser it is running on.
