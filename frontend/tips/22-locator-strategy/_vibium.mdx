## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Tests

Each test visits the download page and finds a link with a CSS selector. `page.find` returns the first element that
matches, and `attr('href')` reads where the link goes. We print it and check it.

- Lines 17 to 22 look for any link on the page (`a`). The first one on the page is the "Fork me on GitHub" banner,
  which is not the link we want.
- Lines 24 to 29 narrow the search to the content of the page (`#content a`). That finds a file link.
- Lines 31 to 36 narrow it further to the list of files (`#content .example a`). This selector says exactly where
  the link is, so a change somewhere else on the page won't break it.
