## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox and visits the page before each test, and the `afterEach` hook quits it.

### The Tests

Each test finds a link with `driver.findElement(By.css(...))`, gets its URL with `getAttribute("href")`, logs it, and
checks where it points to. Note the `By.css`: it tells Selenium which locator strategy to use, and the string we pass
to it is the selector.
