## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox and visits the page before each test, and the `afterEach` method quits it.

### The Tests

Each test finds a link with `driver.findElement(By.cssSelector(...))`, gets its URL with `getDomProperty("href")`
(the full URL, as the browser resolved it), prints it, and checks where it points to. Note the `By.cssSelector`: it
tells Selenium which locator strategy to use, and the string we pass to it is the selector.
