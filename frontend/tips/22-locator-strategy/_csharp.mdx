## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox and visits the
page, and the `TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Tests

Each test finds a link with `_driver.FindElement(By.CssSelector(...))`, gets its URL with `GetDomProperty("href")`
(the full URL, as the browser resolved it), writes it to the console, and checks where it points to. Note the
`By.CssSelector`: it tells Selenium which locator strategy to use, and the string we pass to it is the selector.
