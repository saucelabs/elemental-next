## Code Walkthrough

### Importing Libraries

Lines 3 to 9 pull in Vibium's classes to drive the browser, and JUnit to run the tests.

### Setup and Teardown

The `beforeEach` method (lines 15 to 19) starts the browser and gets its first page (tab). The `afterEach` method
(lines 21 to 26) closes the browser.

### The Tests

Each test visits the download page and finds a link with a CSS selector. `page.find` returns the first element that
matches, and `attr("href")` reads where the link goes. We print it and check it.

- Lines 28 to 34 look for any link on the page (`a`). The first one on the page is the "Fork me on GitHub" banner,
  which is not the link we want.
- Lines 36 to 42 narrow the search to the content of the page (`#content a`). That finds a file link.
- Lines 44 to 50 narrow it further to the list of files (`#content .example a`). This selector says exactly where
  the link is, so a change somewhere else on the page won't break it.
