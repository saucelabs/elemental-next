## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox and visits the page, and the `teardown` method quits it. The `run` method wraps
each test with them.

### The Tests

Each test finds a link with `@driver.find_element(css: ...)`, gets its URL with `attribute('href')`, outputs it, and
checks where it points to. Note the `css:`: it tells Selenium which locator strategy to use, and the string after it
is the selector.
