## Code Walkthrough

### The Tests

All the tests visit the download page first. The fixture on lines 5 to 7 does it, and `autouse=True` makes it run
before every test in the file.

Each test finds the first link with a locator that is a bit more specific than the one before, reads its `href` and
checks where it points:

- Lines 10 to 13 use `a`, which matches every link on the page. The first one is the "Fork me on GitHub" banner, not
  the link we want.
- Lines 16 to 19 look only inside the `#content` element, which gets us one of the download links.
- Lines 22 to 25 go one step further, into the `.example` element inside `#content`.

A locator in Playwright is lazy: it finds the elements when we use it, and `first` picks the first match. The more
specific the locator, the less it depends on the rest of the page.
