### The Test

Lines 4 to 13 are the test itself.

`browser.mock` (line 5) intercepts the requests whose URL matches the pattern. The `*` at the end matches the query
string, which changes with the options of the form. `respond` (line 6) answers them with the given body: WebdriverIO sends an
object as JSON, with a `200`. The request never reaches the server. The other requests load as usual. WebdriverIO
does this with WebDriver BiDi.

Then the test loads the page and clicks the button. The page calls the API, gets the mocked response, and shows its
message. `toHaveText` waits for the message in the status line, and for the attempt in the list (`200: Hello from the
mock`).
