## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `securerandom` (for the room name) and Selenium.

### The Steps of a User

Line 5 builds the URL of the chat with a random room.

- `wait_for_text` (lines 7 to 10) waits up to 10 seconds until the text of an element contains the given text.
- `join` (lines 12 to 17) opens the chat, waits until the page is connected, types the name, and clicks "Join".
- `send_message` (lines 19 to 22) types the message and clicks "Send".

Each one takes the driver of the user, so the same steps work for Alice and for Bob.

### One Browser for Each User

Lines 25 and 26 start one Firefox for Alice and one for Bob. The `ensure` block (lines 38 to 40) quits both, even when
the test fails.

### The Test

Alice and Bob join (lines 28 and 29). Messages are not saved, so Alice waits until she sees "Bob joined" before she
writes (line 31). Then Alice sends "Hi Bob", and the test waits until Bob's page shows it (lines 33 and 34), and the
other way around (lines 36 and 37). When the text doesn't show up, the wait fails the test.
