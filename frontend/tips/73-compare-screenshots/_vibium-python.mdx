## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in `io`, `pytest`, Pillow's `Image` and `ImageChops`, and Vibium's `browser`.

### Setup and Teardown

Lines 9 to 13 are a pytest fixture that starts and stops the browser.

It starts the browser with `browser.start()` and gives the test its first page (tab) with `bro.page()`. After the test
runs, the code after `yield` closes the browser with `bro.stop()`.

### Taking and Comparing Screenshots

`card_screenshot` (lines 16 to 19) loads a URL, takes a screenshot of the card only (`screenshot()` of the element),
and reads the PNG into an image.

`different_pixels` (lines 22 to 28) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, Pillow subtracts one image from the other: the result is black where the pixels are the
same. Its histogram counts the pixels of each shade, and every shade but black is a difference.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
