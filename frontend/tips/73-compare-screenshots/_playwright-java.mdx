## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Playwright's `Page` and JUnit extension, Java's `BufferedImage` and `ImageIO`, and JUnit.

### Setup and Teardown

Line 12 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives
each test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup
or teardown code to write.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 16 to 20) loads a URL, takes a screenshot of the card only (`locator.screenshot()`), and reads
the PNG into an image.

`differentPixels` (lines 22 to 36) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
