### Taking and Comparing Screenshots

`cardScreenshot` (lines 6 to 16) loads a URL, takes a screenshot of the card only, and reads the PNG into an image. It
takes the screenshot with the WebDriver BiDi command `browsingContext.captureScreenshot`, clipped to the card, and
relative to the document (`origin: 'document'`), so it has the whole card even when part of it is out of the window. A
screenshot relative to the window (the default) cuts the card to the visible part.

`differentPixels` (lines 18 to 31) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through the pixel data: each pixel takes 4 bytes (red, green, blue and alpha),
so it compares them 4 bytes at a time.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
