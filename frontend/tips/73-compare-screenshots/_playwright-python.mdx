## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in `io`, Pillow's `Image` and `ImageChops`, and Playwright's `Page`.

### Setup and Teardown

The `pytest-playwright` plugin handles the browser for us. Each test that takes a `page` argument receives a fresh
browser tab, and the plugin closes it when the test ends. There is no setup or teardown code to write.

### Taking and Comparing Screenshots

`card_screenshot` (lines 8 to 11) loads a URL, takes a screenshot of the card only (`locator.screenshot()`), and reads
the PNG into an image.

`different_pixels` (lines 14 to 20) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, Pillow subtracts one image from the other: the result is black where the pixels are the
same. Its histogram counts the pixels of each shade, and every shade but black is a difference.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
