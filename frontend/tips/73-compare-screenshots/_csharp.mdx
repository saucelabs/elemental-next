## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in MSTest, Selenium and SkiaSharp, a cross-platform image library.

### Setup and Teardown

The `SetUp` method (lines 14 to 18) starts Firefox, and the `TearDown` method (lines 20 to 24) quits it.

### Taking and Comparing Screenshots

`CardScreenshot` (lines 26 to 31) loads a URL, takes a screenshot of the card only (`GetScreenshot()` of the element,
through `ITakesScreenshot`), and reads the PNG into an image.

`DifferentPixels` (lines 33 to 52) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the project file (e.g.,
`csharp.csproj` in this case). `SkiaSharp.NativeAssets.Linux` adds the native SkiaSharp library for Linux.
