## Code Walkthrough

### Importing Libraries

Lines 3 to 14 pull in Java's `BufferedImage` and `ImageIO`, JUnit, and Selenium.

### Setup and Teardown

The `beforeEach` method (lines 20 to 23) starts Firefox, and the `afterEach` method (lines 25 to 30) quits it.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 32 to 36) loads a URL, takes a screenshot of the card only
(`getScreenshotAs(OutputType.BYTES)` of the element), and reads the PNG into an image.

`differentPixels` (lines 38 to 52) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
