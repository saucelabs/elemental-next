## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in `assert`, `pngjs` to read PNG images, and Vibium's `browser`.

### Setup and Teardown

After creating a `describe` to group our tests, lines 11 to 18 start and stop the browser.

The `beforeEach` method runs before each test. It starts the browser with `browser.start()` and gets its first page
(tab) with `bro.page()`. The `afterEach` method runs after each test and closes the browser with `bro.stop()`.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 20 to 23) loads a URL, takes a screenshot of the card only (`screenshot()` of the element),
and reads the PNG into an image.

`differentPixels` (lines 25 to 38) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through the pixel data: each pixel takes 4 bytes (red, green, blue and alpha),
so it compares them 4 bytes at a time.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
