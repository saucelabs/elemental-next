## Code Walkthrough

### Importing Libraries

Lines 3 to 8 pull in Selenide, Java's `BufferedImage`, and JUnit.

### Setup and Teardown

Selenide starts the browser when the test opens the first page, and closes it when the tests end. There is no setup or
teardown code to write.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 13 to 16) loads a URL, takes a screenshot of the card only (`screenshotAsImage()` of the
element, which returns the image already read), and reads the PNG into an image.

`differentPixels` (lines 18 to 32) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
