## Code Walkthrough

### Importing Libraries

Lines 3 to 14 pull in Selenide, Java's `BufferedImage` and `ImageIO`, JUnit, and Selenium's `OutputType`.

### Setup and Teardown

Selenide starts the browser when the test opens the first page, and closes it when the tests end. The `useFirefox`
method (lines 19 to 22) tells it to use Firefox: Firefox takes the screenshot of the whole element, even when part of
it is out of the window, while Chrome cuts it to the visible part. The card is near the bottom of a small window, so
in Chrome the moved button could be out of the screenshot.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 24 to 29) loads a URL, takes a screenshot of the card only, and reads the PNG into an image.
It uses the screenshot of the WebDriver element (`toWebElement().getScreenshotAs`): Selenide's own element screenshot
crops the element from a screenshot of the visible part of the page.

`differentPixels` (lines 31 to 45) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
