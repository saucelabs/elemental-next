## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the Playwright test runner and `pngjs` to read PNG images.

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. There is no setup or teardown code to write.

### Taking and Comparing Screenshots

`cardScreenshot` (lines 6 to 9) loads a URL, takes a screenshot of the card only (`locator.screenshot()`), and reads
the PNG into an image.

`differentPixels` (lines 11 to 24) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through the pixel data: each pixel takes 4 bytes (red, green, blue and alpha),
so it compares them 4 bytes at a time.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.
