## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in Playwright's MSTest integration, MSTest, and SkiaSharp, a cross-platform image library.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends. There is no
setup or teardown code to write.

### Taking and Comparing Screenshots

`CardScreenshot` (lines 13 to 18) loads a URL, takes a screenshot of the card only (`ScreenshotAsync()` of the
locator), and reads the PNG into an image.

`DifferentPixels` (lines 20 to 39) counts the pixels that differ between two images. When the sizes differ, every
pixel is different. Otherwise, it goes through every pixel and compares their colors.

### The Tests

Each test takes its baseline in the same run: a screenshot of the card without changes. The first test compares it
with a second screenshot of the same card, and checks that no pixels differ. The second test compares it with a
screenshot of the card with the button moved (`?shift=10`), and checks that some pixels differ.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`playwright-csharp.csproj` in this case). `SkiaSharp.NativeAssets.Linux` adds the native SkiaSharp library for Linux.
