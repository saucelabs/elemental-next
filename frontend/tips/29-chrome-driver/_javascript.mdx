## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook (lines 7 to 10) starts Chrome with `new Builder().forBrowser("chrome").build()`. There is no
driver path: Selenium Manager finds Chrome and the matching ChromeDriver, and downloads what is missing. The
`afterEach` hook (lines 12 to 16) quits the browser.

### The Test

The test (lines 18 to 25) loads the page and checks its title. Then it prints the versions of Chrome and ChromeDriver
from the capabilities of the session, to show which ones Selenium Manager picked. The ChromeDriver version matches the
Chrome version.
