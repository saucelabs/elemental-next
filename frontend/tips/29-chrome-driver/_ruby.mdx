## Code Walkthrough

### Setup and Teardown

The `setup` method (lines 5 to 8) starts Chrome with `Selenium::WebDriver.for :chrome`. There is no driver path:
Selenium Manager finds Chrome and the matching ChromeDriver, and downloads what is missing. The `teardown` method
(lines 10 to 12) quits the browser, and `run` (lines 14 to 18) calls them around the test.

### The Test

The test (lines 20 to 26) loads the page and checks its title. Then it prints the versions of Chrome and ChromeDriver
from the capabilities of the session, to show which ones Selenium Manager picked. The ChromeDriver version matches the
Chrome version.
