### Setup and Teardown

The `beforeEach` method (lines 13 to 17) starts Chrome with `new ChromeDriver()`. There is no
`webdriver.chrome.driver` property: Selenium Manager finds Chrome and the matching ChromeDriver, and downloads what is
missing. The `afterEach` method (lines 19 to 24) quits the browser.

### The Test

`pageLoaded` (lines 26 to 33) loads the page and checks its title. Then it prints the versions of Chrome and
ChromeDriver from the capabilities of the session, to show which ones Selenium Manager picked. The ChromeDriver version
matches the Chrome version.
