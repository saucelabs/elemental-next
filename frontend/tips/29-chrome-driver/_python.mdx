## Code Walkthrough

### Setup and Teardown

The `driver` fixture (lines 5 to 10) starts Chrome with `webdriver.Chrome()`. There is no driver path: Selenium
Manager finds Chrome and the matching ChromeDriver, and downloads what is missing. The fixture `yield`s the driver to
the test, and quits the browser when the test is done.

### The Test

`test_page_loaded` (lines 13 to 17) loads the page and checks its title. Then it prints the versions of Chrome and
ChromeDriver from the capabilities of the session, to show which ones Selenium Manager picked. The ChromeDriver version
matches the Chrome version.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
