## Code Walkthrough

### Setup and Teardown

The `SetUp` method (lines 13 to 18) starts Chrome with `new ChromeDriver()`. There is no driver path: Selenium
Manager finds Chrome and the matching ChromeDriver, and downloads what is missing. The `TearDown` method (lines 20 to
24) quits the browser.

### The Test

`PageLoaded` (lines 26 to 34) loads the page and checks its title. Then it prints the versions of Chrome and
ChromeDriver from the capabilities of the session, to show which ones Selenium Manager picked. The ChromeDriver version
matches the Chrome version.
