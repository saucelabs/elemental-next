## Code Walkthrough

### The Base Page Object

`BasePage` stores the Selenium WebDriver instance it receives in its constructor, and the rest of the class is
filled with common Selenium actions: `visit`, `find`, `click`, `type`, `isDisplayed`, `textOf`, `title`,
and `waitFor`. They are `protected`, so only the Page Objects that inherit from it can use them.

Note that `isDisplayed` returns `false` when the element is not on the page instead of throwing an exception.
That lets `waitFor` use it with an explicit wait (`WebDriverWait`) until the element is displayed.

### The Page Objects

`DynamicLoadingPage` and `LoginPage` inherit from it (`public class DynamicLoadingPage extends BasePage`). Their
constructors call `super(driver)` first, which stores the driver in the Base Page Object. Then they visit their
page and verify that we are in the right place.

Each method now reads like a description of the page behavior (e.g., `click(START_BUTTON)`), with no Selenium code
in it.

### The Test

`BasePageTest` launches Firefox in `beforeEach` and quits it in `afterEach`. The tests create the Page Objects
and use their methods, just like in the previous tip.
