## Code Walkthrough

### The Base Page Object

`BasePage` stores the Selenium WebDriver instance it receives in its constructor, and the rest of the class is
filled with common Selenium actions: `visit`, `find`, `click`, `type`, `isDisplayed`, `textOf`, `title`,
and `waitFor`.

Note that `isDisplayed` returns `false` when the element is not on the page instead of throwing an error, and
`waitFor` waits until the element is located and visible.

### The Page Objects

`DynamicLoadingPage` and `LoginPage` inherit from it (`class DynamicLoadingPage extends BasePage`). Since they
don't need anything else in their constructor, they use the one from `BasePage`. Because WebDriver calls are
asynchronous, visiting the page and verifying that we are in the right place happens in the `load()` method.

Each method now reads like a description of the page behavior (e.g., `await this.click(START_BUTTON)`), with no
Selenium code in it.

### The Test

The `beforeEach` hook launches Firefox and the `afterEach` hook quits it. The tests create the Page Objects, load
them, and use their methods, just like in the previous tip.
