## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox.

MSTest gives the test class a `TestContext` when it has a public property with that name. In the `TearDown()` method
(marked with `[TestCleanup]`) we use it to check if the test failed (`TestContext.CurrentTestOutcome`). If it did, we
cast the driver to `ITakesScreenshot`, capture a screenshot, and save it with the class and test name in the filename
(e.g., `failshot_csharp.ScreenshotTest.FailsOnPurpose.png`). Then we close the browser.

`dotnet test` runs the tests from the build output directory, so the screenshot is saved there (e.g.,
`bin/Debug/net10.0`).

### The Test

`FailsOnPurpose` loads the homepage of the-internet and asserts that the heading is `blah blah blah`, which fails.
