## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox.

In the `afterEach` hook we check if the test failed (`this.currentTest.state === "failed"`). If it did, we capture a
screenshot with `driver.takeScreenshot()`, which returns the image encoded in Base64, and save it with
`fs.writeFileSync`. To make the filename unique we use the test name after cleaning it up (by replacing spaces with
`-`), e.g., `failshot_Screenshot-fails-on-purpose.png`. Then we quit the browser.

Note that the hooks use `function () {}` instead of arrow functions, so Mocha can give us the test through `this`.

### The Test

The test loads the homepage of the-internet and asserts that the heading is `blah blah blah`, which fails.
