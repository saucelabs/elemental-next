## Code Walkthrough

### Taking the Screenshot

The `pytest-playwright` plugin can take a screenshot when a test fails, with no code in the test. We turn it on with
the `--screenshot only-on-failure` option. To not type it every time, we add it to `pytest.ini`.

<TipCode codePath={"16-take-screenshot-on-failure/code/playwright-python/pytest.ini"} language={"ini"}/>

The plugin saves the screenshot as `test-failed-1.png` in a folder for the test, inside `test-results`.

### The Test

Lines 4 to 7 are a test that fails on purpose. It visits the page and checks that the heading says `blah blah blah`,
which it doesn't. We give the check a short timeout (2 seconds), so it fails fast.

When it fails, the plugin takes the screenshot.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.

run the test by executing `pytest screenshot.py` from the command-line.
