## Code Walkthrough

### Setup and Teardown

The `setup` and `teardown` methods launch and quit Firefox.

The `run` method is where we capture a failure and take a screenshot. We wrap our test code (e.g., `yield`) in a
`begin`/`rescue` block. When an assertion fails, the error message is printed to the terminal and we capture a
screenshot with `@driver.save_screenshot`. Then we re-raise the error (`raise`), so the test still fails. The
`ensure` block closes the browser whether the test passed or failed.

Note the use of `Time.now.strftime` in the screenshot filename. This is adding a timestamp (down to the second) to
the filename. This provides a (reasonably) unique file name and has the added benefit of listing the files in the
order taken.

### The Test

The test loads the homepage of the-internet and asserts that the heading is `blah blah blah`, which fails.
