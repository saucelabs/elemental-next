## Code Walkthrough

### The Extension

JUnit 5 lets us hook into the test lifecycle with extensions. `ScreenshotOnFailure` implements
`AfterTestExecutionCallback`, which runs right after the test method and _before_ the `@AfterEach` methods, so the
browser is still open. If the test threw an exception (`context.getExecutionException().isPresent()`), we cast the
driver to `TakesScreenshot`, capture a screenshot, and save it with the class and test name in the filename (e.g.,
`failshot_ScreenshotTest.failsOnPurpose.png`).

The extension receives a `Supplier<WebDriver>` instead of the driver itself, because the driver is created later, in
the `@BeforeEach` method.

### Setup and Teardown

In `ScreenshotTest` we register the extension with `@RegisterExtension`, passing it a lambda that returns the current
driver. The `beforeEach` method launches Firefox and the `afterEach` method quits it.

### The Test

`failsOnPurpose` loads the homepage of the-internet and asserts that the heading is `blah blah blah`, which fails.
