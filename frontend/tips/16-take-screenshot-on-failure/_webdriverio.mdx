## Code Walkthrough

### Taking the Screenshot

WebdriverIO calls the `afterTest` hook of `wdio.conf.ts` after each test, with the result of the test. When the test
didn't pass, the hook builds a file name from the name of the test (with dashes instead of spaces) and saves a
screenshot with `browser.saveScreenshot`, e.g., `failshot_Screenshot-fails-on-purpose.png`.

Since the hook is in the configuration, it works for every test without changing them.

### The Test

Lines 4 to 8 are a test that fails on purpose. It visits the page and checks that the heading says `blah blah blah`,
which it doesn't. We give the check a short timeout (2 seconds), so it fails fast.

When it fails, the hook takes the screenshot.
