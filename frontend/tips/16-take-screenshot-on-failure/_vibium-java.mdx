## Code Walkthrough

### The Extension

`ScreenshotOnFailure` is a JUnit extension. JUnit calls its `afterTestExecution` method after each test, before the
`@AfterEach` methods, so the browser is still open. `context.getExecutionException()` tells us if the test failed.
When it did, we take a screenshot with `page.screenshot()` and save it with the name of the test, e.g.,
`failshot_ScreenshotTest.failsOnPurpose.png`.

The extension gets the page with a `Supplier`, because the page is created later, in `beforeEach`.

### The Test Class

Lines 16 and 17 register the extension. The `beforeEach` method (lines 19 to 23) starts the browser and gets its
first page (tab). The `afterEach` method (lines 25 to 30) closes the browser.

Lines 32 to 36 are a test that fails on purpose. It visits the page and checks that the heading says `blah blah
blah`, which it doesn't. When it fails, the extension takes the screenshot.
