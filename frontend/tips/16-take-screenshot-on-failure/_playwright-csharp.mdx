## Code Walkthrough

### Taking the Screenshot

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property and closes it
after the test. MSTest runs our `[TestCleanup]` method (lines 11 to 21) before that, so the page is still open.

`TestContext.CurrentTestOutcome` tells us how the test ended. When it failed, we take a screenshot with
`ScreenshotAsync` and save it with the name of the test class and the test in the file name, like
`failshot_PlaywrightTests.ScreenshotTest.FailsOnPurpose.png`. The file is saved in the folder the tests run from
(`bin/Debug/net10.0`).

### The Test

Lines 23 to 30 are a test that fails on purpose. It visits the page and checks that the heading says `blah blah blah`,
which it doesn't. We give the check a short timeout (2 seconds), so it fails fast.

When it fails, the cleanup method takes the screenshot.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`playwright-csharp.csproj` in this case).
