## Code Walkthrough

### Knowing When a Test Failed

A pytest fixture doesn't know by itself whether the test that used it failed. So in `conftest.py` we add a hook
(`pytest_runtest_makereport`) that runs after each phase of a test (setup, call, and teardown), and stores the report
of that phase on the test item (e.g., `report_call` for the test itself).

### Setup and Teardown

The `driver` fixture creates a Firefox instance and `yield`s it to the test. After the test, it checks the report of
the test call (`request.node.report_call`). If it failed, it captures a screenshot with
`driver.save_screenshot`, using the test name to make the filename unique (e.g., `failshot_test_fails_on_purpose.png`).
Then it quits the browser.

### The Test

`test_fails_on_purpose` loads the homepage of the-internet and asserts that the heading is `blah blah blah`, which
fails.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
