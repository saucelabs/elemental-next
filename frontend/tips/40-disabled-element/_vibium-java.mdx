### Importing Libraries

Lines 3 to 10 pull in Vibium's classes to drive the browser, and JUnit to run the test.

### Setup and Teardown

The `beforeEach` method (lines 16 to 20) starts the browser and gets its first page (tab). The `afterEach` method
(lines 22 to 27) closes the browser.

### The Test

Lines 29 to 35 are the test itself.

The dropdown has a first option, "Please select an option", that is disabled. We find the options by their role and
text (`new SelectorOptions().role("option").text(...)`), one of Vibium's semantic locators. Then `isEnabled` tells us
if each option can be selected: the first one can't, and "Option 1" can.
