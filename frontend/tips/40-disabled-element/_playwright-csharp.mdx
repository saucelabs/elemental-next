## Code Walkthrough

### The Test

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 11 to 18 are
the test. The dropdown on the page starts with a "Please select an option" placeholder that we can't select, because
it's disabled.

We find each option by its text (`HasText`) and check its state: `ToBeDisabledAsync` for the placeholder and
`ToBeEnabledAsync` for "Option 1". Both checks wait until the element is in that state, or fail after the timeout.

When we try to select a disabled option with `SelectOptionAsync`, Playwright fails too, so this check tells us early
why.
