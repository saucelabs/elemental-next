## Code Walkthrough

### The Test

Lines 3 to 8 are the test. The dropdown on the page starts with a "Please select an option" placeholder that we
can't select, because it's disabled.

We find each option by its text (`hasText`) and check its state: `toBeDisabled` for the placeholder and `toBeEnabled`
for "Option 1". Both checks wait until the element is in that state, or fail after the timeout.

When we try to select a disabled option with `selectOption`, Playwright fails too, so this check tells us early why.
