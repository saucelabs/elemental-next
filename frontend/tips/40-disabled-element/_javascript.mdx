### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Test

`option` finds all the `option` elements (`findElements`, plural) and returns the first one with the text we are
looking for. Getting the text of each element is asynchronous, so we use a `for...of` loop with `await`.

The test visits the page and asserts that the `Please select an option` item is not enabled (`isEnabled()` resolves
to `false`), and that `Option 1` is.
