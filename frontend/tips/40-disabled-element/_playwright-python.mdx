## Code Walkthrough

### The Test

Lines 4 to 8 are the test. The dropdown on the page starts with a "Please select an option" placeholder that we
can't select, because it's disabled.

We find each option by its text (`has_text`) and check its state: `to_be_disabled` for the placeholder and
`to_be_enabled` for "Option 1". Both checks wait until the element is in that state, or fail after the timeout.

When we try to select a disabled option with `select_option`, Playwright fails too, so this check tells us early why.
