## Code Walkthrough

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 12 to 19 are the test. The dropdown
on the page starts with a "Please select an option" placeholder that we can't select, because it's disabled.

We find each option by its text (`setHasText`) and check its state: `isDisabled` for the placeholder and `isEnabled` for
"Option 1". Both checks wait until the element is in that state, or fail after the timeout.

When we try to select a disabled option with `selectOption`, Playwright fails too, so this check tells us early why.
