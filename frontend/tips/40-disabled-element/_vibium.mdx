## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Test

Lines 17 to 22 are the test itself.

The dropdown has a first option, "Please select an option", that is disabled. We find the options by their role and
text (`{role: 'option', text: ...}`), one of Vibium's semantic locators. Then `isEnabled` tells us if each option
can be selected: the first one can't, and "Option 1" can.
