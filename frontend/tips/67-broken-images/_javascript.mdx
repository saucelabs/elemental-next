## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox, loads the page, and finds all the images on it. The `afterEach` hook quits
the browser.

### With an HTTP Library

The first test gets the full URL of each image (`getAttribute("src")`), and requests it with `fetch`. It collects the URLs that don't
return a `200`, and asserts that they are the two broken images.

### With JavaScript

The second test runs a small script for each image (`driver.executeScript`, passing the image as an argument). It returns `true`
when the image finished loading (`complete`) and has a width (`naturalWidth > 0`). It collects the images where it
returns `false`, and asserts that their `src` are the two broken images.
