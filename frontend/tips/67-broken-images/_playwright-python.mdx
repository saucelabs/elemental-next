## Code Walkthrough

### The Tests

Both tests visit a page with three images, two of them broken (the fixture on lines 5 to 7).

#### With an HTTP Request

Lines 10 to 18 read the full URL (`src`) of every image, and request each one with `page.request`, the HTTP client of
Playwright. An image whose request doesn't answer with `200` is broken.

#### With JavaScript

Lines 21 to 26 ask the browser instead. `evaluate_all` runs a function on all the images in the page. An image that
loaded is `complete` and has a width (`naturalWidth`), so the function keeps the others and returns their `src`.

This way is faster, since the browser already tried to load the images.
