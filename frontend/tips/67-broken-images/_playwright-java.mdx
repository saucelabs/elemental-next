## Code Walkthrough

### The Tests

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Both tests visit a page with three images,
two of them broken (the `@BeforeEach` method on lines 16 to 19).

#### With an HTTP Request

Lines 21 to 37 read the full URL (`src`) of every image, and request each one with `page.request()`, the HTTP client of
Playwright. An image whose request doesn't answer with `200` is broken.

`evaluateAll` returns a plain `Object`, so we cast it to a list of strings. `@SuppressWarnings("unchecked")` tells the
compiler that we know the cast can't be checked.

#### With JavaScript

Lines 39 to 48 ask the browser instead. `evaluateAll` runs a function on all the images in the page. An image that
loaded is `complete` and has a width (`naturalWidth`), so the function keeps the others and returns their `src`. This
way is faster, since the browser already tried to load the images.
