## Code Walkthrough

### Setup

The `beforeEach` hook (lines 4 to 6) visits a page with three images. Two of them are broken.

### Example 1: With an HTTP Library

Lines 8 to 19 collect the full URL of every image (the `src` property) and request each one with `fetch`, which comes
with Node.js. An image that doesn't answer with status `200` is broken. We print the broken ones and check their file
names.

This approach works for any image, but it requests every image a second time.

### Example 2: With JavaScript

Lines 21 to 31 ask the browser instead. For each image, `browser.execute` runs a function in the page that checks
whether the image finished loading (`complete`) and has a width (`naturalWidth > 0`). A broken image has a width of
`0`. We collect the `src` attribute of the broken ones and check them.

This approach uses what the browser already loaded, so it doesn't send any extra requests.
