### Example 1: With an HTTP Library

images are `asdf.jpg` and `hjkl.jpg`.

### Example 2: With JavaScript

The browser already knows which images failed to load. The script in lines 21 and 22 returns `true` when an image has
loaded (`complete`) and has a width (`naturalWidth > 0`).

Lines 48 to 55 run it on each image with `executeJavaScript`, keep the ones that didn't load, and check their
`src`. This way, we don't need an extra request per image.
