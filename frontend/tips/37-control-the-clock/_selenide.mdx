## Code Walkthrough

### Importing Libraries

Lines 3 to 17 pull in Selenide, JUnit, and Selenium's BiDi `Script` module. Selenide drives the browser with Selenium,
so the test can use it.

### The Fake Clock

Lines 21 to 35 are the fake clock, a JavaScript function that runs in the page. It replaces `setTimeout` with a function
that only keeps the callback and the time it is due, and adds a `fakeClock` object to the page. `fakeClock.tick`
moves the time forward, and runs the callbacks that are due.

### Setup and Teardown

The `setUp` method (lines 38 to 44) turns on WebDriver BiDi with `enableBiDi()` in the browser capabilities, starts
the browser with `open()`, and creates the `Script` module for Selenide's driver (`getWebDriver()`). The `tearDown`
method (lines 46 to 50) closes the module and the browser.

### The Test

Lines 52 to 65 are the test itself. `addPreloadScript` adds the fake clock as a preload script: the browser runs it in
every page, before the page's own scripts.

Then the test loads the page and clicks the button. The toast shows up with its message. The page asked
`setTimeout` to hide it in one minute, but the fake `setTimeout` only keeps the callback.

The test moves the clock forward 59 seconds with `fakeClock.tick(59000)`, run in the page with `executeJavaScript`. The
toast is still there. One more second (`fakeClock.tick(1000)`) makes the callback due, it runs, and the toast is
gone. `shouldHave` checks the message and the number of toasts.
