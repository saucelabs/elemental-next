## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in the libraries we need: Playwright's MSTest integration and MSTest itself.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends. There is no
setup or teardown code to write.

### The Test

Lines 10 to 25 are the test itself.

First, `Page.Clock.InstallAsync()` replaces the timers of the page with fake ones. They don't move on their own. Then
the test loads the page and clicks the button, and the toast shows up with its message.

`Page.Clock.RunForAsync(59000)` moves the clock forward 59 seconds, and runs what was due (nothing yet): the toast is
still there. One more second runs the callback that hides the toast, and it's gone. `ToHaveCountAsync(0)` checks that
there are no toasts.
