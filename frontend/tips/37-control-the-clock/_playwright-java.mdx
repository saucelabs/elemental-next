## Code Walkthrough

### Importing Libraries

Lines 3 to 7 pull in Playwright's assertions, `Page` and JUnit extension, and JUnit's `@Test`.

### Setup and Teardown

Line 9 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### The Test

Lines 12 to 26 are the test itself.

First, `page.clock().install()` replaces the timers of the page with fake ones. They don't move on their own. Then the
test loads the page and clicks the button, and the toast shows up with its message.

`page.clock().runFor(59000)` moves the clock forward 59 seconds, and runs what was due (nothing yet): the toast is
still there. One more second runs the callback that hides the toast, and it's gone. `hasCount(0)` checks that there
are no toasts.
