## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in `assert`, Selenium, and Selenium's BiDi `Script` module.

### The Fake Clock

Lines 7 to 20 are the fake clock, a JavaScript function that runs in the page. It replaces `setTimeout` with a function
that only keeps the callback and the time it is due, and adds a `fakeClock` object to the page. `fakeClock.tick`
moves the time forward, and runs the callbacks that are due.

### Setup and Teardown

The `beforeEach` method (lines 25 to 29) turns on WebDriver BiDi with `enableBidi()` and starts Chrome. The
`afterEach` method (lines 31 to 35) quits the browser.

### The Test

Lines 37 to 50 are the test itself. `addPreloadScript` adds the fake clock as a preload script: the browser runs it in
every page, before the page's own scripts.

Then the test loads the page and clicks the button. The toast shows up with its message. The page asked
`setTimeout` to hide it in one minute, but the fake `setTimeout` only keeps the callback.

The test moves the clock forward 59 seconds with `fakeClock.tick(59000)`, run in the page with `executeScript`. The
toast is still there. One more second (`fakeClock.tick(1000)`) makes the callback due, it runs, and the toast is
gone.
