## Code Walkthrough

### Importing Libraries

Line 1 pulls in Playwright's `Page` and `expect`.

### Setup and Teardown

The `pytest-playwright` plugin handles the browser for us. Each test that takes a `page` argument receives a fresh
browser tab, and the plugin closes it when the test ends. There is no setup or teardown code to write.

### The Test

Lines 4 to 16 are the test itself.

First, `page.clock.install()` replaces the timers of the page with fake ones. They don't move on their own. Then the
test loads the page and clicks the button, and the toast shows up with its message.

`page.clock.run_for(59000)` moves the clock forward 59 seconds, and runs what was due (nothing yet): the toast is
still there. One more second runs the callback that hides the toast, and it's gone. `to_have_count(0)` checks that
there are no toasts.
