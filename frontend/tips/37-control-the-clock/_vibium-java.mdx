## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Vibium (`Browser`, `Page` and `Vibium`) and JUnit.

### Setup and Teardown

Line 13 is the script that counts the toasts in the page. Lines 14 and 15 declare the browser and the page, so every
method of the class can use them.

The `beforeEach` method (lines 17 to 21) runs before each test. It starts the browser with `Vibium.start()` and gets
its first page (tab) with `browser.page()`. The `afterEach` method (lines 23 to 28) runs after each test and closes the
browser with `browser.stop()`.

### The Test

Lines 30 to 44 are the test itself.

First, `page.clock().install()` replaces the timers of the page with fake ones. They don't move on their own. Then the
test loads the page and clicks the button, and the toast shows up with its message.

`page.clock().runFor(59000)` moves the clock forward 59 seconds, and runs what was due (nothing yet): the toast is
still there. One more second runs the callback that hides the toast, and it's gone. The test counts the toasts by
running the script of line 13 in the page with `evaluate`.
