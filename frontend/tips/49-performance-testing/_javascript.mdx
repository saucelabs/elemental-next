## Code Walkthrough

### The Timings Script

`TIMINGS` (lines 4 to 12) is the JavaScript the test runs in the page. It reads the navigation entry of the
[Navigation Timing API](https://developer.mozilla.org/en-US/docs/Web/API/Performance_API/Navigation_timing), and
returns three of its values, in milliseconds since the navigation started: when the first byte of the page arrived
(`responseStart`), when the HTML was parsed (`domContentLoadedEventEnd`), and when the page and its images, styles
and scripts finished loading (`loadEventEnd`). `LOAD_BUDGET_MS` (line 13) is our budget for the load: 10 seconds.

### Setup and Teardown

The `beforeEach` hook (lines 18 to 20) starts Chrome, and the `afterEach` hook (lines 22 to 26) quits it.

### The Test

The test (lines 28 to 35) loads the page, runs the script with `executeScript`, and prints the three values. Then it
checks that the load is within the budget. The load is 0 while the page is still loading, so the test also checks
that it is greater than 0.
