## Code Walkthrough

### The Timings Script

`TIMINGS` (lines 5 to 13) is the JavaScript the test runs in the page. It reads the navigation entry of the
[Navigation Timing API](https://developer.mozilla.org/en-US/docs/Web/API/Performance_API/Navigation_timing), and
returns three of its values, in milliseconds since the navigation started: when the first byte of the page arrived
(`responseStart`), when the HTML was parsed (`domContentLoadedEventEnd`), and when the page and its images, styles
and scripts finished loading (`loadEventEnd`). `LOAD_BUDGET_MS` (line 14) is our budget for the load: 10 seconds.

### Setup and Teardown

The `setup` method (lines 16 to 18) starts Chrome, the `teardown` method (lines 20 to 22) quits it, and `run` (lines
24 to 29) calls them around the test.

### The Test

The test (lines 31 to 39) loads the page, runs the script with `execute_script`, and prints the three values. Then it
checks that the load is within the budget. The load is 0 while the page is still loading, so the test also checks
that it is greater than 0.
