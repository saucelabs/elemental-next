## Code Walkthrough

### Setup and Teardown

The `beforeEach` method (lines 22 to 29) turns on WebDriver BiDi with `enableBiDi`, starts Chrome, and creates a
`Network` object to work with the requests of the browser. The `afterEach` method (lines 31 to 39) closes it and
quits the browser.

### The Test

`slowRequestIsBlocked` (lines 41 to 59) first tells the browser to hold the requests to the URL of the slow request
(`addIntercept`, lines 44 and 45). Then it listens to the requests the browser sends (`onBeforeRequestSent`, lines 46
to 51). A held request comes with `isBlocked()` set to `true`: the test keeps its URL in a list and fails it, so the
browser never waits for it. Requests to other URLs load as usual.

Then the test loads the page and waits up to 5 seconds until jQuery has no requests running (`jQuery.active` is 0).
The slow request takes 30 seconds, so the wait passes only when the request is blocked. At the end, the test checks
that the slow request was blocked.
