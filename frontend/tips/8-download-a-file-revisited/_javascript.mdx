## Code Walkthrough

### Importing Libraries

We pull in `assert` for our assertions and the classes to drive the browser with Selenium
(`const {Builder, By} = require("selenium-webdriver");`). For the HTTP request we use `fetch`, which is built into
Node.js.

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Test

The test visits the page and grabs the `href` of the first download link (`.example a`).

Then it sends a `HEAD` request for that URL (`fetch(link, {method: "HEAD"})`). From the response we read the
`content-disposition` and `content-length` headers, and assert that the server sends the file as a download
(`attachment`) and that it is not empty.
