## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in `urllib` (from the Python standard library) to send the HTTP request, `pytest` to run the test,
and Vibium's `browser` to drive the browser.

### Setup and Teardown

Lines 7 to 11 are a pytest fixture that starts the browser, gives the test its first page (tab), and closes the
browser after the test.

### The Test

Lines 14 to 24 are the test itself.

After visiting the page, we get the `href` of the first download link. It is a relative URL, so we turn it into a full
URL with `urljoin`, using the URL of the page.

Then we send a `HEAD` request for the file with `urllib`. It returns the headers of the file without downloading it.

Finally, we check two headers. `Content-Disposition` starts with `attachment`, which means the server sends the file
as a download. `Content-Length` tells us the file is not empty.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
