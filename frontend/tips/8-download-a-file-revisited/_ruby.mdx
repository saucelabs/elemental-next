## Code Walkthrough

### Importing Libraries

We pull in `selenium-webdriver` to drive the browser, `rspec/expectations` & `RSpec::Matchers` for our
assertions, and `net/http`, the HTTP library from the Ruby standard library.

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before the test and quit it afterward.

### The Test

The test visits the page and grabs the `href` of the first download link (`.example a`).

Then it opens a connection to the host and sends a `HEAD` request for the file (`http.head(uri.path)`). From the
response we read the `Content-Type` and `Content-Length` headers, and assert that the file is the correct type
and not empty.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the `Gemfile` file.
