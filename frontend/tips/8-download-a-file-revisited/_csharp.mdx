## Code Walkthrough

### Importing Libraries

We pull in an HTTP client (`using System.Net.Http;`), our testing framework
(`using Microsoft.VisualStudio.TestTools.UnitTesting;`), driving the browser with Selenium (`using OpenQA.Selenium;`),
and launching an instance of Firefox (`using OpenQA.Selenium.Firefox;`).

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Test

The test visits the page and grabs the full URL of the first download link (`GetDomProperty("href")`).

Then it sends a `HEAD` request for that URL with `HttpClient` (`new HttpRequestMessage(HttpMethod.Head, link)`).
From the response we read the content disposition and content length headers, and assert that the server sends the
file as a download (`attachment`) and that it is not empty.
