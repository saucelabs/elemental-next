## Code Walkthrough

### Importing Libraries

Lines 1 to 5 pull in `System` to build the URL of the file, Playwright, its MSTest integration, and MSTest itself.

### Setup and Teardown

Lines 9 and 10 declare the test class. It extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package.
`PageTest` handles the browser for us: each test gets a fresh browser tab in the `Page` property, and it is closed when
the test ends. There is no setup or teardown code to write.

### The Test

Lines 12 to 22 are the test itself.

After visiting the page, we get the `href` of the first download link. It is a relative URL, so we turn it into a full
URL with `Uri` and the URL of the page.

Playwright comes with an HTTP client, `Page.APIRequest`, so we don't need another library. We send a `HEAD` request
for the file. It returns the headers of the file without downloading it. It also uses the cookies of the browser,
which helps when the file needs a session.

Finally, we check two headers. `content-disposition` starts with `attachment`, which means the server sends the file
as a download. `content-length` tells us the file is not empty.
