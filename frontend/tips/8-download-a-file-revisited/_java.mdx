## Code Walkthrough

### Importing Libraries

We import the HTTP client that comes with Java (e.g., `java.net.http.HttpClient`), annotations and assertions from
JUnit (e.g., `org.junit.jupiter.api.Test`), and the classes to drive the browser with Selenium
(e.g., `org.openqa.selenium.WebDriver`).

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Test

The test visits the page and grabs the `href` of the first download link. Since the attribute holds a relative
link, we resolve it against the current URL to get the full URL of the file.

Then it sends a `HEAD` request for that URL (`.method("HEAD", HttpRequest.BodyPublishers.noBody())`). From the
response we read the `Content-Disposition` and `Content-Length` headers, and assert that the server sends the file
as a download (`attachment`) and that it is not empty.
