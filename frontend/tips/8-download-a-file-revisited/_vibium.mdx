## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Test

Lines 17 to 27 are the test itself.

After visiting the page, we get the `href` of the first download link. It is a relative URL, so we turn it into a full
URL using the URL of the page.

Then we send a `HEAD` request for the file with `fetch`, which comes with Node.js. It returns the headers of the file
without downloading it.

Finally, we check two headers. `content-disposition` starts with `attachment`, which means the server sends the file
as a download. `content-length` tells us the file is not empty.
