## Code Walkthrough

### Importing Libraries

We pull in an HTTP library from the standard library (`import urllib.request`), our testing framework
(`import pytest`), driving the browser with Selenium (`from selenium import webdriver`), and a locator strategy to
find the elements (`from selenium.webdriver.common.by import By`).

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Test

The test visits the page and grabs the `href` of the first download link (`.example a`).

Then it builds a `HEAD` request for that URL (`urllib.request.Request(download_link, method='HEAD')`) and sends it.
From the response we read the `Content-Disposition` and `Content-Length` headers, and assert that the server sends
the file as a download (`attachment`) and that it is not empty.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
