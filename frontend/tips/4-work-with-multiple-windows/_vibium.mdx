## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Test

Lines 17 to 27 are the test itself.

After visiting the page, we wrap `bro.onPopup` in a promise, and then click the link that opens a new window.
`onPopup` calls us back with the new window as a page object. We wait for it to load with `waitForLoad`.

In Vibium, each window is its own page object, so there is no switching. We can use both at any time, in any order.
This also avoids the problem of the Selenium examples, where the order of the window handles can change between
browsers.

Finally, we check the title of each window.
