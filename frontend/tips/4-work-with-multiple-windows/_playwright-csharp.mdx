## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the libraries we need: Playwright, its MSTest integration (`Microsoft.Playwright.MSTest`), and
MSTest itself.

### Setup and Teardown

Lines 8 and 9 declare the test class. It extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package.
`PageTest` handles the browser for us: each test gets a fresh browser tab in the `Page` property, and its browser
context (the browser session that holds all the tabs) in the `Context` property. They are closed when the test ends.
There is no setup or teardown code to write.

### The Test

Lines 11 to 23 are the test itself.

After visiting the page, we click the link that opens a new window inside `Context.RunAndWaitForPageAsync`. It runs
the click, waits for the new window to open, and returns it as a new `IPage`.

In Playwright, each window is its own page object, so there is no switching. We can use both at any time, in any
order. This also avoids the problem of the Selenium examples, where the order of the window handles can change between
browsers.

Finally, we check the title of each window. `ToHaveTitleAsync` waits for the new window to load.
