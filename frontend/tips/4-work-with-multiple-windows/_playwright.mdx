## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a browser tab) and its `context` (the
browser session that holds all the tabs). Playwright closes them when the test ends.

### The Test

Lines 3 to 12 are the test itself.

After visiting the page, we start waiting for a new `page` event on the context, and then click the link that opens a
new window. When the window opens, we get it as a new page object.

In Playwright, each window is its own page object, so there is no switching. We can use both at any time, in any
order. This also avoids the problem of the Selenium examples, where the order of the window handles can change between
browsers.

Finally, we check the title of each window. `toHaveTitle` waits for the new window to load.
