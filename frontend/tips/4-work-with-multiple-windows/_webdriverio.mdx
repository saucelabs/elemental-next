### The Test

Lines 4 to 13 are the test itself.

`browser.url` returns the browsing context of the page. After visiting the page, we click the link that opens a new
window.

Since WebdriverIO 10, `browser.browsingContexts()` lists every open tab and window as a browsing context. We wait
until the list has a window with the URL of the new page. Each browsing context works on its own window, so there is
no need to switch between them. This also avoids the problem of the Selenium examples, where the order of the window
handles can change between browsers.

Finally, we check the title of the first window and the heading of the new one. `toHaveText` waits for the new window
to load.
