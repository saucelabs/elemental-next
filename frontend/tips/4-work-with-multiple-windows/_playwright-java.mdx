## Code Walkthrough

### Importing Libraries

Lines 3 to 7 pull in Playwright's assertions, its `Page` class and JUnit extension, and JUnit to run the test.

### Setup and Teardown

Line 9 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### The Test

Lines 13 to 20 are the test itself.

After visiting the page, we click the link that opens a new window inside `waitForPage`. `page.context()` is the browser
context the tab belongs to. `waitForPage` runs the click, waits for the new window to open, and returns it as a `Page`.

Now we have both windows as objects (`page` and `newPage`), so there is no need to switch between them. We check the
title of each one.
