## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox and loads the
page, and the `TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Tests

`Texts` finds all the cells that match a locator (`FindElements`, plural) and returns their text. `Dues` removes the
`$` from it and converts it to a number (`double.Parse`, with `CultureInfo.InvariantCulture` so the decimal point is
always a `.`).

The number tests click the `Due` heading (once or twice), grab the values with `Dues`, and compare them to a sorted
copy (`OrderBy`, or `OrderByDescending` for descending order) with `CollectionAssert.AreEqual`. The text test does
the same with the `Email` column, using the text as is. The last test uses the semantic locators of the second table.

After the clicks, `WaitForSort` waits until the header has the class `headerSortDown` (ascending) or
`headerSortUp` (descending). The page sorts the table after the click, so reading the cells right away
could get them in the old order.
