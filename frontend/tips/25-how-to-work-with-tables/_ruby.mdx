## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox and loads the page, and the `teardown` method quits it. The `run` method wraps
each test with them.

### The Tests

`dues` finds all the cells that match a locator (`find_elements`, plural), removes the `$` from their text
(`.delete('$')`), and converts it to a number (`.to_f`).

The number tests click the `Due` heading (once or twice), grab the values with `dues`, and compare them to
`due_values.sort` (or `due_values.sort.reverse` for descending order). The text test does the same with the `Email`
column, using the text as is. The last test uses the semantic locators of the second table.
