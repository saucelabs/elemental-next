## Code Walkthrough

### Helpers

The `dues` function (lines 3 to 5) reads the text of the cells with `allTextContents`, removes the `$` and turns
each value into a number, so we can sort them.

### The Tests

All the tests visit the page with the tables first (lines 7 to 9). Clicking a column header sorts the table by that
column, and the header gets the class `headerSortDown` (ascending) or `headerSortUp` (descending).

- Lines 11 to 16 click the "Due" header of the first table once and check that the values are in ascending order.
  The table has no handy attributes, so we find the column by its position (`nth-of-type(4)`).
- Lines 18 to 24 click it twice to sort in descending order.
- Lines 26 to 31 sort the "Email" column, which holds text.
- Lines 33 to 38 do the same as the first test on the second table, which has a class on each cell (e.g., `.dues`),
  so the locators are easier to read.

`toContainClass` waits until the header has the class, which tells us the table is sorted before we read it.
