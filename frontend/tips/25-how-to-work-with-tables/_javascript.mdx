## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox and loads the page before each test, and the `afterEach` hook quits it.

### The Tests

`texts` finds all the cells that match a locator (`findElements`, plural) and returns their text. `dues` removes the
`$` from it and converts it to a number (`parseFloat`).

The number tests click the `Due` heading (once or twice), grab the values with `dues`, and compare them to a sorted
copy (`[...dueValues].sort((a, b) => a - b)`, or `b - a` for descending order). Note that JavaScript's `sort` compares
values as strings by default, so we pass it a function to compare numbers. The text test does the same with the
`Email` column, using the text as is. The last test uses the semantic locators of the second table.

After the clicks, `waitForSort` waits until the header has the class `headerSortDown` (ascending) or
`headerSortUp` (descending). The page sorts the table after the click, so reading the cells right away
could get them in the old order.
