## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance and loads the page before `yield`ing it to the test, and quits it
once the test is done.

### The Tests

`dues` finds all the cells that match a locator (`find_elements`, plural), removes the `$` from their text, and
converts it to a number (`float`).

The number tests click the `Due` heading (once or twice), grab the values with `dues`, and compare them to
`sorted(due_values)` (or `sorted(due_values, reverse=True)` for descending order). The text test does the same with
the `Email` column, using the text as is. The last test uses the semantic locators of the second table.

After the clicks, `wait_for_sort` waits until the header has the class `headerSortDown` (ascending) or
`headerSortUp` (descending). The page sorts the table after the click, so reading the cells right away
could get them in the old order.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
