## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox and loads the page before each test, and the `afterEach` method quits it.

### The Tests

`texts` finds all the cells that match a locator (`findElements`, plural) and returns their text. `dues` removes the
`$` from it and converts it to a number (`Double.parseDouble`).

The number tests click the `Due` heading (once or twice), grab the values with `dues`, and compare them to a sorted
copy (`stream().sorted()`, or `sorted(Comparator.reverseOrder())` for descending order). The text test does the same
with the `Email` column, using the text as is. The last test uses the semantic locators of the second table.
