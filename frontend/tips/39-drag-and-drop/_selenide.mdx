### Drag and Drop

The page uses HTML5 drag and drop, which the WebDriver Actions API doesn't trigger in every browser. That's why the
Selenium examples run a JavaScript snippet that sends the drag and drop events.

Selenide already does that for us. In line 14, `dragAndDrop(to("#column-b"))` sends the same events with JavaScript
(its default), so we don't need our own script.

### The Test

Lines 15 and 16 check that the columns swapped places: the first column now says `B`, and the second one says `A`.
