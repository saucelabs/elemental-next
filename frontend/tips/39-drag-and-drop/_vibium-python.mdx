### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the test, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 9) starts the browser, gives the test its first page (tab), and closes the browser after the
test.

### The Test

Lines 12 to 18 are the test itself.

The page has two columns, A and B, that use HTML5 drag and drop. Vibium's `drag_to` drags an element and drops it on
another one, and it works with HTML5 drag and drop. So there is no need for the JavaScript helper that some of the
Selenium examples use.

After dragging column A onto column B, we check that the columns swapped their text.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
