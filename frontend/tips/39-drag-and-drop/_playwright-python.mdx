## Code Walkthrough

### The Test

Lines 4 to 10 are the test. The page has two boxes, A and B, that we can swap with HTML5 drag and drop.

`drag_to` drags the first element and drops it on the second one. Playwright moves the mouse step by step, so the page
gets the drag and drop events it expects, and it works the same in Chromium, Firefox and WebKit.

After the drop, the boxes have switched places: the first one says `B` and the second one says `A`.
