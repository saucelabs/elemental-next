## Code Walkthrough

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 12 to 20 are the test. The page has
two boxes, A and B, that we can swap with HTML5 drag and drop.

`dragTo` drags the first element and drops it on the second one. Playwright moves the mouse step by step, so the page
gets the drag and drop events it expects, and it works the same in Chromium, Firefox and WebKit.

After the drop, the boxes have switched places: the first one says `B` and the second one says `A`.
