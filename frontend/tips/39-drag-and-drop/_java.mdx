### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Test

The test visits the page and reads `dnd.js`, which lives in `src/test/resources`, so it's on the test classpath
(`getClass().getResourceAsStream("/dnd.js")`). Then it casts the driver to `JavascriptExecutor` and executes the
script, followed by the call to `simulateDragDrop`. Finally, it asserts that the columns switched places.
