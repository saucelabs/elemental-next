## Code Walkthrough

### Setup and Teardown

The `driver` fixture (lines 8 to 15) turns on WebDriver BiDi with `enable_bidi`, and starts Chrome. It `yield`s the
driver to the test, and quits the browser when the test is done.

### The Test

`test_slow_request_is_blocked` (lines 18 to 31) adds a request handler for the URL of the slow request
(`add_request_handler`, line 25). The handler (lines 21 to 23) keeps the URL in a list and fails the request, so the
browser never waits for it. Requests to other URLs load as usual.

Then the test loads the page and waits up to 5 seconds until jQuery has no requests running (`jQuery.active` is 0).
The slow request takes 30 seconds, so the wait passes only when the request is blocked. At the end, the test checks
that the handler blocked the slow request.

`pip install -r requirements.txt` from the command-line.
