## Code Walkthrough

### Setup and Teardown

The `SetUp` method (lines 19 to 26) turns on WebDriver BiDi with `UseWebSocketUrl`, starts Chrome, and connects to
BiDi with `AsBiDiAsync`. The `TearDown` method (lines 28 to 36) closes the BiDi connection and quits the browser.

### The Test

`SlowRequestIsBlocked` (lines 38 to 59) first tells the browser to hold the requests to the URL of the slow request
(`AddInterceptAsync`, lines 42 and 43). Then it listens to the requests the browser sends (`BeforeRequestSent`, lines
44 to 51). A held request comes with `IsBlocked` set to `true`: the test keeps its URL in a list and fails it, so the
browser never waits for it. Requests to other URLs load as usual.

Then the test loads the page and waits up to 5 seconds until jQuery has no requests running (`jQuery.active` is 0).
The slow request takes 30 seconds, so the wait passes only when the request is blocked. At the end, the test checks
that the slow request was blocked.
