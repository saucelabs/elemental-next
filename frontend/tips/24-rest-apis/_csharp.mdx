## Code Walkthrough

### Setup and Teardown

The `SetUp` method (lines 22 to 30) creates the user with `HttpClient`. The name has a random part (`Guid`), so
tests that run at the same time don't share a user. `PostAsJsonAsync` sends the user name and the password as JSON.
It checks the `201`, and starts Chrome. The `TearDown` method (lines 32 to 37) quits the browser and deletes the
user, even when the test fails.

### The Tests

`LoggedInUser` (lines 39 to 44) waits until the secure area shows the user name, and returns it.

`LogInWithANewUser` (lines 46 to 54) opens the login page, types the user name and the password, submits the form, and checks the name in the
secure area.

`SkipTheLoginForm` (lines 56 to 69) posts the same JSON to `/api/sessions`, and takes the value of the
`rack.session` cookie from the `Set-Cookie` header. The browser accepts cookies only for the site it shows, so the test opens the login page first, adds the cookie, and
then opens the secure area directly.
