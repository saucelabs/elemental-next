## Code Walkthrough

### The Listener

In C#, the event firing driver (`EventFiringWebDriver`, from the `Selenium.Support` package) exposes .NET events for
each action (e.g., `Navigated`, `FindingElement`, `FindElementCompleted`, `ElementClicking`, and `ElementClicked`).
`Wrapper` subscribes to the ones we're interested in, and logs a message for each of them with `Log`, which writes it
to the console and keeps it in the `Messages` list.

The project references `Microsoft.Bcl.AsyncInterfaces` explicitly, since the event firing driver needs it and
doesn't bring it in on its own for `net10.0`.

### The Test

The `SetUp()` method (marked with `[TestInitialize]`) wraps a Firefox instance in an `EventFiringWebDriver` and
creates our listener with it. From then on, every action we perform through it raises the events.

The test visits the page, clicks the link, and asserts the messages the listener logged.
