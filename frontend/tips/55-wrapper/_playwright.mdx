## Code Walkthrough

### The Wrapper

`LoggingPage` (in `loggingPage.ts`) wraps a Playwright `page`. It has its own `goto` and `click` that do the same as
Playwright's, and log what they did:

- Lines 16 to 19 visit the URL and log it.
- Lines 21 to 30 log the text of the element, click it, and log the new URL if the click changed it.
  `waitForLoadState` waits for the new page to load before we read the URL.

Each message is printed and saved in `messages` (line 6), so the test can check them.

### The Test

The test creates the wrapper (line 5), visits the home page and clicks the Checkboxes link through it. Then it checks
the messages.

Playwright has its own record of every action: run the tests with `--trace on` and open the trace with
`npx playwright show-trace`. The wrapper is useful when we want our own messages.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the `package.json` file.
