## Code Walkthrough

### The Wrapper

`selenium-webdriver` for JavaScript doesn't come with an event listener, so `Wrapper` wraps the driver instead. It
has the same methods we use in our test (`get`, `findElement`, and `click` on the element it returns), and logs a
message before and after calling the real ones. `log` prints each message and keeps it in the `messages` list.

### The Test

The `beforeEach` hook wraps a Firefox instance in our `Wrapper`, and the `afterEach` hook quits it.

The test visits the page, clicks the link, and asserts the messages the wrapper logged.
