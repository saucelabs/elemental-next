## Code Walkthrough

### The Wrapper

<TipCode codePath={"55-wrapper/code/playwright-java/src/test/java/com/elemental/playwright/LoggingPage.java"} language={"java"}/>

`LoggingPage` wraps a Playwright page. It has its own `navigate` and `click` that do the same as Playwright's, and log
what they did:

- Lines 25 to 28 visit the URL and log it.
- Lines 30 to 39 log the text of the element, click it, and log the new URL if the click changed it. `waitForLoadState`
  waits for the new page to load before we read the URL.

Each message is printed and saved in `messages` (line 14), so the test can check them.

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. The test creates the wrapper with it,
visits the home page and clicks the Checkboxes link through it. Then it checks the messages.

Playwright has its own record of every action: the trace (`context.tracing()`), which we open with `playwright
show-trace`. The wrapper is useful when we want our own messages.
