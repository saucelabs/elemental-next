## Code Walkthrough

### The Listener

`Wrapper` implements `WebDriverListener` and overrides the hooks we're interested in: `afterGet`,
`beforeFindElement`, `afterFindElement`, `beforeClick`, and `afterClick`. Each of them receives the arguments of the
action (e.g., the URL, or the locator). They log a message with `log`, which prints it and keeps it in the
`messages` list. The click hooks only receive the element, so we keep the driver from `afterGet` to check the URL.

### The Test

The `beforeEach` method creates our listener and decorates a Firefox instance with it
(`new EventFiringDecorator<>(listener).decorate(...)`). From then on, every action we perform through the decorated
driver calls the listener's hooks.

The test visits the page, clicks the link, and asserts the messages the listener logged.
