## Code Walkthrough

### The Wrapper

Vibium doesn't have hooks to change its commands, so we wrap the page in a class of our own. The test uses the wrapper
instead of the page.

    <summary>Toggle to see the <code>LoggingPage.java</code> file.</summary>

- Lines 11 to 17 keep the Vibium page, and a list of the messages logged, so the test can check them.
- Lines 19 to 22 print a message and add it to the list.
- Lines 24 to 27 go to a URL and log it.
- Lines 29 to 39 log the text of the element before clicking it. After the click, they wait for the page to load, and
  log the new URL when it changed.

### The Test

The `beforeEach` method (lines 16 to 20) starts the browser and wraps its first page (tab). The `afterEach` method
(lines 22 to 27) closes the browser.

The test (lines 29 to 38) visits the home page and clicks the "Checkboxes" link. Then it checks the three messages the
wrapper logged.
