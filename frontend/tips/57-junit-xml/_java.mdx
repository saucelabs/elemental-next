## Code Walkthrough

### The Test

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it. `title` loads the
page and checks its title.

### The Report

There's nothing to configure: Maven Surefire, the plugin that runs the tests in `mvn test`, writes a JUnit XML report
for each test class in `target/surefire-reports` (e.g., `TEST-com.elemental.selenium.TitleTest.xml`).
