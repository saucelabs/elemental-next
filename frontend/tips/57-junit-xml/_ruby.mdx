## Code Walkthrough

### The Test

In RSpec, test files are referred to as 'specs'. The setup and teardown live in `spec/spec_helper.rb`: before each
spec it launches Firefox, and after each spec it quits it. The spec loads the page and checks its title.

### The Report

The `rspec_junit_formatter` gem (in the `Gemfile`) adds the `RspecJunitFormatter` formatter to RSpec. Rather than
typing the options every time, we put them in the `.rspec` file, which RSpec reads on every run: it loads the spec
helper, prints the progress in the terminal (`--format progress`), and writes the JUnit XML report to `result.xml`
(`--format RspecJunitFormatter --out result.xml`). `run_specs.rb` runs `bundle exec rspec`.
