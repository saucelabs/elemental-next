## Code Walkthrough

### Saving the Results as JUnit XML

WebdriverIO creates reports with reporters, set in `wdio.conf.ts`. We use two: `spec` prints the results in the
terminal, and `junit` (the `@wdio/junit-reporter` package) saves them as JUnit XML, the format most CI servers read.

Lines 8 to 11 set the JUnit reporter. `outputDir` is the folder for the reports, and `outputFileFormat` names each
file. WebdriverIO writes one file per worker, so the name includes the worker id (`cid`), e.g.,
`reports/results-0-0.xml`.

### The Test

Lines 3 to 8 are a simple test that loads the page and checks its title. The reporter writes the results of every test
without any change to the tests.

After running `npm test`, the `reports` folder has the XML file. Point your CI server to it to see the results of each
test.
