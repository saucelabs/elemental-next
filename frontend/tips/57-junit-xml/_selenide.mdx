### The JUnit XML Report

We don't need any extra code or settings: Maven Surefire, which runs the tests, writes a JUnit XML report for each test
class in `target/surefire-reports` (e.g., `TEST-com.elemental.selenium.TitleTest.xml`). CI servers (Jenkins, GitHub
Actions, GitLab, ...) read these files to show the results of the tests.

When a Selenide check fails, the report has the error message of Selenide, with the paths of the screenshot and the
page source it saved.
