## Code Walkthrough

### The Test

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it. The test loads the page
and checks its title.

### The Report

Mocha comes with an `xunit` reporter, which writes the results in the XML format CI servers read. The `test` script
in `package.json` uses it (`--reporter xunit`) and writes the report to `result.xml`
(`--reporter-option output=result.xml`).
