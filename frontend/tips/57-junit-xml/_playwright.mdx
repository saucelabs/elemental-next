## Code Walkthrough

### The Report

Playwright Test comes with a JUnit reporter. In `playwright.config.ts` (line 5), we use two reporters: `list` prints
the results while the tests run, and `junit` saves them as XML in `reports/results.xml`. CI servers (e.g., Jenkins,
GitLab, GitHub Actions) can read this file to show the results.

### The Test

Lines 3 to 6 are the test. It visits the page and checks the title. Any test works: the reporter doesn't need
anything in the test.
