### The JUnit XML Report

Mocha has an `xunit` reporter, which saves the results in the JUnit XML format. The `test` script in
`package.json` uses it with `--reporter xunit`, and `--reporter-option output=result.xml` saves the report in the
`result.xml` file. CI servers (e.g., Jenkins) read this file to show the results.
