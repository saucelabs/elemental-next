## Code Walkthrough

### The Test

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.
`test_title` loads the page and checks its title.

### The Report

pytest writes a JUnit XML report when we pass `--junitxml` with the path of the file. Rather than typing it every
time, we add it to the default options in `pytest.ini` (`addopts = --junitxml=result.xml`), so every run writes the
report to `result.xml`.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
