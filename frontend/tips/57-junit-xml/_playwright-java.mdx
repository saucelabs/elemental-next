## Code Walkthrough

### The Report

Maven Surefire, the plugin that runs the tests, saves the results as JUnit XML on every run, with nothing to set. It
writes one file per test class in `target/surefire-reports` (e.g., `TEST-com.elemental.playwright.TitleTest.xml`). CI
servers (e.g., Jenkins, GitLab, GitHub Actions) can read these files to show the results.

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 12 to 16 are the test. It visits the
page and checks the title. Any test works: the report doesn't need anything in the test.
