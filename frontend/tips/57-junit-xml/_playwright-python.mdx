## Code Walkthrough

### The Report

pytest can save the results as JUnit XML, with no plugin. In `pytest.ini`, `--junitxml` saves them in
`reports/results.xml`. CI servers (e.g., Jenkins, GitLab, GitHub Actions) can read this file to show the results.

<TipCode codePath={"57-junit-xml/code/playwright-python/pytest.ini"} language={"ini"}/>

### The Test

Lines 4 to 6 are the test. It visits the page and checks the title. Any test works: the report doesn't need anything
in the test.

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
