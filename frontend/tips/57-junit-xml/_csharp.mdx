## Code Walkthrough

### The Test

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it. `Title` loads the page and checks its title.

### The Report

The `JunitXml.TestLogger` package adds a `junit` logger to `dotnet test`. We could enable it from the command-line
(`dotnet test --logger junit`), but to get the report on every run we enable it in `junit.runsettings`, with the path
of the report (`TestResults/result.xml`). The project file points to it with `RunSettingsFilePath`.
