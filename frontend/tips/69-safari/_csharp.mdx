## Code Walkthrough

### macOS Only

Safari runs on macOS only, so `[OSCondition(OperatingSystems.OSX)]` (lines 7 to 9) skips the test on Windows and
Linux.

### Setup and Teardown

The `SetUp` method (lines 14 to 18) starts Safari with `new SafariDriver()`. Selenium finds `safaridriver`, which
comes with macOS, so there is nothing to download. The `TearDown` method (lines 20 to 24) quits the browser.

### The Test

`PageLoaded` (lines 26 to 34) loads the page, prints the name and version of the browser from the capabilities of the
session, and checks the title of the page.
