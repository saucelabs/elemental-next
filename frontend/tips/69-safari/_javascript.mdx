## Code Walkthrough

### macOS Only

Safari runs on macOS only, so the `before` hook (lines 7 to 12) skips the test on Windows and Linux.

### Setup and Teardown

The `beforeEach` hook (lines 14 to 16) starts Safari with `forBrowser("safari")`. Selenium finds `safaridriver`,
which comes with macOS, so there is nothing to download. The `afterEach` hook (lines 18 to 22) quits the browser.

### The Test

The test (lines 24 to 30) loads the page, prints the name and version of the browser from the capabilities of the
session, and checks the title of the page.
