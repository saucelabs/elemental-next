## Code Walkthrough

### macOS Only

Safari runs on macOS only, so lines 5 to 9 skip the test on Windows and Linux.

### Setup and Teardown

The `setup` method (lines 11 to 13) starts Safari with `Selenium::WebDriver.for :safari`. Selenium finds
`safaridriver`, which comes with macOS, so there is nothing to download. The `teardown` method (lines 15 to 17) quits
the browser, and `run` (lines 19 to 24) calls them around the test.

### The Test

The test (lines 26 to 32) loads the page, prints the name and version of the browser from the capabilities of the
session, and checks the title of the page.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `Gemfile`.
