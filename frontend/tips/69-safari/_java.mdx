## Code Walkthrough

### macOS Only

Safari runs on macOS only, so `@EnabledOnOs(OS.MAC)` (lines 12 and 13) skips the test on Windows and Linux.

### Setup and Teardown

The `beforeEach` method (lines 17 to 20) starts Safari with `new SafariDriver()`. Selenium finds `safaridriver`,
which comes with macOS, so there is nothing to download. The `afterEach` method (lines 22 to 27) quits the browser.

### The Test

`pageLoaded` (lines 29 to 36) loads the page, prints the name and version of the browser from the capabilities of the
session, and checks the title of the page.
