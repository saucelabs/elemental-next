## Code Walkthrough

### Setup

The `beforeEach` hook (lines 4 to 10) logs in and waits for the success message. After logging in, the login form
(`#login`) is no longer on the page.

### Example 1: Acting on a Missing Element

Lines 12 to 14 try to click the login form. WebdriverIO waits for the element to show up (5 seconds by default, the
`waitforTimeout` setting), and then throws an error that says the element wasn't found. `rejects.toThrow` checks that
the click fails with that error.

### Example 2: Checking That an Element Is Not Displayed

Lines 16 to 18 check that the login form is not displayed. In WebdriverIO, `isDisplayed` returns `false` when the
element doesn't exist, instead of throwing an error. So we don't need to catch an exception to check that something is
gone, like we do in the Selenium examples.
