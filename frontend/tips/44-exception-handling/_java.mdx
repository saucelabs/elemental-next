## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox, logs in, and waits for the success message. The `afterEach` method quits
the browser.

### The Helper

`isDisplayed` tries to find the element and return whether it's displayed. If Selenium throws a
`NoSuchElementException` or a `StaleElementReferenceException`, it catches it (in a multi-catch block) and returns
`false`.

### The Tests

`lookingForAMissingElementThrowsAnException` shows the problem: it uses `Assertions.assertThrows` to assert that
looking for the login form throws a `NoSuchElementException`.

`loginFormIsNotDisplayed` uses the helper instead, and asserts that the login form is not displayed.
