## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) launches Firefox, logs in, and waits for the success message.
The `TearDown()` method (marked with `[TestCleanup]`) closes the browser.

### The Helper

`IsDisplayed` tries to find the element and return whether it's displayed. If Selenium throws a
`NoSuchElementException` or a `StaleElementReferenceException`, it catches it (with an exception filter, `when`) and
returns `false`.

### The Tests

`LookingForAMissingElementThrowsAnException` shows the problem: it uses `Assert.ThrowsExactly` to assert that looking
for the login form throws a `NoSuchElementException`.

`LoginFormIsNotDisplayed` uses the helper instead, and asserts that the login form is not displayed.
