## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox, logs in, and waits for the success message. The `teardown` method quits the
browser. The `run` method wraps each test with them.

### The Helpers

`rescue_exceptions` runs the block it receives, and rescues the `NoSuchElementError` and
`StaleElementReferenceError` errors, returning `false` when one of them happens. `displayed?` uses it to check whether
an element is displayed.

### The Tests

The first test shows the problem: it asserts that looking for the login form raises a `NoSuchElementError`
(`raise_error`).

The second test uses the helper instead, and asserts that the login form is not displayed.
