## Code Walkthrough

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 12 to 35 are the test. We add a
small notification library (jQuery Growl) to the page and use it to show a message, which is handy to follow what a test
does while it runs.

1. Lines 16 to 20 add jQuery, if the page doesn't have it. `addScriptTag` adds a `<script>` tag and waits until the
   script is loaded, so we don't need to wait for it ourselves.
2. Lines 22 to 24 add jquery-growl the same way.
3. Lines 26 to 28 add its styles with `addStyleTag`.
4. Line 31 shows a message with `page.evaluate`, which runs the function in the page.

Lines 33 and 34 check the title and the message of the notification.
