## Code Walkthrough

### The Test

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 11 to 42 are
the test. We add a small notification library (jQuery Growl) to the page and use it to show a message, which is handy to
follow what a test does while it runs.

1. Lines 16 to 23 add jQuery, if the page doesn't have it. `AddScriptTagAsync` adds a `<script>` tag and waits until
   the script is loaded, so we don't need to wait for it ourselves.
2. Lines 25 to 29 add jquery-growl the same way.
3. Lines 31 to 35 add its styles with `AddStyleTagAsync`.
4. Line 38 shows a message with `Page.EvaluateAsync`, which runs the function in the page.

Lines 40 and 41 check the title and the message of the notification.
