## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Test

The test loads the page and runs the four steps with `driver.executeScript`. After adding jQuery, it waits until
`window.jQuery` is defined, and after adding jQuery Growl and its styles, it waits until `$.growl` is defined
(with `driver.wait` and a function that runs `return !!window.jQuery` in the browser). Then it displays the notification.

Finally, it waits for the notification (`#growls .growl`) to be displayed, and checks its title (`.growl-title`) and
message (`.growl-message`).
