## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Test

The test loads the page and runs the four steps with `driver.execute_script`. After adding jQuery, it waits until
`window.jQuery` is defined, and after adding jQuery Growl and its styles, it waits until `$.growl` is defined
(with a `WebDriverWait` and a lambda that runs `return !!window.jQuery` in the browser). Then it displays the notification.

Finally, it waits for the notification (`#growls .growl`) to be displayed, and checks its title (`.growl-title`) and
message (`.growl-message`).

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
