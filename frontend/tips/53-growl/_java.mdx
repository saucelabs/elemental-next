## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox and casts the driver to `JavascriptExecutor`, and the `afterEach` method
quits it.

### The Test

The test loads the page and runs the four steps with `js.executeScript`. After adding jQuery, it waits until
`window.jQuery` is defined, and after adding jQuery Growl and its styles, it waits until `$.growl` is defined
(with a `WebDriverWait` and a lambda that runs `return !!window.jQuery` in the browser). Then it displays the notification.

Finally, it waits for the notification (`#growls .growl`) to be displayed, and checks its title (`.growl-title`) and
message (`.growl-message`).
