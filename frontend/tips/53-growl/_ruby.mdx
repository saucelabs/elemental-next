## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before the test and quit it afterward. `wait_for` wraps an
explicit wait, running the block we give it until it returns something truthy.

### The Test

The test loads the page and runs the four steps with `@driver.execute_script`. After adding jQuery, it waits until
`window.jQuery` is defined, and after adding jQuery Growl and its styles, it waits until `$.growl` is defined
(with `wait_for` and a block that runs `return !!window.jQuery` in the browser). Then it displays the notification.

Finally, it waits for the notification (`#growls .growl`) to be displayed, and checks its title (`.growl-title`) and
message (`.growl-message`).
