## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Vibium's classes to drive the browser, and JUnit to run the test.

### Setup and Teardown

The `beforeEach` method (lines 16 to 20) starts the browser and gets its first page (tab).
`new StartOptions().headless(true)` runs Chrome without a window. The `afterEach` method (lines 22 to 27) closes the
browser.

### The Test

Lines 29 to 37 visit the page and check its title, as with a browser that has a window.

To check that Chrome runs headless, we read the user agent of the browser with `page.evaluate`. Headless Chrome says
`HeadlessChrome` in it.
