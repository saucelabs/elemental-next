## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). `headless: true` runs Chrome
without a window. The `afterEach` method (lines 13 to 15) closes the browser.

### The Test

Lines 17 to 24 visit the page and check its title, as with a browser that has a window.

To check that Chrome runs headless, we read the user agent of the browser with `page.evaluate`. Headless Chrome says
`HeadlessChrome` in it.
