## Code Walkthrough

### Running Chrome Headless

Headless is a browser setting, so in WebdriverIO it goes in the capabilities of `wdio.conf.ts`. The `--headless`
argument in `goog:chromeOptions` starts Chrome without a window, so the tests run on a machine without a display
(e.g., a CI server), with no extra tools like Xvfb.

### The Test

Lines 4 to 11 load the page and check its title, like any other test. To show that Chrome runs headless, we read the
user agent of the browser with `browser.execute`, print it, and check that it says `HeadlessChrome`.
