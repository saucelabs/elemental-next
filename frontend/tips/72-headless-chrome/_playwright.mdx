## Code Walkthrough

### Running Headless

Playwright runs the browsers headless (without a window) by default. In `playwright.config.ts`, `headless: true`
(line 6) only makes it visible. To see the browser, run `npx playwright test --headed`.

For Chromium, Playwright uses a headless build of the browser (`chromium-headless-shell`), which starts faster.

### The Test

Lines 3 to 10 are the test. It visits the page, checks the title, and reads the user agent with `page.evaluate`. A
headless Chrome says `HeadlessChrome` in it.
