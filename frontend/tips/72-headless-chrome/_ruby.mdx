## Code Walkthrough

### Setup and Teardown

The `setup` method (lines 5 to 10) adds the `--headless` argument to the Chrome options, and starts Chrome with
them. The `teardown` method (lines 12 to 14) quits the browser, and `run` (lines 16 to 20) calls them around the
test.

### The Test

The test (lines 22 to 29) loads the page and checks its title, like any other test. Then it reads the user agent of
the browser with `execute_script`, prints it, and checks that it says `HeadlessChrome`.
