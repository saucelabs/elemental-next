## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook (lines 8 to 12) adds the `--headless` argument to the Chrome options, and starts Chrome with
them. The `afterEach` hook (lines 14 to 18) quits the browser.

### The Test

The test (lines 20 to 27) loads the page and checks its title, like any other test. Then it reads the user agent of
the browser with `executeScript`, prints it, and checks that it says `HeadlessChrome`.
