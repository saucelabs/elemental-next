## Code Walkthrough

### Running Headless

`@UsePlaywright` runs the browsers headless (without a window) by default, so there is nothing to set. To see the
browser, pass it a class that implements `OptionsFactory` and returns `new Options().setHeadless(false)`, like
`@UsePlaywright(HeadedOptions.class)`.

For Chromium, Playwright uses a headless build of the browser (`chromium-headless-shell`), which starts faster.

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 13 to 21 are the test. It visits the
page, checks the title, and reads the user agent with `page.evaluate`. A headless Chrome says `HeadlessChrome` in it.
