## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the test, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 9) starts the browser, gives the test its first page (tab), and closes the browser after the
test. `headless=True` runs Chrome without a window.

### The Test

Lines 12 to 18 visit the page and check its title, as with a browser that has a window.

To check that Chrome runs headless, we read the user agent of the browser with `page.evaluate`. Headless Chrome says
`HeadlessChrome` in it.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
