## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab), and Playwright closes
it when the test ends.

### The Test

Lines 3 to 9 are the test itself.

After visiting the page, we call `selectOption` on the dropdown. It takes the value, the label (the visible text) or
the index of the option. Here we use the label, `Option 1`.

To check the selection, we find the selected option with the `:checked` CSS pseudo-class and check its text.
`toHaveText` waits until it matches.
