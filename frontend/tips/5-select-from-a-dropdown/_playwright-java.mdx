## Code Walkthrough

### Importing Libraries

Lines 3 to 8 pull in Playwright's assertions, its `Page` class and JUnit extension, `SelectOption` to pick the option,
and JUnit to run the test.

### Setup and Teardown

Line 10 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### The Test

Lines 14 to 20 are the test itself.

After visiting the page, we call `selectOption` on the dropdown. `new SelectOption().setLabel("Option 1")` picks the
option by its visible text. It could also pick it by its value with `setValue`.

Then we check that the selected option (`option:checked`) is the one we chose.
