## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Vibium's classes to drive the browser, and JUnit to run the test.

### Setup and Teardown

Lines 13 and 14 declare the browser and the page. The `beforeEach` method (lines 16 to 20) starts the browser and
gets its first page (tab). The `afterEach` method (lines 22 to 27) closes the browser.

### The Test

Lines 29 to 36 are the test itself.

After visiting the page, we find the dropdown and pick an option by its text with `selectOption`. There is no need
to find the option first or to loop over the options.

Then we check that the selected option (`option:checked`) is the one we picked.
