## Code Walkthrough

### Importing Libraries

Lines 3 to 9 pull in Vibium's classes to drive the browser, and JUnit to run the test.

### Setup and Teardown

Lines 12 and 13 declare the browser and the page. The `beforeEach` method (lines 15 to 19) starts the browser and
gets its first page (tab). The `afterEach` method (lines 21 to 26) closes the browser.

### The Test

Lines 28 to 35 are the test itself.

After visiting the page, we find the dropdown and pick an option by its text with `selectOption`. There is no need
to find the option first or to loop over the options.

Then we check that the selected option (`option:checked`) is the one we picked.
