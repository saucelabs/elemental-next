## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the test, and Vibium's `browser` to drive the browser.

### Setup and Teardown

Lines 5 to 9 are a pytest fixture that starts the browser, gives the test its first page (tab), and closes the
browser after the test.

### The Test

Lines 12 to 17 are the test itself.

After visiting the page, we find the dropdown and pick an option by its text with `select_option`. There is no need
to find the option first or to loop over the options.

Then we check that the selected option (`option:checked`) is the one we picked.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
