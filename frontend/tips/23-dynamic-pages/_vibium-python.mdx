## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the tests, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 9) starts the browser, gives each test its first page (tab), and closes the browser after the
test.

### The Tests

Lines 12 to 18 run the test once for each example page (`pytest.mark.parametrize`). The first one has an element that
is hidden and shows up after loading. The second one adds the element to the page after loading.

Each test visits the page and clicks the start button. Then `wait_until('visible')` waits up to 10 seconds for the
`#finish` element to be visible, which works for both examples. Finally, we check that it is visible.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
