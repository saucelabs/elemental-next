## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Tests

Lines 17 to 25 create one test for each example page. The first one has an element that is hidden and shows up after
loading. The second one adds the element to the page after loading.

Each test visits the page and clicks the start button. Then `waitUntil('visible')` waits up to 10 seconds for the
`#finish` element to be visible, which works for both examples. Finally, we check that it is visible.
