## Code Walkthrough

### The Tests

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 12 and 13
run the test once for each of the two examples of the page, with a name for each (`DisplayName`):

- In example 1, the element is on the page but hidden, and it shows up after the loading bar.
- In example 2, the element is not on the page at all until the loading bar ends.

Each test clicks the start button and waits for the `#finish` element to be visible. `ToBeVisibleAsync` keeps checking
until the element shows up or the timeout ends (10 seconds here). So the same check works for both examples: a hidden
element and a missing one are both not visible.
