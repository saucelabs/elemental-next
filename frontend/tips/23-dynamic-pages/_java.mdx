## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Wait Helper

`waitFor` receives a condition (a function that receives the driver) and uses
`new WebDriverWait(driver, Duration.ofSeconds(10)).until(condition)`, which calls the condition repeatedly until it
returns `true`, or throws a `TimeoutException` when the time runs out. While waiting, it ignores the
`NoSuchElementException` thrown when the element is not on the page yet.

### The Test

`dynamicLoading` is a `@ParameterizedTest`, so it runs once for each example. It visits the page, clicks the start
button, waits for the finish element to be displayed (`d -> d.findElement(By.id("finish")).isDisplayed()`), and
asserts that it is.
