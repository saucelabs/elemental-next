## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Wait Helper

`waitForDisplayed` receives a locator and a timeout. It uses `driver.wait` with the built-in conditions from `until`:
first `until.elementLocated` waits for the element to be on the page (needed for the second example), and then
`until.elementIsVisible` waits for it to be displayed. If the time runs out, `driver.wait` throws a `TimeoutError`.

### The Test

We create one test (`it`) for each example with a `for` loop. Each test visits the page, clicks the start button,
waits for the finish element to be displayed, and asserts that it is.
