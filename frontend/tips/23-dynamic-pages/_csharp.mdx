## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Wait Helper

`WaitFor` receives a condition (a function that receives the driver) and a timeout. It uses
`new WebDriverWait(_driver, ...).Until(condition)`, which calls the condition repeatedly until it returns `true`, or
throws a `WebDriverTimeoutException` when the time runs out. While waiting, it ignores the `NoSuchElementException`
thrown when the element is not on the page yet.

### The Test

`DynamicLoading` runs once for each `[DataRow]`. It visits the page, clicks the start button, waits for the finish
element to be displayed (`d => d.FindElement(By.Id("finish")).Displayed`), and asserts that it is.
