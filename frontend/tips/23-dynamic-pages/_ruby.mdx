## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward.

### The Wait Helper

`wait_for` accepts a timeout and the action we want to wait for as a block. It uses
`Selenium::WebDriver::Wait.new(timeout: seconds).until { yield }`, which runs the block repeatedly until it returns
something truthy, or raises a `TimeoutError` when the time runs out. While waiting, it ignores the
`NoSuchElementError` raised when the element is not on the page yet.

### The Tests

Each `run` block visits one of the examples, clicks the start button, waits for the finish element to be displayed
(`wait_for { @driver.find_element(id: 'finish').displayed? }`), and asserts that it is.
