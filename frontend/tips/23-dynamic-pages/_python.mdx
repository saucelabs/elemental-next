## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Wait Helper

`wait_for` receives the driver, a condition (a function that receives the driver), and a timeout. It uses
`WebDriverWait(driver, seconds).until(condition)`, which calls the condition repeatedly until it returns something
truthy, or raises a `TimeoutException` when the time runs out. While waiting, it ignores the `NoSuchElementException`
raised when the element is not on the page yet.

### The Test

`test_dynamic_loading` is parametrized, so it runs once for each example. It visits the page, clicks the start
button, waits for the finish element to be displayed (`lambda d: d.find_element(By.ID, 'finish').is_displayed()`),
and asserts that it is.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
