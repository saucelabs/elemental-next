### Importing Libraries

Line 1 pulls in the WebdriverIO globals (`browser`, `$` and `expect`).

### The Tests

Line 4 loops over the two examples of the page and creates one test for each. In the first example the text is on the
page but hidden. In the second one, the text is added to the page after the loading finishes.

Each test visits the example and clicks the start button. Then `toBeDisplayed` waits until the text (`#finish`) is on
the page and visible, up to 10 seconds (the `wait` option). The loading takes about 5 seconds.

The same check works for both examples. WebdriverIO keeps looking for the element until it exists and is displayed,
so we don't need a separate wait for each case.
