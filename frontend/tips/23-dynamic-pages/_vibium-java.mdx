## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in Vibium's classes to drive the browser, and JUnit to run the tests.

### Setup and Teardown

The `beforeEach` method (lines 17 to 21) starts the browser and gets its first page (tab). The `afterEach` method
(lines 23 to 28) closes the browser.

### The Tests

Lines 30 to 39 run the test once for each example page (`@ParameterizedTest`, from the `junit-jupiter-params` library
in the `pom.xml` file). The first one has an element that is hidden and shows up after loading. The second one adds
the element to the page after loading.

Each test visits the page and clicks the start button. Then `waitUntil("visible", ...)` waits up to 10 seconds for the
`#finish` element to be visible, which works for both examples. Finally, we check that it is visible.
