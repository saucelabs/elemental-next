## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in `pytest`, Selenium's `webdriver`, and the `By` locators.

### Setup and Teardown

Lines 6 to 10 are a fixture that starts Firefox, gives it to the test, and quits it at the end.

### The Tests

Both tests load the page first.

The first test goes through the shadow roots one at a time. It finds the outer component (`#outer-card`) and gets its
shadow root with `shadow_root`. Inside it, `find_element` finds the inner component (`#inner-card`), and the test gets
its shadow root too. Inside that one, it finds the button and clicks it. Inside a shadow root, use CSS selectors:
XPath doesn't work there.

The page shows the result outside the components, so the test finds `#nested-result` with the driver, as usual, and
checks its text.

The second test shows the problem: a normal locator for the button finds nothing, because the button is in a shadow
root. `find_elements` returns an empty list.
