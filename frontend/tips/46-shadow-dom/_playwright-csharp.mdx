## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in the libraries we need: Playwright's MSTest integration and MSTest itself.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends. The
`OpenPage` method (lines 10 to 14) loads the page before each test.

### The Tests

The first test clicks the button with the usual CSS locator (`#inner-button`). Playwright's CSS locators look inside
open shadow roots, so the test doesn't name the shadow hosts on the way. Then it checks the text of `#nested-result`.

The second test shows that XPath locators don't look inside shadow roots: the same button, found by XPath, isn't
there. `ToHaveCountAsync(0)` checks it.
