## Code Walkthrough

### Importing Libraries

Lines 3 to 8 pull in Playwright's assertions, `Page` and JUnit extension, and JUnit.

### Setup and Teardown

Line 10 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. The `openPage` method
(lines 13 to 16) loads the page before each test.

### The Tests

The first test clicks the button with the usual CSS locator (`#inner-button`). Playwright's CSS locators look inside
open shadow roots, so the test doesn't name the shadow hosts on the way. Then it checks the text of `#nested-result`.

The second test shows that XPath locators don't look inside shadow roots: the same button, found by XPath, isn't
there. `hasCount(0)` checks it.
