## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Selenide (`$`, `open`, the `exactText` and `exist` conditions, and the `shadowCss` selector) and
JUnit.

### Setup and Teardown

The `openPage` method (lines 13 to 16) loads the page before each test. Selenide starts the browser when the test
opens the first page, and closes it when the tests end.

### The Tests

The first test (lines 18 to 24) finds the button with `shadowCss`. It takes the CSS selector of the element, then the
shadow hosts on the way to it, from the outermost: `#outer-card`, then `#inner-card`. Selenide goes through their
shadow roots, and the test clicks the button. Then `shouldHave` checks the text of `#nested-result`, in the page.

The second test (lines 26 to 29) shows the problem: a normal locator for the button finds nothing, because the button
is in a shadow root. `shouldNot(exist)` checks it.
