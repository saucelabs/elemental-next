## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect` from `@playwright/test`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. `test.beforeEach` (lines 3 to 5) loads the page before each test.

### The Tests

The first test clicks the button with the usual CSS locator (`#inner-button`). Playwright's CSS locators look inside
open shadow roots, so the test doesn't name the shadow hosts on the way. Then it checks the text of `#nested-result`.

The second test shows that XPath locators don't look inside shadow roots: the same button, found by XPath, isn't
there. `toHaveCount(0)` checks it.
