## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` and Playwright's `Page` and `expect`.

### Setup and Teardown

The `pytest-playwright` plugin handles the browser for us. Each test that takes a `page` argument receives a fresh
browser tab, and the plugin closes it when the test ends. The `open_page` fixture (lines 5 to 7) loads the page before
each test (`autouse=True`).

### The Tests

The first test clicks the button with the usual CSS locator (`#inner-button`). Playwright's CSS locators look inside
open shadow roots, so the test doesn't name the shadow hosts on the way. Then it checks the text of `#nested-result`.

The second test shows that XPath locators don't look inside shadow roots: the same button, found by XPath, isn't
there. `to_have_count(0)` checks it.
