### The Tests

The first test (lines 8 to 12) clicks the button with the usual CSS selector (`#inner-button`). WebdriverIO's `$`
looks inside open shadow roots, so the test doesn't name the shadow hosts on the way. Then it checks the text of
`#nested-result`.

The second test (lines 14 to 18) goes one shadow root at a time, like Selenium: `shadow$` finds an element inside the
shadow root of the element before it. It's useful when the same selector matches elements in more than one
component.
