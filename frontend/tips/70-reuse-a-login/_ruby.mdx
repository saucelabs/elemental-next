## Code Walkthrough

### Logging In Once

The `log_in` method (lines 8 to 17) runs once: line 37 calls it before the tests and keeps the cookie in
`SESSION_COOKIE`: it starts a browser, logs in through the form, and keeps the session cookie of the logged-in user,
`rack.session`, with `cookie_named`. Then it closes that browser.

### Starting Each Test Logged In

The `setup` method (lines 19 to 24) starts a fresh browser for each test. It opens the site first, because a cookie
can only be added for the site of the current page, and then adds the session cookie with `add_cookie`, with its name
and value. The browser now sends the session cookie, so the site sees the user as logged in. The `teardown` method
(lines 26 to 28) quits the browser, and `run` (lines 30 to 35) calls them around each test.

### The Tests

Both tests open the secure area (`/secure`) directly, without the form. The first one checks that it shows the user
name, and the second one clicks "Logout" and checks the message in `#flash`.
