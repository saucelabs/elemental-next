## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Playwright's assertions, `Browser`, `BrowserContext`, `Page` and JUnit extension, and JUnit.

### Logging In Once

The `logIn` method (lines 17 to 29) runs once, before the tests of the class (`@BeforeAll`), with the `Browser` that
`@UsePlaywright` gives it: it creates a browser context (a fresh browser profile), logs in through the form, and waits
for the secure area. Then `context.storageState()` saves the storage state of the context: its cookies and local
storage. That's the whole session, whatever the site uses to keep it.

### Starting Each Test Logged In

`loggedInPage` (lines 31 to 34) creates a context with the storage state, and a page in it. Each test calls it, so its
page starts with the cookies and the local storage of the logged-in user. The test closes the context at the end.

### The Tests

Both tests open the secure area (`/secure`) directly, without the form. The first one checks that it shows the user
name, and the second one clicks "Logout" and checks the message (`containsText`).
