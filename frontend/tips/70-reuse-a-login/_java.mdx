## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in JUnit and Selenium.

### Logging In Once

The `logIn` method (lines 18 to 31) runs once, before the tests of the class (`@BeforeAll`): it starts a browser, logs
in through the form, and keeps the session cookie of the logged-in user, `rack.session`, with `getCookieNamed`. Then
it closes that browser.

### Starting Each Test Logged In

The `beforeEach` method (lines 33 to 39) starts a fresh browser for each test. It opens the site first, because a
cookie can only be added for the site of the current page, and then adds the session cookie with `addCookie`, with its
name and value. The browser now sends the session cookie, so the site sees the user as logged in. The `afterEach`
method (lines 41 to 46) quits the browser.

### The Tests

Both tests open the secure area (`/secure`) directly, without the form. The first one checks that it shows the user
name, and the second one clicks "Logout" and checks the message in `#flash`.
