## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `assert` and Selenium.

### Logging In Once

The `before` hook (lines 10 to 22) runs once, before the tests of the `describe`: it starts a browser, logs in through
the form, and keeps the session cookie of the logged-in user, `rack.session`, with `getCookie`. Then it closes that
browser.

### Starting Each Test Logged In

The `beforeEach` hook (lines 24 to 29) starts a fresh browser for each test. It opens the site first, because a cookie
can only be added for the site of the current page, and then adds the session cookie with `addCookie`, with its name
and value. The browser now sends the session cookie, so the site sees the user as logged in. The `afterEach` hook
(lines 31 to 33) quits the browser.

### The Tests

Both tests open the secure area (`/secure`) directly, without the form. The first one checks that it shows the user
name, and the second one clicks "Logout" and checks the message in `#flash`.
