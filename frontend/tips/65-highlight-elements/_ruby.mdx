## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox and loads the page, and the `teardown` method quits it. The `run` method wraps
each test with them.

### The Helper

`highlight` reads the `style` attribute of the element (`dom_attribute('style')`), using an empty string when the element doesn't have
one. Then it sets the highlight style with JavaScript (`@driver.execute_script`, passing the element and the style as arguments).
If the duration is greater than `0`, it waits that long and sets the original style back.

### The Tests

Both tests find an element on the page. The first one highlights it with a duration of `0` (so the style stays) and
checks that the style has the dashed border. The second one highlights it for 1 second and checks that the dashed
border is gone afterward.
