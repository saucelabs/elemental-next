## Code Walkthrough

### Importing Libraries

Lines 3 to 12 pull in Vibium's classes to drive the browser, JUnit to run the tests, and `Objects`.

### Setup and Teardown

The `beforeEach` method (lines 20 to 25) starts the browser, gets its first page (tab), and visits a page with a lot
of elements. The `afterEach` method (lines 27 to 32) closes the browser.

### Highlighting an Element

Line 15 has the style we use to highlight an element: a red dashed border.

Lines 34 to 45 are the `highlight` method. It takes the selector of the element, and how many seconds to keep the
highlight.

`page.evaluate` runs JavaScript in the page and takes it as a string, so line 35 builds the code that finds the
element. We store the original style of the element (line 37, an empty string when there is none), and set the
highlight style with `setAttribute` (line 39). After the given seconds (`page.sleep`), we put the original style back
(lines 41 to 44). With a duration of `0`, the highlight stays.

### The Tests

The element we highlight has an id with a dot (`sibling-2.3`). In CSS, a dot starts a class name, so we use an
attribute selector (`[id="sibling-2.3"]`).

- Lines 47 to 51 highlight the element with no duration, and check that its style has the dashed border.
- Lines 53 to 58 highlight it for 1 second, and check that the style is back to the original one.
