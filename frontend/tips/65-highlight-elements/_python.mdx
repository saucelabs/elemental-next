## Code Walkthrough

### Setup and Teardown

The `driver` fixture launches Firefox and loads the page before `yield`ing the driver to the test, and quits it once
the test is done.

### The Helper

`highlight` reads the `style` attribute of the element (`get_dom_attribute('style')`), using an empty string when the element doesn't have
one. Then it sets the highlight style with JavaScript (`driver.execute_script`, passing the element and the style as arguments).
If the duration is greater than `0`, it waits that long and sets the original style back.

### The Tests

Both tests find an element on the page. The first one highlights it with a duration of `0` (so the style stays) and
checks that the style has the dashed border. The second one highlights it for 1 second and checks that the dashed
border is gone afterward.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
