## Code Walkthrough

### The Highlight Method

Lines 17 to 28 hold the `highlight` method. It saves the style of the element, gives it a red dashed border with
`evaluate` (which runs a function on the element in the page), waits for a few seconds, and puts the original style
back. With a duration of `0`, the border stays.

Playwright has its own `highlight`, which draws an overlay over the element. It's useful while debugging, but it doesn't
change the element, so we can't check it in a test.

### The Tests

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Both tests visit a large page first (the
`@BeforeEach` method on lines 30 to 33) and find one of its elements.

- Lines 36 to 40 highlight it for good and check that its style has the dashed border.
- Lines 43 to 47 highlight it for 1 second and check that the border is gone afterward.
