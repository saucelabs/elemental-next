## Code Walkthrough

### The Highlight Helper

Lines 5 to 15 are a helper that highlights an element on the page.

- Line 7 saves the original `style` attribute of the element, so we can put it back later.
- Line 9 runs JavaScript in the page with `browser.execute`. WebdriverIO passes the element and the style to the
  function, which sets the style to a red dashed border (line 3).
- When a duration is given, lines 11 to 14 wait that many seconds with `browser.pause` and then restore the original
  style.

### Setup

The `beforeEach` hook (lines 18 to 20) visits a page with a lot of elements.

### The Tests

The id of the element has a dot (`sibling-2.3`), which `#sibling-2.3` would read as a class, so we use an attribute
selector: `[id="sibling-2.3"]`.

- Lines 22 to 26 highlight the element without a duration and check that its style has the dashed border.
- Lines 28 to 32 highlight it for 1 second and check that the dashed border is gone afterward.
