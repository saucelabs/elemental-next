### Our Own Highlight

The `highlight` method (lines 25 to 35) gets an element and a duration:

1. It keeps the original `style` of the element (or an empty one), so we can put it back later.
2. It sets the style to a red dashed border with JavaScript.
3. If the duration is more than 0, it waits that long and puts the original style back.

`executeJavaScript` accepts a Selenide element as an argument, like Selenium's `executeScript` does with a
`WebElement`.

### The Tests

The element's id has a dot (`sibling-2.3`), which means something else in CSS, so we find it with `byId`.

- Lines 38 to 42 highlight the element and check that its style has the dashed border.
- Lines 45 to 49 highlight it for 1 second and check that the style is back to the original one.

### Selenide's Highlight

Selenide also has a `highlight()` method. Lines 52 to 56 use it with a border of our own (`border(...)`). Without
options, it gives the element a colorful background. It doesn't put the style back, though, so we still need our own
method for that.
