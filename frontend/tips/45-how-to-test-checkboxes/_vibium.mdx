## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 12) starts the browser and gets its first page (tab), and visits the page with the checkboxes. The `afterEach` method
(lines 14 to 16) closes the browser.

### The Tests

The page has two checkboxes. The first one is not checked, and the last one is.

Lines 18 to 23 find the checkboxes with `page.findAll` and read their `checked` attribute. We print the values:
`null` means the attribute is not there, so the checkbox is not checked.

Lines 25 to 29 do the same with `isChecked`, which returns `true` or `false`. This is easier to read and also
works when the user checks a checkbox (the attribute only shows the starting state).
