## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox, loads the page, and finds all the checkboxes on it
(`find_elements(css: 'input[type="checkbox"]')`). The `teardown` method quits the browser. The `run` method wraps each
test with them.

### The Tests

The first test uses `dom_attribute('checked')`, which returns the value of the attribute in the markup, or `nil` when
the attribute is not there.

The second test uses `selected?`, which returns `true` or `false`.

Both of them output the values for every checkbox (with `p`).
