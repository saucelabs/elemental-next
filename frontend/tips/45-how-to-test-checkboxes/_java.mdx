## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox, loads the page, and finds all the checkboxes on it
(`findElements(By.cssSelector("input[type=\"checkbox\"]"))`). The `afterEach` method quits the browser.

### The Tests

`attributeLookup` uses `getDomAttribute("checked")`, which returns the value of the attribute in the markup, or
`null` when the attribute is not there.

`isSelected` uses `isSelected()`, which returns `true` or `false`.

Both of them print the values for every checkbox.
