## Code Walkthrough

### The Tests

Both tests visit the page with two checkboxes first (lines 3 to 5). The first checkbox is not checked and the second
one is.

- Lines 7 to 12 look at the `checked` attribute. Line 9 prints it for every checkbox, with `evaluateAll`. The
  attribute is `null` when it's not there, so we check that the first one is `null` and the last one is not. The
  attribute only says how the checkbox started, not how it is now.
- Lines 14 to 18 check the state of the checkboxes with `toBeChecked`, which is what the user sees, even after a click
  changes it. This is the check to use.
