## Code Walkthrough

### The Tests

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Both tests visit the page with two
checkboxes first: the `@BeforeEach` method on lines 16 to 19 runs before each test and does it. The first checkbox is
not checked and the second one is.

- Lines 22 to 29 look at the `checked` attribute. Lines 24 to 26 print it for every checkbox, with `evaluateAll`. The
  attribute is `null` when it's not there, so we check that the first one is `null` and the last one is not. The
  attribute only says how the checkbox started, not how it is now.
- Lines 32 to 36 check the state of the checkboxes with `isChecked` (and `not()` to check the opposite), which is what
  the user sees, even after a click changes it. This is the check to use.
