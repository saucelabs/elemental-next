## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) launches Firefox, loads the page, and finds all the checkboxes
on it (`FindElements(By.CssSelector("input[type=\"checkbox\"]"))`). The `TearDown()` method (marked with
`[TestCleanup]`) closes the browser.

### The Tests

`AttributeLookup` uses `GetDomAttribute("checked")`, which returns the value of the attribute in the markup, or
`null` when the attribute is not there.

`IsSelected` uses the `Selected` property, which is `true` or `false`.

Both of them write the values for every checkbox to the console.
