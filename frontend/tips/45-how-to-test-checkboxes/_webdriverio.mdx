## Code Walkthrough

### Setup

The `beforeEach` hook (lines 4 to 6) visits the page with the checkboxes before each test. The first checkbox starts
unchecked and the second one starts checked.

### Example 1: The Checked Attribute

Lines 8 to 13 find all the checkboxes with `$$` and print their `checked` attribute: `[ null, 'true' ]`. The attribute
is missing (`null`) on the unchecked checkbox, so we check that the first one is `null` and the last one isn't.

This works, but it relies on how the page writes its HTML. The attribute also doesn't change when someone clicks the
checkbox.

### Example 2: Is It Selected?

Lines 15 to 19 use `toBeSelected`, which asks the browser whether the checkbox is checked right now. It is the more
reliable option: it works however the page sets the checkbox, and it reflects clicks.
