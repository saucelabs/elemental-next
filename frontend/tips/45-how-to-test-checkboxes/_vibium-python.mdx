## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the tests, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 11) starts the browser, visits the page with the checkboxes in its first page (tab), gives
the page to each test, and closes the browser after the test.

### The Tests

The page has two checkboxes. The first one is not checked, and the last one is.

Lines 14 to 18 find the checkboxes with `page.find_all` and read their `checked` attribute. We print the values:
`None` means the attribute is not there, so the checkbox is not checked.

Lines 21 to 24 do the same with `is_checked`, which returns `True` or `False`. This is easier to read and also works
when the user checks a checkbox (the attribute only shows the starting state).

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
