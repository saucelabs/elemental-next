## Code Walkthrough

### Setup and Teardown

The `checkboxes` fixture launches Firefox, loads the page, and `yield`s all the checkboxes on it
(`find_elements(By.CSS_SELECTOR, 'input[type="checkbox"]')`) to the test. Once the test is done, it quits the browser.

### The Tests

`test_attribute_lookup` uses `get_dom_attribute('checked')`, which returns the value of the attribute in the markup,
or `None` when the attribute is not there.

`test_is_selected` uses `is_selected()`, which returns `True` or `False`.

Both of them `print` the values for every checkbox. Run pytest with `-s` (e.g., `pytest -s checkboxes.py`) to see
them.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
