## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox, loads the page, and finds all the checkboxes on it
(`findElements(By.css('input[type="checkbox"]'))`). The `afterEach` hook quits the browser.

### The Tests

The first test uses `getDomAttribute("checked")`, which resolves to the value of the attribute in the markup, or
`null` when the attribute is not there.

The second test uses `isSelected()`, which resolves to `true` or `false`.

Both of them log the values for every checkbox.
