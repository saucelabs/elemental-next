## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the libraries we need: Playwright, its MSTest integration, and MSTest itself.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends.

`PageTest` creates the browser context with the options of `ContextOptions`, which lines 11 to 20 override. The
browser context (a fresh browser profile for each test) starts with the location of Berlin, the geolocation permission
(so the browser doesn't ask the user), the `Asia/Tokyo` time zone and the `de-DE` locale.

### The Tests

`Geolocation` (lines 22 to 30) loads the page and clicks the button. The page asks the browser for the location, and
`ToHaveTextAsync` waits for the latitude and longitude of Berlin.

`TimeZoneAndLocale` (lines 32 to 42) loads the second page. The server greets the user in German (`Hallo!`), and the
page shows the language (`de-DE`), the time zone (`Asia/Tokyo`), the date in German at the time of Tokyo (`Mittwoch,
15. April 2026 um 21:00`), and the number with German separators (`1.234.567,891`).
