## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in Playwright's assertions, `Browser`, `Page` and JUnit extension, and JUnit's `@Test`.

### Setup and Teardown

Line 13 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends.

`@UsePlaywright` takes the `CustomOptions` class (lines 16 to 25), which sets the options of the browser context.
The browser context (a fresh browser profile for each test) starts with the location of Berlin, the geolocation
permission (so the browser doesn't ask the user), the `Asia/Tokyo` time zone and the `de-DE` locale.

### The Tests

`geolocation` (lines 27 to 34) loads the page and clicks the button. The page asks the browser for the location, and
`hasText` waits for the latitude and longitude of Berlin.

`timeZoneAndLocale` (lines 36 to 45) loads the second page. The server greets the user in German (`Hallo!`), and the
page shows the language (`de-DE`), the time zone (`Asia/Tokyo`), the date in German at the time of Tokyo (`Mittwoch,
15. April 2026 um 21:00`), and the number with German separators (`1.234.567,891`).
