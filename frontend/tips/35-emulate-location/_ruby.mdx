## Code Walkthrough

### Setup and Teardown

The `setup` method (lines 5 to 12) turns on WebDriver BiDi with `web_socket_url`, starts Chrome, creates Selenium's
BiDi `Emulation` module, and keeps the window handle of the current tab in `@tab`. The overrides apply to the browser
tabs we pass in `contexts`: the current tab, from its window handle. The `teardown` method (lines 14 to 16) quits the
browser, and `run` (lines 18 to 23) calls them around each test.

### The Tests

The first test (lines 25 to 39) grants the geolocation permission to the-internet with `set_permission`, so the
browser doesn't ask the user. Then `set_geolocation_override` sets the location to Berlin.

Then the test loads the page and clicks the button. The page asks the browser for the location, and shows the
latitude and longitude of Berlin. The test waits for them and checks them.

The second test (lines 41 to 52) sets the time zone with `set_timezone_override` and the language with
`set_locale_override`, for the current tab.

Then the test loads the page. The server greets the user in German (`Hallo!`), and the page shows the language
(`de-DE`), the time zone (`Asia/Tokyo`), the date in German at the time of Tokyo (`Mittwoch, 15. April 2026 um
21:00`), and the number with German separators (`1.234.567,891`).
