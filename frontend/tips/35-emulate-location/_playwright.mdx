## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect` from `@playwright/test`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends.

`test.use` (lines 3 to 8) sets the options of the browser context for the tests of the file. The browser context (a
fresh browser profile for each test) starts with the location of Berlin, the geolocation permission (so the browser
doesn't ask the user), the `Asia/Tokyo` time zone and the `de-DE` locale.

### The Tests

`geolocation` (lines 10 to 16) loads the page and clicks the button. The page asks the browser for the location, and
`toHaveText` waits for the latitude and longitude of Berlin.

`time zone and locale` (lines 18 to 26) loads the second page. The server greets the user in German (`Hallo!`), and
the page shows the language (`de-DE`), the time zone (`Asia/Tokyo`), the date in German at the time of Tokyo
(`Mittwoch, 15. April 2026 um 21:00`), and the number with German separators (`1.234.567,891`).
