## Code Walkthrough

### Importing Libraries

Lines 1 to 5 pull in `pytest`, Selenium's `webdriver`, the `By` locators, the `GeolocationCoordinates` of the BiDi
`emulation` module, and `WebDriverWait`.

### Setup and Teardown

Lines 8 to 15 are a fixture that starts Chrome with WebDriver BiDi turned on (`enable_bidi`), gives it to the test,
and quits it at the end.

### The Tests

`test_geolocation` (lines 18 to 28) grants the geolocation permission to the-internet with
`driver.permissions.set_permission`, so the browser doesn't ask the user. Then
`driver.emulation.set_geolocation_override` sets the location to Berlin. The overrides apply to the browser tabs we
pass in `contexts`: the current tab, from its window handle.

Then the test loads the page and clicks the button. The page asks the browser for the location, and shows the
latitude and longitude of Berlin. The test waits for them and checks them.

`test_time_zone_and_locale` (lines 31 to 41) sets the time zone with `set_timezone_override` and the language with
`set_locale_override`, for the current tab.

Then the test loads the page. The server greets the user in German (`Hallo!`), and the page shows the language
(`de-DE`), the time zone (`Asia/Tokyo`), the date in German at the time of Tokyo (`Mittwoch, 15. April 2026 um
21:00`), and the number with German separators (`1.234.567,891`).
