## Code Walkthrough

### Setup and Teardown

If the credentials are not set, the script prints a message and exits without running the test.

The `setup` method is where the magic is happening. It creates the options for Chrome
(`Selenium::WebDriver::Options.chrome`), sets the browser version and operating system (`browser_version` and
`platform_name`), and adds the Sauce Labs options with `add_option('sauce:options', ...)`. Then it connects to Sauce
Labs with `Selenium::WebDriver.for(:remote, ...)`, passing the Sauce Labs URL and the options. The `teardown` method
quits the browser.

### The Test

The test loads the page and checks its title, just like any other test. It runs in Sauce Labs because of the driver
created in `setup`.
