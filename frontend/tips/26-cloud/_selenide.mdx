## Code Walkthrough

### Importing Libraries

Lines 3 to 15 pull in Selenide's `Configuration`, the JUnit annotations, Selenium's `ChromeOptions`, and the Selenide
methods we use (`open`, `closeWebDriver`, `webdriver` and the `title` condition).

### Setup

The `setUp` method (lines 20 to 36) reads the Sauce Labs username and access key from environment variables. If they
are not set, `Assumptions.assumeTrue` skips the test instead of failing it.

Then we say which browser we want (the latest Chrome on Windows 11) with `ChromeOptions`, and put the Sauce Labs
credentials and the name of the test in `sauce:options`.

Selenide is set up through `Configuration`. Lines 34 and 35 give it the address of Sauce Labs (`remote`) and the
options (`browserCapabilities`). With `remote` set, Selenide starts the browser on Sauce Labs instead of on our
computer. The rest of the test doesn't change.

### Teardown

Lines 38 to 41 close the browser after the test with `closeWebDriver()`, which ends the session on Sauce Labs.

### The Test

Lines 43 to 47 open the page and check its title. `webdriver().shouldHave(title(...))` waits for the title, like
the other Selenide checks.
