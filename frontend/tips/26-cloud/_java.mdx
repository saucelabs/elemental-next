## Code Walkthrough

### Setup and Teardown

The `beforeEach` method is where the magic is happening. If the credentials are not set,
`Assumptions.assumeTrue` aborts the test, which reports it as skipped. Otherwise, it creates the options for Chrome
(`ChromeOptions`), sets the browser version and operating system (`setBrowserVersion` and `setPlatformName`), and adds
the Sauce Labs options with `setCapability("sauce:options", ...)`.

Then it connects to Sauce Labs with a `RemoteWebDriver`, passing the Sauce Labs URL and the options. The `afterEach`
method quits the browser.

### The Test

`title` loads the page and checks its title, just like any other test. It runs in Sauce Labs because of the driver
created in `beforeEach`.
