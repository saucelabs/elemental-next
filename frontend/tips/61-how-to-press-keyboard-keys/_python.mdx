## Code Walkthrough

### Setup and Teardown

The `driver` fixture launches Firefox and visits the page before `yield`ing the driver to the test, and quits it once
the test is done.

### The Tests

The keys that don't print a character (e.g., space, tab, enter, or the arrows) are available as constants
(`Keys`, from `selenium.webdriver.common.keys`).

The first test finds the `target` element and sends the space key to it (`send_keys(Keys.SPACE)`). The second one sends the tab
key with the Actions API (`ActionChains(driver).send_keys(Keys.TAB).perform()`), without finding an element. Both of them check the result text on the page.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
