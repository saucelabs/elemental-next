## Code Walkthrough

### Setup and Teardown

The `setup` method launches Firefox and visits the page, and the `teardown` method quits it. The `run` method wraps
each test with them.

### The Tests

The keys that don't print a character (e.g., space, tab, enter, or the arrows) are available as constants
(as symbols, e.g., `:space` and `:tab`).

The first test finds the `target` element and sends the space key to it (`send_keys :space`). The second one sends the tab
key with the Actions API (`@driver.action.send_keys(:tab).perform`), without finding an element. Both of them check the result text on the page.
