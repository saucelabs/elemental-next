## Code Walkthrough

### The Tests

Both tests visit a page that shows the last key we pressed (the fixture on lines 5 to 7).

- Lines 10 to 12 press a key on an element: `press` focuses the input and presses `Space` on it.
- Lines 15 to 17 press a key without an element: `page.keyboard.press` sends `Tab` to whatever has the focus.

The keys have names like `Enter`, `ArrowDown` or `Shift+A`, and Playwright fires the same events a real key press
does.
