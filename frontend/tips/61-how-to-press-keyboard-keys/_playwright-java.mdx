## Code Walkthrough

### The Tests

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Both tests visit a page that shows the
last key we pressed (the `@BeforeEach` method on lines 13 to 16).

- Lines 19 to 22 press a key on an element: `press` focuses the input and presses `Space` on it.
- Lines 25 to 28 press a key without an element: `page.keyboard().press` sends `Tab` to whatever has the focus.

The keys have names like `Enter`, `ArrowDown` or `Shift+A`, and Playwright fires the same events a real key press does.
