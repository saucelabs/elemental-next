### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) launches Firefox and visits the page, and the `TearDown()`

### The Tests

The keys that don't print a character (e.g., space, tab, enter, or the arrows) are available as constants
(`Keys`, from `OpenQA.Selenium`).

The first test finds the `target` element and sends the space key to it (`SendKeys(Keys.Space)`). The second one sends the tab
key with the Actions API (`new Actions(_driver).SendKeys(Keys.Tab).Perform()`), without finding an element. Both of them check the result text on the page.
