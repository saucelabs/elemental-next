## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox and visits the page before each test, and the `afterEach` hook quits it.

### The Tests

The keys that don't print a character (e.g., space, tab, enter, or the arrows) are available as constants
(`Key`, from `selenium-webdriver`).

The first test finds the `target` element and sends the space key to it (`sendKeys(Key.SPACE)`). The second one sends the tab
key with the Actions API (`driver.actions().sendKeys(Key.TAB).perform()`), without finding an element. Both of them check the result text on the page.
