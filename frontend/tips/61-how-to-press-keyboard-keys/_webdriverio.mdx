## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the WebdriverIO globals (`browser`, `$` and `expect`) and `Key`, which has the names of the
special keys (e.g., `Key.Space`, `Key.Tab`, `Key.Enter`). `Key` comes from the `webdriverio` package, so it is in the
`package.json` too.

### Setup

The `beforeEach` hook (lines 5 to 7) visits a page that shows the last key we pressed.

### Example 1: Sending Keys to an Element

Lines 9 to 12 press the space key in the input field with `addValue`, which types into an element without clearing it
first. Then we check that the page says `You entered: SPACE`.

### Example 2: Sending Keys Without an Element

Lines 14 to 17 press the tab key with `browser.keys`. It sends the keys to whatever has the focus, so it's useful for
keyboard shortcuts or to move between fields. Then we check that the page says `You entered: TAB`.
