## Code Walkthrough

### The Tests

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Both tests visit a
page that shows the last key we pressed (the `[TestInitialize]` method on lines 11 to 15).

- Lines 17 to 22 press a key on an element: `PressAsync` focuses the input and presses `Space` on it.
- Lines 24 to 29 press a key without an element: `Page.Keyboard.PressAsync` sends `Tab` to whatever has the focus.

The keys have names like `Enter`, `ArrowDown` or `Shift+A`, and Playwright fires the same events a real key press
does.
