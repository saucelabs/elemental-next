## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the tests, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 11) starts the browser, visits the page that shows the last key pressed in its first page
(tab), gives the page to each test, and closes the browser after the test.

### The Tests

- Lines 14 to 16 press the space key on an input field with the element's `press` method.
- Lines 19 to 21 press the tab key with `page.keyboard.press`, without an element. The key goes to the element that
  has the focus.

Vibium uses the key names of the browser (e.g., `Space`, `Tab`, `Enter`, `ArrowDown`). Each test checks the message
that the page shows for the key.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
