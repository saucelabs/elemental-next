## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox and visits the page before each test, and the `afterEach` method quits it.

### The Tests

The keys that don't print a character (e.g., space, tab, enter, or the arrows) are available as constants
(`Keys`, from `org.openqa.selenium`).

The first test finds the `target` element and sends the space key to it (`sendKeys(Keys.SPACE)`). The second one sends the tab
key with the Actions API (`new Actions(driver).sendKeys(Keys.TAB).perform()`), without finding an element. Both of them check the result text on the page.
