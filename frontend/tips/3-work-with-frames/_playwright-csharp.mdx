## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the libraries we need: Playwright, its MSTest integration (`Microsoft.Playwright.MSTest`), and
MSTest itself.

### Setup and Teardown

Lines 8 and 9 declare the test class. It extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package.
`PageTest` handles the browser for us: each test gets a fresh browser tab in the `Page` property, and it is closed when
the test ends. There is no setup or teardown code to write.

### Example 1: Nested Frames

Lines 11 to 20 are the first test. The page has a frame (`frame-top`) with frames inside it, and we want the text of
the `frame-middle` frame.

Playwright doesn't switch between frames. Instead, `FrameLocator` points to a frame, and we chain them to reach a
frame inside another one. Then we find the element in that frame and check its text, which is `MIDDLE`.

### Example 2: An iframe

Lines 22 to 32 are the second test. The page has a text editor (TinyMCE) inside an iframe.

We point to the iframe with `FrameLocator` and to the editor's body (`#tinymce`) inside it. We replace its text with
`FillAsync`, and check that the editor now has the new text.

Then we check the heading of the page. Since Playwright never switched into the iframe, there is nothing to switch
back from: `Page.Locator` still works on the page.
