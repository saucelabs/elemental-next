## Code Walkthrough

### Setup and Teardown

The setup is the one from [tip 30](/tips/30-mobile): lines 24 to 44 skip the tests without credentials and end the
session after each test, and lines 84 to 90 are the Sauce Labs options. Lines 49 and 68 ask for phones with a regular
screen (a Pixel 8 or newer, and an iPhone 14 to 17), where "Add to cart" shows without scrolling.

### Waiting

Line 53 creates a `WebDriverWait` that checks a condition again and again, for up to 30 seconds, and returns as soon as
it is true. Each step of the test waits for what it needs:

- Line 55 waits for the first product to be visible (`visibilityOfElementLocated`). The app shows a splash screen
  first, and it can take a few seconds on some devices. `until` returns the element, so the test taps it right away.
- Lines 56 and 57 wait for "Add to cart" and for the cart button to be clickable (`elementToBeClickable`: visible and
  enabled), since the product screen slides in after the tap.
- Lines 59 and 60 wait for the checkout button of the cart.
- Line 61 removes the backpack, and line 62 waits for the checkout button to go away
  (`invisibilityOfElementLocated`). The cart is empty, so the app hides it.

Lines 74 to 81 do the same on iOS, with the accessibility IDs of the iOS app.

There is no `Thread.sleep` and no implicit wait: each wait ends as soon as the app is ready.
