## Code Walkthrough

### Running in Parallel

Mobilewright runs the tests of each project in workers, as Playwright does. Each worker gets its own device.

- Line 12 runs two workers at the same time (`workers: 2`).
- Lines 16 to 37 are the two projects: an Android phone and an iPhone. One `mobilewright test` runs both, so the
  Android test and the iOS test start at the same time. In tip 30, `npm test` runs each project on its own, one after
  the other.

The rest is the configuration from tip 30: the Sauce Labs driver, the timeouts, and the device and app of each project.
