## Code Walkthrough

### Running in Parallel

In WebdriverIO, the devices are part of the configuration (above), and the test runs on each one.

- Line 11 runs up to two devices at the same time (`maxInstances: 2`). In tip 30 it is `1`, so the iPhone waits for
  the Android phone.
- Lines 12 to 24 are the two devices: an Android phone and an iPhone, each with the demo app.

The rest is the configuration from tip 30: the Sauce Labs credentials and region, the Sauce service that names each
job, and the timeouts.
