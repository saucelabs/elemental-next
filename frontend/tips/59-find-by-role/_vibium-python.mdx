## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` and Vibium's `browser`.

### Setup and Teardown

Lines 5 to 9 are a pytest fixture that starts and stops the browser.

It starts the browser with `browser.start()` and gives the test its first page (tab) with `bro.page()`. After the test
runs, the code after `yield` closes the browser with `bro.stop()`.

### The Test

The test loads the page, and `page.find(role='combobox', label='Fruit')` finds the combobox labelled "Fruit". The test
clicks it, and the list of fruits opens. Then `page.find(role='option', text='Mango')` finds the option with the text
"Mango", and the test clicks it. At the end, the test checks that the combobox shows "Mango", and that the page shows
`Selected: mango`.
