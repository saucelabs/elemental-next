## Code Walkthrough

### Importing Libraries

Line 1 pulls in Playwright's `Page` and `expect`.

### Setup and Teardown

The `pytest-playwright` plugin handles the browser for us. Each test that takes a `page` argument receives a fresh
browser tab, and the plugin closes it when the test ends. There is no setup or teardown code to write.

### The Test

The test loads the page, and `get_by_role('combobox', name='Fruit')` finds the combobox named "Fruit" (its accessible
name, from the label next to it). The test clicks it, and the list of fruits opens. Then the test finds the "Mango"
option the same way, and clicks it. At the end, `to_have_text` checks that the combobox shows "Mango", and that the
page shows `Selected: mango`.
