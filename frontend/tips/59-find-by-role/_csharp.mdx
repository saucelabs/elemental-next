### Importing Libraries

### Setup and Teardown

The `SetUp` method (lines 12 to 16) starts Firefox, and the `TearDown` method (lines 18 to 22) quits it.

### Finding by Role and Name

Selenium has no role locator yet, so the helper `FindByRole` (lines 24 to 35) finds the elements with a `role`
attribute and keeps the first one with the role and the name we ask for. The browser computes both, as a screen reader
sees them: `ComputedAccessibleRole` returns the role, and `ComputedAccessibleLabel` returns the accessible name, which
for the combobox comes from the label next to it (`aria-labelledby`). When no element matches, the helper fails with a
clear message. Both are properties of the `WebElement` class, so the loop uses it instead of the `IWebElement`
interface.

### The Test

The test loads the page, finds the combobox named "Fruit" and clicks it, and the list of fruits opens. Then it finds
the option named "Mango" and clicks it. At the end, it checks that the combobox shows "Mango", and that the page shows
`Selected: mango`.
