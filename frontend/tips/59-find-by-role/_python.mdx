## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in `pytest`, Selenium's `webdriver`, and the `By` locators.

### Setup and Teardown

Lines 6 to 10 are a fixture that starts Firefox, gives it to the test, and quits it at the end.

### Finding by Role and Name

Selenium has no role locator yet, so the helper `find_by_role` (lines 13 to 18) finds the elements with a `role`
attribute and keeps the first one with the role and the name we ask for. The browser computes both, as a screen reader
sees them: `aria_role` returns the role, and `accessible_name` returns the accessible name, which for the combobox
comes from the label next to it (`aria-labelledby`). When no element matches, the helper fails with a clear message.

### The Test

The test loads the page, finds the combobox named "Fruit" and clicks it, and the list of fruits opens. Then it finds
the option named "Mango" and clicks it. At the end, it checks that the combobox shows "Mango", and that the page shows
`Selected: mango`.
