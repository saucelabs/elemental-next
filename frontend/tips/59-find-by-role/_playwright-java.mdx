## Code Walkthrough

### Importing Libraries

Lines 3 to 8 pull in Playwright's assertions, `Page`, JUnit extension and `AriaRole`, and JUnit's `@Test`.

### Setup and Teardown

Line 10 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### The Test

The test loads the page, and `getByRole(AriaRole.COMBOBOX, new Page.GetByRoleOptions().setName("Fruit"))` finds the
combobox named "Fruit" (its accessible name, from the label next to it). The test clicks it, and the list of fruits
opens. Then the test finds the "Mango" option the same way, and clicks it. At the end, `hasText` checks that the
combobox shows "Mango", and that the page shows `Selected: mango`.
