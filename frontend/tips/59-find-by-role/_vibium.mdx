## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module for the assertions and Vibium's `browser` to drive the browser.

### Setup and Teardown

After creating a `describe` to group our tests, lines 8 to 15 start and stop the browser.

The `beforeEach` method runs before each test. It starts the browser with `browser.start()` and gets its first page
(tab) with `bro.page()`. The `afterEach` method runs after each test and closes the browser with `bro.stop()`.

### The Test

The test loads the page, and `page.find({role: 'combobox', label: 'Fruit'})` finds the combobox labelled "Fruit". The
test clicks it, and the list of fruits opens. Then `page.find({role: 'option', text: 'Mango'})` finds the option with
the text "Mango", and the test clicks it. At the end, the test checks that the combobox shows "Mango", and that the
page shows `Selected: mango`.
