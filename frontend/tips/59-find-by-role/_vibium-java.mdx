## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Vibium (`Browser`, `Page`, `Vibium` and the `SelectorOptions` to find by role) and JUnit.

### Setup and Teardown

Lines 13 and 14 declare the browser and the page, so every method of the class can use them.

The `beforeEach` method (lines 16 to 20) runs before each test. It starts the browser with `Vibium.start()` and gets
its first page (tab) with `browser.page()`. The `afterEach` method (lines 22 to 27) runs after each test and closes the
browser with `browser.stop()`.

### The Test

The test loads the page, and `page.find(new SelectorOptions().role("combobox").label("Fruit"))` finds the combobox
labelled "Fruit". The test clicks it, and the list of fruits opens. Then `new
SelectorOptions().role("option").text("Mango")` finds the option with the text "Mango", and the test clicks it. At the
end, the test checks that the combobox shows "Mango", and that the page shows `Selected: mango`.
