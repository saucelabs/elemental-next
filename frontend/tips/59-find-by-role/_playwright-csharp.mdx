## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the libraries we need: Playwright (for `AriaRole`), its MSTest integration, and MSTest itself.

### Setup and Teardown

The test class extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package. `PageTest` handles the browser
for us: each test gets a fresh browser tab in the `Page` property, and it is closed when the test ends. There is no
setup or teardown code to write.

### The Test

The test loads the page, and `GetByRole(AriaRole.Combobox, new() { Name = "Fruit" })` finds the combobox named "Fruit"
(its accessible name, from the label next to it). The test clicks it, and the list of fruits opens. Then the test
finds the "Mango" option the same way, and clicks it. At the end, `ToHaveTextAsync` checks that the combobox shows
"Mango", and that the page shows `Selected: mango`.
