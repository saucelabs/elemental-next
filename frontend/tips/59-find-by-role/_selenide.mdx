### Setup and Teardown

Selenide starts the browser when the test opens the first page, and closes it when the tests end. There is no setup or
teardown code to write.

### The Test

The test loads the page, and `byRole("combobox", "Fruit")` finds the combobox named "Fruit". The test clicks it, and
the list of fruits opens. Then `byRole("option", "Mango")` finds the option, and the test clicks it. At the end,
`shouldHave` checks that the combobox shows "Mango", and that the page shows `Selected: mango`.
