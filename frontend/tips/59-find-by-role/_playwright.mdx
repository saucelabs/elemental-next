## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect` from `@playwright/test`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. There is no setup or teardown code to write.

### The Test

The test loads the page, and `getByRole('combobox', {name: 'Fruit'})` finds the combobox named "Fruit" (its accessible
name, from the label next to it). The test clicks it, and the list of fruits opens. Then the test finds the "Mango"
option the same way, and clicks it. At the end, `toHaveText` checks that the combobox shows "Mango", and that the page
shows `Selected: mango`.
