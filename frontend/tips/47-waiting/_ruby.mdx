## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward. Note that `setup`
doesn't set an implicit wait: only the tests that show the implicit wait set it, with
`@driver.manage.timeouts.implicit_wait = 3`.

### The Implicit Wait Tests

The first test clicks start in the second example and asserts that finding the finish element raises a
`NoSuchElementError`.

The second test clicks start in the first example and asserts that the finish element is found, but not displayed.

### The Explicit Wait Test

`wait_for` wraps an explicit wait: it runs the block we give it until it returns something truthy, for up to the
number of seconds we specify. For both examples, the test clicks start, waits up to 10 seconds for the finish element
to be displayed, and asserts its text.
