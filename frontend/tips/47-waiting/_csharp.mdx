## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it. Note that it doesn't set an implicit wait: only the tests
that show the implicit wait set it, with `_driver.Manage().Timeouts().ImplicitWait = TimeSpan.FromSeconds(3)`.

### The Implicit Wait Tests

`ImplicitWaitGivesUpBeforeTheElementIsRendered` clicks start in the second example and uses `Assert.ThrowsExactly` to
assert that finding the finish element throws a `NoSuchElementException`.

`ImplicitWaitDoesNotWaitForHiddenElements` clicks start in the first example and asserts that the finish element is
found, but not displayed.

### The Explicit Wait Test

`ExplicitWait` runs once for each `[DataRow]` (both examples). It clicks start and uses a `WebDriverWait` of up to 10
seconds, with a condition that returns the finish element once it's displayed (and `null` until then). Then it
asserts its text.
