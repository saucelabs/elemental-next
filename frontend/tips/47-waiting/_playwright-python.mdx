## Code Walkthrough

### Waiting for an Element

Lines 7 to 13 run a test for each example of the page. The element shows up a few seconds after we click start: in
example 1 it is hidden until then, and in example 2 it is not on the page until then.

`wait_for` waits until the element is in a state, `visible` here, or fails after the timeout (10 seconds). Then we
read its text.

### Giving Up

Lines 16 to 21 wait for only 2 seconds, which is too short. `wait_for` fails with a `TimeoutError`, and
`pytest.raises` checks that it did.

### Waiting Inside the Assertion

Lines 24 to 28 show the shorter way. The assertions of Playwright (e.g., `to_have_text`) wait on their own: they keep
checking until the element matches or the timeout ends. So we don't need a separate wait. Actions like `click` and
`fill` wait for the element too.
