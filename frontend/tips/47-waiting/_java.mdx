## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it. Note that it doesn't
set an implicit wait: only the tests that show the implicit wait set it, with
`driver.manage().timeouts().implicitlyWait(Duration.ofSeconds(3))`.

### The Implicit Wait Tests

`implicitWaitGivesUpBeforeTheElementIsRendered` clicks start in the second example and uses
`Assertions.assertThrows` to assert that finding the finish element throws a `NoSuchElementException`.

`implicitWaitDoesNotWaitForHiddenElements` clicks start in the first example and asserts that the finish element is
found, but not displayed.

### The Explicit Wait Test

`explicitWait` is a `@ParameterizedTest`, so it runs for both examples. It clicks start and waits up to 10 seconds for
the finish element to be visible with `ExpectedConditions.visibilityOfElementLocated`, which returns the element. Then
it asserts its text.
