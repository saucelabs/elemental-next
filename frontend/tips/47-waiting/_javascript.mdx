## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it. Note that it doesn't set
an implicit wait: only the tests that show the implicit wait set it, with
`driver.manage().setTimeouts({implicit: 3000})` (in milliseconds).

### The Implicit Wait Tests

The first test clicks start in the second example and uses `assert.rejects` to assert that finding the finish element
fails with a `NoSuchElementError`.

The second test clicks start in the first example and asserts that the finish element is found, but not displayed.

### The Explicit Wait Test

We create one explicit wait test for each example with a `for` loop. Each test clicks start, waits up to 10 seconds
for the finish element to be located and then visible (`until.elementLocated` and `until.elementIsVisible`), and
asserts its text.
