## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### The Retry Helper

Lines 4 to 10 are a small helper, `retryIfMessageContains`. It runs an action that returns a message, and runs it
again while the message contains the failure text, up to 10 attempts. Then it returns the last message.

### Setup and Teardown

The `beforeEach` method (lines 16 to 19) starts the browser and gets its first page (tab). The `afterEach` method
(lines 21 to 23) closes the browser.

### The Test

Lines 25 to 31 are the test itself.

We give the helper the failure text (`please try again`) and an action that loads the page and returns the text of the
notification. When the helper is done, we check that the message says `Action successful`.

If it still fails after 10 attempts, the assertion fails, and we know there is a real problem.
