## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the libraries we need: Playwright, its MSTest integration (`Microsoft.Playwright.MSTest`), and
MSTest itself. Line 11 sets how many times we try.

### Setup and Teardown

Lines 8 and 9 declare the test class. It extends `PageTest`, from the `Microsoft.Playwright.MSTest.v4` package.
`PageTest` handles the browser for us: each test gets a fresh browser tab in the `Page` property, and it is closed when
the test ends. There is no setup or teardown code to write.

### The Test

Lines 13 to 29 are the test itself.

Playwright for JavaScript has a built-in way to retry a block of actions (`expect(...).toPass()`), but Playwright for
.NET doesn't. A loop does the same job.

In each attempt, we load the page and check that the notification says `Action successful`. We give that check a
short timeout (1 second), so a page with the wrong message fails fast. When the check passes, `return` ends the test.

When it fails, `Expect` throws a `PlaywrightException`. We catch it and try again, unless it was the last attempt: the
`when` filter on line 25 lets the exception of the last attempt through, so the test fails with that error.
