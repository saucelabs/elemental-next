## Code Walkthrough

### Importing Libraries

Line 1 pulls in the Playwright test runner (`test` and `expect`).

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab), and Playwright closes
it when the test ends.

### The Test

Lines 3 to 8 are the test itself.

Playwright has a built-in way to retry a block of actions: `expect(...).toPass()`. It runs the function we give it
again and again until it doesn't throw, or until the timeout (30 seconds here) runs out. Between attempts it waits a
little longer each time.

In the function, we load the page and check that the notification says `Action successful`. We give that check a short
timeout (1 second), so a page with the wrong message fails fast and the next attempt starts.

If the message never shows up, the test fails after 30 seconds with the error of the last attempt.
