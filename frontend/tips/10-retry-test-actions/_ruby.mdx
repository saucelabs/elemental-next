## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before the test and quit it afterward.

### The Retry Helper

`retry_if_message_contains` receives the failure message and the maximum number of attempts, and a block with the
actions to perform. It runs the block (with `yield`) once, and runs it again while the message it returns contains
the failure message. Then it returns the last message it got.

### The Test

In the `run` block we pass a block that loads the page and returns the text of the notification message
(`@driver.find_element(id: 'flash').text`), together with the failure message (`please try again`). Then we assert
that the message we end up with is the successful one.
