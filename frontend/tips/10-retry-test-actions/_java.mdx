## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Retry Helper

`retryIfMessageContains` receives the failure message and the action to perform (a `Supplier<String>` that returns
the notification message). It performs the action once, and repeats it while the message contains the failure
message, up to 10 attempts. Then it returns the last message it got.

### The Test

In the test we pass a lambda that loads the page and returns the text of the notification message
(`driver.findElement(By.id("flash")).getText()`), together with the failure message (`please try again`). Then we
assert that the message we end up with is the successful one.
