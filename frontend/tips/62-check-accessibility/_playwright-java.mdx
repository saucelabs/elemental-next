## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in Deque's `AxeBuilder` and `Rule` (from `com.deque.html.axe-core:playwright`), Playwright's `Page`
and JUnit extension, and JUnit. Lines 16 and 17 lists the axe rules that the page breaks on purpose.

### Setup and Teardown

Line 13 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### Scanning the Page

`scan` (lines 19 to 24) `AxeBuilder` adds the axe-core script to the page and runs it with `analyze`. `include` limits
the scan to the `#widgets` section, and the scan returns the results: the violations, the rules that passed, and the
ones to review. The helper keeps the rule id of each violation.

### The Tests

The first test loads the page with the issues and checks that the scan reports every known issue (`containsAll`). It
doesn't check that the scan reports only them: a newer version of axe can add rules, or report a rule as "incomplete"
when it can't be sure (like the color contrast of text that another element covers).

The second test loads the fixed page and checks that the scan reports no violations (`Set.of()`). This is the check to
use for our own pages.
