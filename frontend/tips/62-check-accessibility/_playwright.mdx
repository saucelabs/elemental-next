## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the Playwright test runner and Deque's `AxeBuilder` (from `@axe-core/playwright`). Line 5 lists
the axe rules that the page breaks on purpose.

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. There is no setup or teardown code to write.

### Scanning the Page

`scan` (lines 7 to 11) `AxeBuilder` adds the axe-core script to the page and runs it with `analyze`. `include` limits
the scan to the `#widgets` section, and the scan returns the results: the violations, the rules that passed, and the
ones to review. The helper keeps the rule id of each violation.

### The Tests

The first test loads the page with the issues and checks that the scan reports every known issue
(`expect.arrayContaining`). It doesn't check that the scan reports only them: a newer version of axe can add rules, or
report a rule as "incomplete" when it can't be sure (like the color contrast of text that another element covers).

The second test loads the fixed page and checks that the scan reports no violations (`[]`). This is the check to
use for our own pages.
