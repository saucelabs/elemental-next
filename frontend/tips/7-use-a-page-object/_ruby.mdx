## Code Walkthrough

### The Page Object

`DynamicLoadingPage` is a standard Ruby class. At the top of it we store the URL and the locators as constants.
Instead of using the two part 'how', 'what' approach, we are using a hash to store the locator type and its value
(e.g., `START_BUTTON = { css: '#start button' }`).

Next we use `attr_reader` to create a place to store the Selenium WebDriver instance for use throughout the class.
The `initialize` method receives it, visits the page, and verifies that we are in the right place.

Then each test step is a method that describes the behavior of the page: `start` clicks the start button,
`wait_for_finish` waits until the finish message is displayed, and `finish_text` returns its text.

At the bottom of the class we have a private method (`verify_page`). It's useful for the class to function, but
we don't want it to be available outside of the class.

### The Test

The `setup`, `teardown`, and `run` methods launch Firefox before the test and quit it afterward.

The test creates the Page Object (`DynamicLoadingPage.new(@driver)`), uses its methods to start the loading and
wait for it to finish, and asserts the text. Notice that the test has no locators or Selenium calls in it.
