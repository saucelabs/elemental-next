## Code Walkthrough

### The Page Object

`DynamicLoadingPage` stores the URL and the locators as constants (e.g.,
`private static final By START_BUTTON = By.cssSelector("#start button");`).

The constructor receives the Selenium WebDriver instance, stores it in a field, visits the page, and verifies that
we are in the right place by checking the page title.

Then each test step is a method that describes the behavior of the page: `start()` clicks the start button,
`waitForFinish()` uses an explicit wait (`WebDriverWait`) until the finish message is displayed, and
`finishText()` returns its text.

### The Test

`DynamicLoadingTest` launches Firefox in the `beforeEach` method and quits it in the `afterEach` method.

The test (`helloWorldIsDisplayed`) creates the Page Object, uses its methods to start the loading and wait for it
to finish, and asserts the text. Notice that the test has no locators or Selenium calls in it.
