## Code Walkthrough

### The Page Object

`DynamicLoadingPage` is a standard Python class. At the top of it we store the URL and the locators as class
constants (e.g., `START_BUTTON = (By.CSS_SELECTOR, '#start button')`). Each locator is a tuple with the locator
strategy and its value, which we unpack with `*` when calling `find_element`.

The constructor (`__init__`) receives the Selenium WebDriver instance, stores it, visits the page, and verifies
that we are in the right place by checking the page title.

Then each test step is a method that describes the behavior of the page: `start` clicks the start button,
`wait_for_finish` uses an explicit wait (`WebDriverWait`) until the finish message is displayed, and
`finish_text` returns its text.

### The Test

The `driver` fixture creates a Firefox instance before the test, `yield`s it to the test, and quits it
afterward.

The test (`test_hello_world_is_displayed`) creates the Page Object, uses its methods to start the loading and
wait for it to finish, and asserts the text. Notice that the test has no locators or Selenium calls in it.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
