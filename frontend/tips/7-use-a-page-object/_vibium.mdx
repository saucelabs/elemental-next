## Code Walkthrough

### The Page Object

<TipCode codePath={"7-use-a-page-object/code/vibium/pages/dynamicLoadingPage.js"} language={"js"}/>

The page object keeps the URL and the selectors of the page in one place (lines 3 to 5). It receives the Vibium page
in its constructor (lines 8 to 10).

`visit` (lines 12 to 15) goes to the page and checks its title. `start` (lines 17 to 19) clicks the start button.
`waitForFinish` (lines 21 to 23) waits up to 10 seconds for the text to be visible, and `finishText` (lines 25 to 27)
returns it.

### The Test

After the imports, the `beforeEach` hook (lines 9 to 13) starts the browser, creates the page object with the first
page of the browser, and visits the page. The `afterEach` hook (lines 15 to 17) closes the browser.

The test (lines 19 to 23) clicks the start button, waits for the loading to finish, and checks the text.

The test only talks to the page object. If the page changes, we update the page object and the test stays the same.
