## Code Walkthrough

### The Page Object

`DynamicLoadingPage` is a class in its own module. At the top of the file we store the URL and the locators as
constants (e.g., `const START_BUTTON = By.css("#start button");`).

The constructor receives the Selenium WebDriver instance. Since WebDriver calls in JavaScript are asynchronous and
a constructor can't be `async`, visiting the page and verifying its title happens in the `visit()` method.

Then each test step is a method that describes the behavior of the page: `start()` clicks the start button,
`waitForFinish()` waits until the finish message is located and visible (the element is only added to the page
once loading is done), and `finishText()` returns its text.

### The Test

The `beforeEach` hook launches Firefox, creates the Page Object, and visits the page. The `afterEach` hook quits
the browser.

The test (`displays Hello World! after loading`) uses the Page Object methods to start the loading and wait for it
to finish, and asserts the text. Notice that the test has no locators or Selenium calls in it.
