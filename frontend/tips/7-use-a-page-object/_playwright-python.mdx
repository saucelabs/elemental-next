## Code Walkthrough

### The Page Object

<TipCode codePath={"7-use-a-page-object/code/playwright-python/dynamic_loading_page.py"} language={"python"}/>

The page object is a class that receives the Playwright `page` (lines 5 to 8). It keeps the locators of the page in
one place: the start button and the text that shows when the loading finishes. A Playwright locator doesn't look for
the element until we use it, so we can create them in the constructor.

`visit` (lines 10 to 12) goes to the page and checks its title. `start` (lines 14 and 15) clicks the start button.

### The Test

After the imports, the `dynamic_loading` fixture (lines 6 to 10) creates the page object with the `page` that the
`pytest-playwright` plugin gives each test, and visits the page.

The test (lines 13 to 15) clicks the start button and checks the text. We don't need a method to wait for the text:
`to_have_text` waits until the text shows up, up to 10 seconds (the loading takes about 5).

The test only talks to the page object. If the page changes, we update the page object and the test stays the same.
