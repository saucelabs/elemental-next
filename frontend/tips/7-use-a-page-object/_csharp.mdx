## Code Walkthrough

### The Page Object

`DynamicLoadingPage` stores the URL and the locators as constants (e.g.,
`private static readonly By StartButton = By.CssSelector("#start button");`).

The constructor receives the Selenium WebDriver instance, stores it in a field (`_driver`), visits the page, and
verifies that we are in the right place by checking the page title.

Then each test step is a method that describes the behavior of the page: `Start()` clicks the start button,
`WaitForFinish()` uses an explicit wait (`WebDriverWait`) until the finish message is displayed, and
`GetFinishText()` returns its text.

### The Test

`DynamicLoadingTest` creates an instance of WebDriver with Firefox in the `SetUp()` method (marked with
`[TestInitialize]`), and closes it in the `TearDown()` method (marked with `[TestCleanup]`).

The test (`HelloWorldIsDisplayed()`) creates the Page Object, uses its methods to start the loading and wait for
it to finish, and asserts the text. Notice that the test has no locators or Selenium calls in it.
