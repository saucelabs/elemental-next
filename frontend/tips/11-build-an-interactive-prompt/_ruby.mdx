## Code Walkthrough

### The Prompt

`run_repl` receives the driver, and where to read the input from and write the output to (`$stdin` and `$stdout` by
default). We capture a `binding` before the loop, so every command is evaluated in the same context and can use
`driver` (and any variable declared by a previous command).

The `print` command is used instead of `puts` because we want `>> ` to appear on the same line as the input that we
are issuing. This gives us the look and feel of a prompt. And we use `gets` to take in input and `chomp` to remove
the carriage return character (e.g., `\n`) from it.

If the command is `q`, we say goodbye and leave the loop. Otherwise we `eval` it, print the result when there is
one, and rescue errors, printing their class and message and continuing.

At the bottom, when the file is run directly (`if __FILE__ == $PROGRAM_NAME`), we launch Firefox, start the prompt,
and quit the browser when the prompt ends.

### The Test

The test passes the commands with a `StringIO` and collects the output in another one. Then it checks that the title
was printed, that the missing element printed a `NoSuchElementError`, and that `q` ended the prompt.

### Using the Prompt

Run `ruby repl.rb` and type commands like `driver.get 'https://the-internet.herokuapp.com'` or
`driver.find_element(css: 'h1').text`. Type `q` to quit.
