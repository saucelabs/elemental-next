## Code Walkthrough

### The Prompt

Vibium calls return promises, so commands need to be `await`ed. To evaluate them we create an `AsyncFunction` with
the command as its body and `page` as its parameter (lines 6 to 14). First we try to use the command as an
expression (`return (${command});`), so we get its value back. If that's not valid JavaScript (e.g., it's a
statement), we use the command as the body as is.

`runRepl` receives the page, a function to read input, and a function to write output. In the loop we read a
command. If it is `q`, we say goodbye and leave the loop. Otherwise we evaluate it and print the result when there
is one. When there is an error we print its name and message and keep going.

At the bottom, when the file is run directly (`require.main === module`), we start the browser, read the commands
from the terminal with `readline`, and stop the browser when the prompt ends.

The test passes the commands from an array (`async () => commands.shift()`) and collects the output in another
array. Then it checks that the title was printed, that the missing element printed an error, and that `q` ended the
prompt.

### Using the Prompt

Run `npm run repl` and type commands like `page.go('https://the-internet.herokuapp.com')` or
`page.find('h1').text()`. Type `q` to quit.
