### Importing Libraries

Lines 3 to 8 pull in the JUnit annotations for parameterized tests, the Selenide methods we use (`open` and
`executeJavaScript`), and JUnit's `assertEquals`.

### Getting the Status Code

WebDriver doesn't give us the HTTP status code of a page, but the browser knows it. Lines 11 and 12 hold a script
that reads it from the browser's Navigation Timing API (`performance.getEntriesByType('navigation')`).

### The Test

Lines 14 to 20 run once for each status code in `@ValueSource`. Each run visits the page for that code, runs the
script with `executeJavaScript`, and checks that the browser got the code we expect. JavaScript numbers come back as a
`long`.
