## Code Walkthrough

### The Tests

Lines 14 and 15 give JUnit the status codes we want to check. `@ParameterizedTest` runs the test once for each value of
`@ValueSource`, with the code in `expected`. `@UsePlaywright` still gives each run a fresh `Page`, in the second
parameter.

Playwright doesn't need the Navigation Timing API: `page.navigate` returns the response of the main request of the page.
So we visit the page for the status code and check `response.status()`.
