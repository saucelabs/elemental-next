## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### Retrieving the Status Code

`statusCode()` casts the driver to `JavascriptExecutor`, executes the Navigation Timing script with
`executeScript`, and returns the result. Selenium returns JavaScript numbers as a `Long`.

### The Test

The test is a `@ParameterizedTest` (from the `junit-jupiter-params` dependency), so it runs once for each value in
`@ValueSource`. It visits the page that returns the code and asserts that `statusCode()` returns the same one.
