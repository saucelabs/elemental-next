## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward.

### Retrieving the Status Code

`status_code` executes the Navigation Timing script in the browser with `@driver.execute_script` and returns the
result.

### The Test

For each status code we `run` a test that visits the page that returns the code and asserts that `status_code`
returns the same one.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the `Gemfile` file.
