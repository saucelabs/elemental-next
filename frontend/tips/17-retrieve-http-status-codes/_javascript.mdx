## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### Retrieving the Status Code

`statusCode()` executes the Navigation Timing script in the browser with `driver.executeScript` and returns the
result.

### The Test

We create one test (`it`) for each status code with a `for` loop. Each test visits the page that returns the code
and asserts that `statusCode()` returns the same one.
