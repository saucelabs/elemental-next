## Code Walkthrough

### Setup and Teardown

The fixture (lines 5 to 9) starts the browser, gives each test its first page (tab), and closes the browser after the
test.

### The Tests

Line 12 uses `pytest.mark.parametrize` to run the test once for each status code we want to check.

Vibium can watch the network traffic of the page, so we don't need the Navigation Timing API.
`page.capture.response` starts listening for a response to the URL, runs the function we give it (visiting the page),
and returns the response once it arrives. Then we check its `status`.

### Executing the Test
