### Retrieving the Status Code

`StatusCode()` casts the driver to `IJavaScriptExecutor`, executes the Navigation Timing script with `ExecuteScript`,
and converts the result to a number.

the page that returns the code and asserts that `StatusCode()` returns the same one.
