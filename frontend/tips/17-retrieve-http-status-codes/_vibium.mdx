## Code Walkthrough

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Tests

Line 17 loops over the status codes we want to check, and creates one test for each.

Vibium can watch the network traffic of the page, so we don't need the Navigation Timing API. `page.capture.response`
starts listening for a response to the URL, runs the function we give it (visiting the page), and returns the response
once it arrives. Then we check `response.status()`.
