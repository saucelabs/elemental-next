## Code Walkthrough

### Reading the Status Code

Lines 3 to 6 are a helper that runs JavaScript in the page with `browser.execute`. It reads the `responseStatus` of the
navigation entry of the Navigation Timing API, which is the status code of the page we loaded. The function runs in the
browser, and WebdriverIO sends its result back to the test.

### The Tests

Line 9 loops over the status codes we want to check, and creates one test for each. Each test visits the page for the
status code and checks that the helper returns it.

### Executing the Test

The WebdriverIO test runner reads the browser and the test framework (Mocha) from the `wdio.conf.ts` file.
