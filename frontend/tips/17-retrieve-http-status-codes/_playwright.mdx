## Code Walkthrough

### The Tests

Line 3 loops over the status codes we want to check, and creates one test for each.

Playwright doesn't need the Navigation Timing API: `page.goto` returns the response of the main request of the page.
So we visit the page for the status code and check `response.status()`.

The response is `null` only when the navigation doesn't load a new document (e.g., a change of the URL fragment), so
we tell TypeScript it is there with `!`.
