## Code Walkthrough

### The Tests

Line 5 gives pytest the status codes we want to check. `pytest.mark.parametrize` runs the test once for each, with the
code in `expected`.

Playwright doesn't need the Navigation Timing API: `page.goto` returns the response of the main request of the page.
So we visit the page for the status code and check `response.status`.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
