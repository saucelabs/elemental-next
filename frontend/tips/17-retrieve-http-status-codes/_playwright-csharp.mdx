## Code Walkthrough

### The Tests

Lines 12 to 15 give MSTest the status codes we want to check. Each `[DataRow]` runs the test once, with the code in
`expected`.

Playwright doesn't need the Navigation Timing API: `Page.GotoAsync` returns the response of the main request of the
page. So we visit the page for the status code and check `response.Status`.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`playwright-csharp.csproj` in this case).
