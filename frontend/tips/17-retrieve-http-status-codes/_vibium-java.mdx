## Code Walkthrough

### Setup and Teardown

The `beforeEach` method (lines 17 to 21) starts the browser and gets its first page (tab). The `afterEach` method
(lines 23 to 28) closes the browser.

### The Tests

Lines 30 and 31 make it a parameterized test, which JUnit runs once for each status code we want to check. The
`junit-jupiter-params` library in the `pom.xml` file brings `@ParameterizedTest`.

Vibium can watch the network traffic of the page, so we don't need the Navigation Timing API.
`page.capture().response` starts listening for a response to the URL, runs the code we give it (visiting the page),
and returns the response once it arrives. Then we check `response.status()`.
