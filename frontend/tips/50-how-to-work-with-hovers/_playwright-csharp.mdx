## Code Walkthrough

### The Test

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 11 to 21 are
the test. The page has a few avatars, and hovering over one shows a caption with a link.

We find the first avatar and the caption inside it. Before hovering, the caption is hidden (`ToBeHiddenAsync`). Then
`HoverAsync` moves the mouse over the avatar, and the caption becomes visible (`ToBeVisibleAsync`).
