## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Test

After loading the page we find the first avatar (the first element with the `figure` class) and store it in a
variable. Then we find its caption by searching _within_ the avatar (`anAvatar.findElement(...)`), so we get the caption of that avatar
and not of any other one.

We assert that the caption is not displayed, trigger the hover with `driver.actions().move({origin: anAvatar}).perform()`, and assert that the caption is displayed.
