## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Test

After loading the page we find the first avatar (the first element with the `figure` class) and store it in a
variable. Then we find its caption by searching _within_ the avatar (`anAvatar.FindElement(...)`), so we get the caption of that avatar
and not of any other one.

We assert that the caption is not displayed, trigger the hover with `new Actions(_driver).MoveToElement(anAvatar).Perform()`, and assert that the caption is displayed.
