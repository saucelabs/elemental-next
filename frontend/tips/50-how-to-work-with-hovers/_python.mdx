## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Test

After loading the page we find the first avatar (the first element with the `figure` class) and store it in a
variable. Then we find its caption by searching _within_ the avatar (`an_avatar.find_element(...)`), so we get the caption of that avatar
and not of any other one.

We assert that the caption is not displayed, trigger the hover with `ActionChains(driver).move_to_element(an_avatar).perform()`, and assert that the caption is displayed.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
