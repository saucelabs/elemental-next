## Code Walkthrough

### Importing Libraries

Lines 3 to 10 pull in Vibium's classes to drive the browser, and JUnit to run the test.

### Setup and Teardown

The `beforeEach` method (lines 16 to 20) starts the browser and gets its first page (tab). The `afterEach` method
(lines 22 to 27) closes the browser.

### The Test

Lines 29 to 39 are the test itself.

The page shows avatars, and each one has a caption that only shows up when the mouse is over it. We find the first
avatar, and its caption inside it with `find`. At first, the caption is not visible.

Then `hover` moves the mouse over the avatar. We wait for the caption to be visible and check it.
