## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in `pytest` to run the test, and Vibium's `browser` to drive the browser.

### Setup and Teardown

The fixture (lines 5 to 9) starts the browser, gives the test its first page (tab), and closes the browser after the
test.

### The Test

Lines 12 to 20 are the test itself.

The page shows avatars, and each one has a caption that only shows up when the mouse is over it. We find the first
avatar, and its caption inside it with `find`. At first, the caption is not visible.

Then `hover` moves the mouse over the avatar. We wait for the caption to be visible and check it.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
