## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before the test and quit it afterward.

### The Test

After loading the page we find the first avatar (the first element with the `figure` class) and store it in a
variable. Then we find its caption by searching _within_ the avatar (`an_avatar.find_element(...)`), so we get the caption of that avatar
and not of any other one.

We assert that the caption is not displayed, trigger the hover with `@driver.action.move_to(an_avatar).perform`, and assert that the caption is displayed.
