## Code Walkthrough

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 13 to 22 are the test. The page has
a few avatars, and hovering over one shows a caption with a link.

We find the first avatar and the caption inside it. Before hovering, the caption is hidden (`isHidden`). Then `hover`
moves the mouse over the avatar, and the caption becomes visible (`isVisible`).
