## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Setup and Teardown

The `beforeEach` method (lines 8 to 11) starts the browser and gets its first page (tab). The `afterEach` method
(lines 13 to 15) closes the browser.

### The Test

Lines 17 to 26 are the test itself.

The page shows avatars, and each one has a caption that only shows up when the mouse is over it. We find the first
avatar, and its caption inside it with `find`. At first, the caption is not visible.

Then `hover` moves the mouse over the avatar. We wait for the caption to be visible and check it.
