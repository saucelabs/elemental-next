## Code Walkthrough

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Test

After loading the page we find the first avatar (the first element with the `figure` class) and store it in a
variable. Then we find its caption by searching _within_ the avatar (`anAvatar.findElement(...)`), so we get the caption of that avatar
and not of any other one.

We assert that the caption is not displayed, trigger the hover with `new Actions(driver).moveToElement(anAvatar).perform()`, and assert that the caption is displayed.
