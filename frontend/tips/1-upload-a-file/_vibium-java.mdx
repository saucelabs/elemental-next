## Code Walkthrough

### Importing Libraries

Lines 3 to 12 pull in Vibium's `Browser`, `Page` and `Vibium` classes to drive the browser, JUnit to run the test,
`File` to build the path to the file, and `List` to pass it to the file input.

### Setup and Teardown

Lines 15 and 16 declare the browser and the page, so every method of the class can use them.

The `beforeEach` method (lines 18 to 22) runs before each test. It starts the browser with `Vibium.start()` and gets
its first page (tab) with `browser.page()`. The `afterEach` method (lines 24 to 29) runs after each test and closes the
browser with `browser.stop()`.

### The Test

Lines 31 to 42 are the test itself.

First we set the name of the file we'd like to upload. It's a text file called `some-file.txt` in the current working
directory. We build the full path to it and store it in `path`.

Next we visit the page with the upload form. `setFiles` sets the file on the file input, without opening the operating
system dialog. Then we click the submit button.

After the file is uploaded, the page shows the name of the file. We read that text and check that it matches the name
we expect.
