## Code Walkthrough

### Importing Libraries

Lines 1 to 3 pull in the `assert` module for the assertion, the `path` module to build the path to the file, and
Vibium's `browser` to drive the browser.

### Setup and Teardown

After creating a `describe` to group our tests, lines 9 to 16 start and stop the browser.

The `beforeEach` method runs before each test. It starts the browser with `browser.start()` and gets its first page
(tab) with `bro.page()`. The `afterEach` method runs after each test and closes the browser with `bro.stop()`.

### The Test

Lines 18 to 28 are the test itself.

First we set the name of the file we'd like to upload. It's a text file called `some-file.txt` in the current working
directory. We build the full path to it and store it in `filePath`.

Next we visit the page with the upload form. `setFiles` sets the file on the file input, without opening the operating
system dialog. Then we click the submit button.

After the file is uploaded, the page shows the name of the file. We read that text and check that it matches the name
we expect.
