## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the Playwright test runner (`test` and `expect` from `@playwright/test`) and the `path` module
to build the path to the file.

### Setup and Teardown

Playwright Test handles the browser for us. Each test receives a `page` (a fresh browser tab) as a fixture, and
Playwright closes it when the test ends. There is no setup or teardown code to write.

### The Test

Lines 4 to 13 are the test itself.

First we set the name of the file we'd like to upload. It's a text file called `some-file.txt` in the current working
directory. We build the full path to it and store it in `filePath`.

Next we visit the page with the upload form. `setInputFiles` sets the file on the file input, without opening the
operating system dialog. Then we click the submit button.

After the file is uploaded, the page shows the name of the file. `toHaveText` checks that it matches the name we
expect. It waits for the text to appear, so we don't need an explicit wait.
