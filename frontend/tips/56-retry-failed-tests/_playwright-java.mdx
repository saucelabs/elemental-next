## Code Walkthrough

### Retrying the Test

JUnit doesn't retry failed tests, but Maven Surefire, the plugin that runs them, can. `rerunFailingTestsCount` in the
`pom.xml` file runs a failed test up to 9 more times before it counts as failed. It applies to every test of the
project. A test that passes on a retry shows up as a "flake" in the results.

### The Test

`@UsePlaywright` gives each test a fresh browser tab in its `Page` parameter. Lines 14 to 20 are the test. The page
shows the successful message only some of the time, so the test is flaky on purpose. It visits the page and checks that
the notification says `Action successful`.

Retries hide flaky tests, so use them with care: keep the count low, and fix the cause of the flakiness when you can.
