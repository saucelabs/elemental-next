## Code Walkthrough

### The Test

In RSpec, test files are referred to as 'specs'. The setup and teardown live in `spec/spec_helper.rb`: before each
spec it launches Firefox, and after each spec it quits it (the `.rspec` file loads it for every spec). The spec loads
the page and asserts that the message is the successful one.

### Retrying

RSpec can remember which specs failed: with `example_status_persistence_file_path` set in `spec_helper.rb`, it
stores the status of each spec in a file (`examples.txt`). Then, `rspec --only-failures` runs just the specs that
failed last time.

`run_with_retries.rb` puts it together. It runs all the specs, and while there are failures, it runs only the failed
ones again, up to 9 more times.
