## Code Walkthrough

### A Flaky Test

Lines 12 to 16 open the page and check that the notification says `Action successful`. The page shows that message
only some of the time, so this test fails now and then, on purpose.

`shouldHave` waits up to 4 seconds for the message, but that doesn't help here: the message changes only when the page
is loaded again.

### Retrying the Failed Test

Maven Surefire, which runs the tests, can run a failed test again. Line 41 of the `pom.xml` sets
`rerunFailingTestsCount` to 9, so a failed test runs up to 9 more times. If it passes in one of them, Surefire reports
it as a flake, and the build passes.
