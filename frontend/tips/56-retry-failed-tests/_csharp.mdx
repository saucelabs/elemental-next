## Code Walkthrough

### The Test

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it. `NotificationMessage` loads the page and asserts that the
message is the successful one.

### Retrying

MSTest comes with a `[Retry]` attribute. With `[Retry(9)]`, MSTest runs the test again (including the setup and
cleanup, so with a new browser) up to 9 more times when it fails.
