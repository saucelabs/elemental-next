## Code Walkthrough

### Importing Libraries

Lines 1 and 2 pull in the `assert` module and Vibium's `browser` to drive the browser.

### Retrying the Test

The page shows the successful message only some of the time, so the test is flaky on purpose. Line 7 tells Mocha to
run a failing test again, up to 9 more times. Mocha also runs the `beforeEach` and `afterEach` hooks again, so each
try gets a new browser.

### Setup and Teardown

The `beforeEach` method (lines 12 to 15) starts the browser and gets its first page (tab). The `afterEach` method
(lines 17 to 19) closes the browser.

### The Test

Lines 21 to 25 visit the page and check that the notification says `Action successful`. When it doesn't, the test
fails and Mocha runs it again.
