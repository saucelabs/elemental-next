## Code Walkthrough

### Retrying the Test

Playwright Test can run a failed test again. In `playwright.config.ts`, `retries: 9` (line 5) runs a failed test up to
9 more times before it counts as failed. When a test passes after a retry, Playwright marks it as `flaky` in the
results, so it doesn't go unnoticed.

We can also set the retries from the command-line (`npx playwright test --retries 9`) or for a group of tests with
`test.describe.configure({retries: 9})`.

### The Test

Lines 5 to 10 are the test. The page shows the successful message only some of the time, so the test is flaky on
purpose. It visits the page and checks that the notification says `Action successful`.

Retries hide flaky tests, so use them with care: keep the count low, and fix the cause of the flakiness when you can.
