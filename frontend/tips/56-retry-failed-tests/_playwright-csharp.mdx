## Code Walkthrough

### Retrying the Test

MSTest can run a failed test again. The `[Retry(9)]` attribute on line 14 runs the test up to 9 more times before it
counts as failed. It only applies to the test that has it.

### The Test

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Lines 13 to 21 are
the test. The page shows the successful message only some of the time, so the test is flaky on purpose. It visits the
page and checks that the notification says `Action successful`.

Retries hide flaky tests, so use them with care: keep the count low, and fix the cause of the flakiness when you can.
