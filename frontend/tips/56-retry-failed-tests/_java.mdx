`notificationMessage` loads the page and asserts that the message is the successful one.

### Retrying

Maven Surefire (the plugin that runs the tests in `mvn test`) can rerun failing tests. We configure it in the
`pom.xml` with `<rerunFailingTestsCount>9</rerunFailingTestsCount>`, so it runs a failed test again up to 9 more
times. When a rerun passes, the summary reports the test as a flake (e.g., `Flakes: 1`).

You can also set it from the command-line, with `mvn test -Dsurefire.rerunFailingTestsCount=9`.
