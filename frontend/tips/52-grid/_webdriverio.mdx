## Code Walkthrough

### Configuring the Grid

In WebdriverIO, where the browser runs is part of the configuration, not of the test.

<TipCode codePath={"52-grid/code/webdriverio/wdio.conf.ts"} language={"ts"}/>

- Line 1 reads the address of the Grid from the `GRID_URL` environment variable, or uses `http://localhost:4444`.
- Line 5 asks the Grid for its status, to know if it is running. The configuration is a module, so it can `await` at
  the top level.
- Lines 9 to 14 point WebdriverIO to the Grid when it is running: its protocol, host, port and path. With them,
  WebdriverIO sends the session to the Grid instead of starting a local browser. The Grid then starts Chrome on one of
  its nodes.

### The Test

The `before` hook (lines 5 to 10) skips the test when the Grid is not running, with a message that says how to run
it. The test (lines 12 to 15) loads the page and checks the title. It is the same test we would run without a Grid.
