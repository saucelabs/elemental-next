## Code Walkthrough

### Importing Libraries

Lines 3 to 17 pull in Selenide's `Configuration`, the JUnit annotations, Java's HTTP client, and the Selenide methods
we use (`open`, `closeWebDriver`, `webdriver` and the `title` condition).

### Checking the Grid

Lines 20 and 21 read the address of the Grid from the `GRID_URL` environment variable, or use `http://localhost:4444`.

Lines 23 to 30 call the `/status` endpoint of the Grid, and return `true` when it answers. If the Grid is not running,
the `setUp` method skips the test (`Assumptions.assumeTrue`) instead of failing it.

### Setup and Teardown

Line 36 sets `Configuration.remote` to the Grid. From then on, Selenide asks the Grid for the browser (Chrome, by
default) instead of starting it on our computer. Lines 39 to 42 close the browser after the test, which ends the
session on the Grid.

### The Test

Lines 44 to 48 open the page and check its title. The test is the same as one that runs on our computer: only the
configuration changes.
