## Code Walkthrough

### Setup and Teardown

`grid_is_running` checks if the Grid answers on its `/status` endpoint.

The `driver` fixture skips the test when the Grid is not running. Otherwise, it connects to the Grid with
`webdriver.Remote`, passing the Grid's address and the options of the browser we want (`webdriver.FirefoxOptions()`),
and `yield`s the driver to the test. Once the test is done, it quits the browser.

### The Test

`test_page_loaded` loads the page and asserts its title, just like a local test.

### Executing the Test

First, start a Selenium Grid (see Part 1). Then, before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
