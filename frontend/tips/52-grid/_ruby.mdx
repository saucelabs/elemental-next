## Code Walkthrough

### Setup and Teardown

`grid_running?` checks if the Grid answers on its `/status` endpoint. When it doesn't, the script prints a message
and exits without running the test.

The `setup` method connects to the Grid with `Selenium::WebDriver.for(:remote, ...)`, passing the Grid's address and
the options of the browser we want (`Selenium::WebDriver::Options.firefox`). The `teardown` method quits the browser.

### The Test

The test loads the page and asserts its title, just like a local test.

### Executing the Test

First, start a Selenium Grid (see Part 1). Then, before executing the test, we need to make sure the required dependencies are declared on the `Gemfile` file.
