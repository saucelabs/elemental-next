## Code Walkthrough

### Setup and Teardown

`gridIsRunning` checks if the Grid answers on its `/status` endpoint.

The `beforeEach` hook skips the test (`this.skip()`) when the Grid is not running. Otherwise, it tells the `Builder`
to use the Grid (`usingServer(GRID_URL)`) with the options of the browser we want (`new firefox.Options()`). The
`afterEach` hook quits the browser.

### The Test

The test loads the page and asserts its title, just like a local test.

### Executing the Test

First, start a Selenium Grid (see Part 1). Then, before executing the test, we need to make sure the required dependencies are declared on the `package.json` file.
