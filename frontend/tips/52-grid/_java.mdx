## Code Walkthrough

### Setup and Teardown

`gridIsRunning` checks if the Grid answers on its `/status` endpoint.

The `beforeEach` method skips the test (`Assumptions.assumeTrue`) when the Grid is not running. Otherwise, it connects
to the Grid with a `RemoteWebDriver`, passing the Grid's address and the options of the browser we want
(`new FirefoxOptions()`). The `afterEach` method quits the browser.

### The Test

`pageLoaded` loads the page and asserts its title, just like a local test.

### Executing the Test

First, start a Selenium Grid (see Part 1). Then, before executing the test, we need to make sure the required dependencies are declared on the `pom.xml` file.
