## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Tests

The first test loads the page and checks that the heading (`h3`) is one of the A/B test variations. Then it adds the
opt-out cookie with `driver.manage().addCookie({name: "optimizelyOptOut", value: "true"})`, refreshes the page, and
checks that the heading now says `No A/B Test`.

The second test loads the home page first. A cookie can only be added for the domain the browser is on, so we need to
visit a page of the site before adding it. Then it adds the cookie and visits the A/B test page.

The third test appends `?optimizely_opt_out=true` to the URL. It waits for the JavaScript alert it triggers
(`until.alertIsPresent()`) and dismisses it. The page keeps loading after that, so it also waits for the heading
before checking it.
