## Code Walkthrough

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward.

### The Tests

The first `run` block loads the page and checks that the heading (`h3`) is one of the A/B test variations. Then it
adds the opt-out cookie with `@driver.manage.add_cookie(name: 'optimizelyOptOut', value: 'true')`, refreshes the
page, and checks that the heading now says `No A/B Test`.

The second one loads the home page first. A cookie can only be added for the domain the browser is on, so we need to
visit a page of the site before adding it. Then it adds the cookie and visits the A/B test page.

The third one appends `?optimizely_opt_out=true` to the URL. It waits for the JavaScript alert it triggers and
dismisses it. The page keeps loading after that, so it also waits for the heading before checking it.
