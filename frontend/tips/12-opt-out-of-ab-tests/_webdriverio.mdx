## Code Walkthrough

### The Opt-out Cookie

Line 3 sets the cookie that tells the site to skip the A/B test (`optimizelyOptOut` set to `true`), with the `domain`
of the site.

WebdriverIO uses the same browser for all the tests of a file, so the `afterEach` hook (lines 6 to 8) deletes the
cookies after each test.

### Example 1: Forge the Cookie on the Target Page

Lines 10 to 18 visit the A/B test page and check that it shows one of the two variants. Then we add the cookie with
`browser.setCookies`, reload the page, and check that the heading says `No A/B Test`.

### Example 2: Forge the Cookie Before Visiting the Page

Lines 20 to 25 add the cookie first and then visit the page. Since the cookie has a `domain`, WebdriverIO can add it
before we visit the site, so we skip the extra page load that Selenium needs. The page shows `No A/B Test` right away.

### Example 3: Append the Opt-out Parameter to the URL

Lines 27 to 32 visit the page with `?optimizely_opt_out=true` in the URL. The site then shows a JavaScript alert.
`browser.once('dialog')` dismisses the next alert. Then we check the heading.
