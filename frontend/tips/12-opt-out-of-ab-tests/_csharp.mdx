## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Tests

`ForgeCookieOnTargetPage` loads the page and checks that the heading (`h3`) is one of the A/B test variations
(`CollectionAssert.Contains`). Then it adds the opt-out cookie with
`_driver.Manage().Cookies.AddCookie(new Cookie("optimizelyOptOut", "true"))`, refreshes the page, and checks that the
heading now says `No A/B Test`.

`ForgeCookieBeforeVisitingTargetPage` loads the home page first. A cookie can only be added for the domain the
browser is on, so we need to visit a page of the site before adding it. Then it adds the cookie and visits the A/B
test page.

`UrlParameter` appends `?optimizely_opt_out=true` to the URL. It waits for the JavaScript alert it triggers
(ignoring `NoAlertPresentException` until it shows up) and dismisses it. The page keeps loading after that, so it
also waits for the heading before checking it.
