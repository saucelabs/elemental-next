## Code Walkthrough

### The Opt-out Cookie

Lines 15 and 16 set the cookie that tells the site to skip the A/B test (`optimizelyOptOut` set to `true`). Playwright
needs to know which site the cookie is for, so we give it the URL of the site.

`@UsePlaywright` gives each test a `Page`. Cookies belong to its browser context (the browser session), which we get
with `page.context()`.

### Example 1: Forge the Cookie on the Target Page

Lines 19 to 27 visit the A/B test page and check that it shows one of the two variants (with a regular expression). Then
we add the cookie with `addCookies`, reload the page, and check that the heading says `No A/B Test`.

### Example 2: Forge the Cookie Before Visiting the Page

Lines 30 to 35 add the cookie first and then visit the page. Since the cookie has a URL, Playwright can add it before we
visit the site, so we skip the extra page load that Selenium needs. The page shows `No A/B Test` right away.

### Example 3: Append the Opt-out Parameter to the URL

Lines 38 to 43 visit the page with `?optimizely_opt_out=true` in the URL. The site then shows a JavaScript alert. The
`onDialog` handler dismisses it. Playwright dismisses dialogs on its own when nobody listens for them, but the handler
makes it clear. Then we check the heading.
