## Code Walkthrough

### Importing Libraries

Lines 3 to 14 pull in the JUnit annotations, the Selenium `Cookie` class, and the Selenide methods and conditions we
use (e.g., `open`, `$`, `refresh`, `exactText`).

### One Browser per Test

Selenide opens the browser on the first `open()` and, by default, keeps it open for the next tests. Here each test
needs a browser without cookies, so line 16 adds `BrowserPerTestStrategyExtension`, which closes the browser after
each test.

### Example 1: Forge the Cookie on the Target Page

Lines 19 to 25 visit the A/B test page and check that the heading is one of the two variants
(`oneOfExactTexts`). Then we add the opt-out cookie (`optimizelyOptOut` set to `true`) through the WebDriver that
Selenide uses (`getWebDriver()`), reload the page with `refresh()`, and check that the heading says `No A/B Test`.

### Example 2: Forge the Cookie Before Visiting the Page

Lines 28 to 33 open the home page first, since the browser accepts cookies only for the site it is on. Then we add
the cookie, visit the A/B test page, and the heading says `No A/B Test` right away.

### Example 3: Append the Opt-out Parameter to the URL

Lines 36 to 40 visit the page with `?optimizely_opt_out=true` in the URL. The site then shows a JavaScript alert.
`switchTo().alert()` waits for it, and `dismiss()` closes it. Then we check the heading.

Like every Selenide check, `shouldHave` waits for the condition (up to 4 seconds by default), so we don't need an
explicit wait.
