## Code Walkthrough

### The Opt-out Cookie

Line 4 sets the cookie that tells the site to skip the A/B test (`optimizelyOptOut` set to `true`), with the `domain`
of the site.

The fixture (lines 7 to 11) starts the browser, gives each test its first page (tab), and closes the browser after the
test.

### Example 1: Forge the Cookie on the Target Page

Lines 14 to 22 visit the A/B test page and check that it shows one of the two variants. Then we add the cookie to the
context of the page (`page.context.set_cookies`), reload the page, and check that the heading says `No A/B Test`.

### Example 2: Forge the Cookie Before Visiting the Page

Lines 25 to 29 add the cookie first and then visit the page. Since the cookie has a `domain`, Vibium can add it before
we visit the site, so we skip the extra page load that Selenium needs. The page shows `No A/B Test` right away.

### Example 3: Append the Opt-out Parameter to the URL

Lines 32 to 36 visit the page with `?optimizely_opt_out=true` in the URL. The site then shows a JavaScript alert.
`page.on_dialog('dismiss')` dismisses it. Then we check the heading.
