## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Tests

`test_forge_cookie_on_target_page` loads the page and checks that the heading (`h3`) is one of the A/B test
variations. Then it adds the opt-out cookie with `driver.add_cookie({'name': 'optimizelyOptOut', 'value': 'true'})`,
refreshes the page, and checks that the heading now says `No A/B Test`.

`test_forge_cookie_before_visiting_target_page` loads the home page first. A cookie can only be added for the
domain the browser is on, so we need to visit a page of the site before adding it. Then it adds the cookie and visits
the A/B test page.

`test_url_parameter` appends `?optimizely_opt_out=true` to the URL. It waits for the JavaScript alert it triggers
(`EC.alert_is_present()`) and dismisses it. The page keeps loading after that, so it also waits for the heading
before checking it.
