## Code Walkthrough

### Setup and Teardown

The `setup` method (lines 5 to 10) turns on WebDriver BiDi with `web_socket_url`, and starts Chrome. The `teardown`
method (lines 12 to 14) quits the browser, and `run` (lines 16 to 21) calls them around the test.

### The Test

The test (lines 23 to 42) adds two handlers: `add_console_message_handler` (line 26) gets each console message, and
`add_javascript_error_handler` (line 27) gets each JavaScript error that the page does not catch. They keep them in
two lists.

Then it loads [the Network & Console page](https://the-internet.herokuapp.com/network_console) and clicks two
buttons: one logs a message, a warning and an error to the console, the other throws a JavaScript error. The handlers
run outside the page, so the test waits up to 5 seconds until they have the 3 console messages and the error. At the
end, it checks the level and text of each message (they can arrive in any order) and the text of the error.
