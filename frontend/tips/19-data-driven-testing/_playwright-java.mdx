## Code Walkthrough

### Reading the Data

The data lives in a CSV file, `user_data.csv`, next to the `pom.xml` file. Each row is a user: the type of account, the
username, the password and the message we expect after logging in.

JUnit reads the file for us. `@CsvFileSource` (line 14) points to it, relative to the folder the tests run from, and
`numLinesToSkip = 1` skips the first line (the header).

### The Tests

`@ParameterizedTest` (line 13) runs the test once for each row of the file, and passes its values as the first four
arguments of the test. `name = "{0}"` names each run after the first value (the type of account), so a failure points to
the row that caused it. `@UsePlaywright` gives each run a fresh `Page`, in the last parameter.

Each test logs in with the username and password of its row, and checks that the message on the page contains the
expected text.
