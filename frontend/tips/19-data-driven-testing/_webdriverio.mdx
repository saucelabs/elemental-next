## Code Walkthrough

### Loading the Data

Lines 5 to 11 read the test data from `user_data.csv`. The first line of the file is the header. We split the file into
lines and each line into values, and turn each row into an object with the header names as keys (e.g.,
`user.username`). The file has one row per user: the account type, the user name, the password, and the message the
site should show.

### The Tests

Line 14 loops over the users and creates one test for each, named after the account type.

Each test visits the login page, fills in the user name and the password, and submits the form. Then it checks that
the notification contains the message for that user. `toHaveText` with `expect.stringContaining` waits until the
notification shows the expected text.

To test another user, we add a row to the CSV file. The test code stays the same.
