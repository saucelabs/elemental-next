## Code Walkthrough

### Reading the Data

The data lives in a CSV file, `user_data.csv`, next to the test. Each row is a user: the type of account, the
username, the password and the message we expect after logging in. The project file copies it to the output
directory, where the tests run.

Lines 14 to 19 read the file. `UserData` skips the first line (the header), splits each row by commas, and returns one
array of values per user.

### The Tests

The test class extends `PageTest`, which gives each test a fresh browser tab in the `Page` property. Line 22 gives
MSTest the users: `[DynamicData]` runs the test once for each array that `UserData` returns, and passes its values
as the arguments of the test. MSTest lists them as separate tests, so a failure points to the row that caused it.

Each test logs in with the username and password of its row, and checks that the message on the page contains the
expected text.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`playwright-csharp.csproj` in this case).

run the test by executing `dotnet test` from the command-line.
