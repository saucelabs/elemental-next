## Code Walkthrough

### Reading the Data

JUnit can read the data for us. The CSV file lives in `src/test/resources`, so it's on the test classpath, and
`@CsvFileSource(resources = "/user_data.csv", numLinesToSkip = 1)` reads it, skipping the header. This annotation
comes from the `junit-jupiter-params` dependency.

### Setup and Teardown

The `beforeEach` method launches Firefox before each test, and the `afterEach` method quits it.

### The Test

`notificationText` uses an explicit wait (`WebDriverWait`) until the notification is visible and returns its text.

`login` is a `@ParameterizedTest` that receives one argument for each column of the CSV file, so JUnit runs it once
for each row. `name = "{0}"` names each run after the account type. The test logs in with the user's credentials and
asserts that the notification starts with the expected message.
