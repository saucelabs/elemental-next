## Code Walkthrough

### Reading the Data

`user_data` reads `user_data.csv` with Ruby's `CSV` library. With `headers: true` it uses the first row as the keys,
and `header_converters: :symbol` turns them into symbols, so each user is a Hash (e.g., `user[:username]`). Since
Ruby 3.4, `csv` is a bundled gem, so we add it to the `Gemfile`.

### Setup and Teardown

The `setup`, `teardown`, and `run` methods launch Firefox before each test and quit it afterward.

### The Test

`notification_text` uses an explicit wait (`Selenium::WebDriver::Wait`) until the notification is displayed and
returns its text.

We iterate through each user and `run` a test that logs in with the user's credentials and asserts that the
notification starts with the expected message.
