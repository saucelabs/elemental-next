## Code Walkthrough

### Reading the Data

The data lives in a CSV file, `user_data.csv`, next to the test. Each row is a user: the type of account, the
username, the password and the message we expect after logging in.

Lines 7 to 9 read the file with the `csv` module. `csv.DictReader` turns each row into a dictionary, using the first
line (the header) for the keys.

### The Tests

Line 12 gives pytest the users. `pytest.mark.parametrize` runs the test once for each, named after the type of account
(`ids`). pytest lists them as separate tests, so a failure points to the row that caused it.

Each test logs in with the username and password of its row, and checks that the message on the page contains the
expected text.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.

Install the libraries with `pip install -r requirements.txt` and the browser with `playwright install chromium`. Then
run the test by executing `pytest data_driven.py` from the command-line.
