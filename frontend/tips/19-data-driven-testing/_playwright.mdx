## Code Walkthrough

### Reading the Data

The data lives in a CSV file, `user_data.csv`, next to the tests. Each row is a user: the type of account, the
username, the password and the message we expect after logging in.

Lines 5 to 11 read the file with `fs`, split it into lines and values, and turn each row into an object, using the
first line (the header) for the keys.

### The Tests

Lines 13 to 22 loop over the users and create one test for each, named after the type of account. Playwright Test
lists them as separate tests, so a failure points to the row that caused it.

Each test logs in with the username and password of its row, and checks that the message on the page contains the
expected text.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the `package.json` file.
