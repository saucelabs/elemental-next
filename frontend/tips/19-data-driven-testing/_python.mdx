## Code Walkthrough

### Reading the Data

`user_data` opens `user_data.csv` (next to the test file) and reads it with `csv.DictReader`, which uses the first row
as the keys. So each user is a dictionary (e.g., `user['username']`).

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Test

`notification_text` uses an explicit wait (`WebDriverWait`) until the notification is visible and returns its text.

`test_login` is parametrized with the user data (`@pytest.mark.parametrize('user', user_data(), ...)`), so pytest
runs it once for each user. The `ids` argument names each run after the account type (e.g.,
`test_login[bad_password]`), which makes the results easier to read. The test logs in with the user's credentials
and asserts that the notification starts with the expected message.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
