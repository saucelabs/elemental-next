### Setup and Teardown

The `beforeEach` method (lines 16 to 20) starts the browser and gets its first page (tab). The `afterEach` method
(lines 22 to 27) closes the browser.

### The Tests

Lines 29 and 30 make it a parameterized test. `@CsvFileSource` reads the file, skips the header line, and runs the
test once for each row, passing the values of the row as the parameters of the method. Each run is named after the
account type. The `junit-jupiter-params` library in the `pom.xml` file brings these annotations.

Each test visits the login page, fills in the user name and the password, and submits the form. Then it checks that
the notification starts with the message for that user. `page.find` waits for the notification to show up.

To test another user, we add a row to the CSV file. The test code stays the same.
