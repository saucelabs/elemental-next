## Code Walkthrough

### Reading the Data

`UserData` reads the lines of `user_data.csv`, skips the header, and splits each line into the values for one test
run. The project file copies the CSV file to the output directory (`CopyToOutputDirectory`), where the tests run.

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Test

`NotificationText` uses an explicit wait (`WebDriverWait`) until the notification is displayed and returns its text.

`Login` receives one argument for each column of the CSV file. `[DynamicData(nameof(UserData))]` tells MSTest to run
it once for each row returned by `UserData`. The test logs in with the user's credentials and asserts that the
notification starts with the expected message.
