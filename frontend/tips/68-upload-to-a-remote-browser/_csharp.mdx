## Code Walkthrough

### Setup and Teardown

The `SetUp` method (lines 18 to 42) marks the test as inconclusive when the Sauce Labs credentials are not set.
Otherwise, it asks for the latest Chrome on Windows 11. The `sauce:options` carry the credentials and the name of the
test on Sauce Labs. It connects with `RemoteWebDriver`, and line 41 sets the file detector,
`FileDetector = new LocalFileDetector()`. Without it, C# types the path as it is. The `TearDown` method (lines 44 to
48) quits the browser.

To use a Selenium Grid instead, only the address changes (e.g., `http://localhost:4444`), and the `sauce:options`
are not needed.

### The Test

`UploadFile` (lines 50 to 59) builds the full path of `some-file.txt`, which the project file copies to the output
folder. Then it visits [the upload page](https://the-internet.herokuapp.com/upload), types the path of the file in the file
input, submits the form, and checks that the page shows the name of the file. When the test types the path (line 56), the file detector sends the file to the remote machine.

### Executing the Test

Set the `SAUCE_USERNAME` and `SAUCE_ACCESS_KEY` environment variables. Then, before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`csharp.csproj` in this case). It also copies `some-file.txt` to the output folder.
