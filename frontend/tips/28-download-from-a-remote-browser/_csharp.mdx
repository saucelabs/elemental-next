## Code Walkthrough

### Setup and Teardown

The `SetUp` method (lines 20 to 44) skips the test (`Assert.Inconclusive`) when the Sauce Labs credentials are not
set. Otherwise, it asks for the latest Chrome on Windows 11, and sets `EnableDownloads = true`. This sends the
`se:downloadsEnabled` capability, so Sauce Labs keeps the files the browser downloads. The `sauce:options` carry the
credentials and the name of the test on Sauce Labs. Then it connects with a `RemoteWebDriver`. The `TearDown` method
(lines 46 to 50) quits the browser.

To use a Selenium Grid instead, only the address changes (e.g., `http://localhost:4444`), and the `sauce:options`
are not needed.

The `_driver` field is a `RemoteWebDriver` and not an `IWebDriver`, since the download methods are part of
`RemoteWebDriver`.

### The Test

`DownloadFile` (lines 52 to 75) visits the page, saves the name of the first download link, and clicks it.

- Lines 61 and 62 wait up to 10 seconds until the file shows up in `GetDownloadableFiles()`, the list of files the
  browser downloaded on the remote machine.
- Lines 65 to 74 copy the file with `DownloadFile(fileName, targetDir)` to a temp folder on our machine, check that it
  is not empty, and delete the temp folder.

### Executing the Test

Set the `SAUCE_USERNAME` and `SAUCE_ACCESS_KEY` environment variables (see Part 1). Then, before executing the test,
we need to make sure the required dependencies are declared on the project file (e.g., `csharp.csproj` in this case).
