## Code Walkthrough

### Importing Libraries

Lines 1 to 4 pull in the `assert`, `fs` and `path` modules, and Vibium's `browser` to drive the browser.

### Setup and Teardown

Line 9 sets the path of a `tmp` folder for the downloaded file.

The `beforeEach` method (lines 11 to 15) creates the folder, starts the browser and gets its first page (tab). The
`afterEach` method (lines 17 to 20) closes the browser and deletes the folder with the files in it.

### The Test

Lines 22 to 33 are the test itself.

Vibium doesn't need any browser setting to download files. It catches each download, and `page.onDownload` lets us
know when one starts.

After visiting the page, we wrap `page.onDownload` in a promise, and then click the first download link. When the
download starts, the promise gives us a `download` object.

We save the file with `saveAs` into the `tmp` folder, using the name the server suggests.

Finally, we check that the file is not empty.
