## Code Walkthrough

### Importing Libraries

Lines 1 to 5 pull in the WebdriverIO globals (`browser` and `$$`), the `assert`, `fs` and `path` modules, and the
download folder that we set in `wdio.conf.ts`.

### Configuring the Browser

To skip the download dialog, Chrome needs two settings, which we set in `wdio.conf.ts`. `download.default_directory`
is the folder where Chrome saves the files (a `tmp` folder in the current directory), and
`download.prompt_for_download: false` tells Chrome to save the file without asking.

### Setup and Teardown

Lines 8 to 14 create the download folder before each test and delete it, with the files in it, after each test.

### The Test

Lines 16 to 26 are the test itself.

After visiting the page, we click the first download link. `$$` finds all the links, and we take the first one.

Then we wait up to 5 seconds for the file. While Chrome downloads a file, it uses a temporary `.crdownload` file, so
we wait for a file without that extension.

Finally, we check that the downloaded file is not empty.

### Executing the Test

The WebdriverIO test runner reads the browser and the test framework (Mocha) from the `wdio.conf.ts` file.
