## Code Walkthrough

### Importing Libraries

Lines 3 to 11 pull in JUnit's `assertTrue`, Playwright's `Download` and `Page` classes and its JUnit extension, the
`java.nio.file` classes to check the downloaded file, and JUnit to run the test.

### Setup and Teardown

Line 13 adds `@UsePlaywright` to the test class. It's Playwright's JUnit extension: it starts the browser and gives each
test that asks for a `Page` parameter a fresh browser tab, which it closes when the test ends. There is no setup or
teardown code to write.

### The Test

Lines 17 to 27 are the test itself.

Playwright doesn't need any browser setting to download files. It catches each download as a download event.

After visiting the page, we click the first download link inside `waitForDownload`. It runs the click, waits for the
download to start, and returns it as a `Download` object.

We save the file with `saveAs` into a new temporary folder, using the name the server suggests.

Finally, we check that the file is not empty.
