## Code Walkthrough

### Running in Parallel

JUnit runs the tests one after the other. The `junit-platform.properties` file, in `src/test/resources`, turns on
parallel execution for every test of the project.

<TipCode codePath={"27-parallel/code/playwright-java/src/test/resources/junit-platform.properties"} language={"text"}/>

`parallel.enabled` turns it on, and `mode.default=concurrent` lets every test method run at the same time as the others,
not only the tests of different classes. The last two lines set how many run at the same time (4).

`@UsePlaywright` gives each thread its own browser, and each test a new page, so the tests don't share any state and
they can run in any order.

### The Tests

Each class holds two tests that sort the "Due" column of one of the tables, in ascending and descending order. The
`dues` method (lines 16 to 20) reads the values of the column as numbers. The first class uses the class names of the
second table, and the second class uses the position of the column in the first table.
