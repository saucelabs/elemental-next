## Code Walkthrough

### Setup and Teardown

Since we are working with threads, we need variables that are thread safe. The best candidates are thread local
variables: they have a global scope (similar to global variables) but are only accessible from within the thread that
created them. So instead of an instance variable (e.g., `@driver`), `setup` stores each browser in
`Thread.current[:driver]`, and `teardown` quits it.

### Running in Parallel

`run` spawns a thread for each of the browsers (`Thread.new`). Each thread runs `setup`, the test, and `teardown`
(in an `ensure` block, so the browser quits even when the test fails). Then `run` waits for all of them to finish
with `join`, which also raises any error from a thread, so a failed assertion fails the script.

### The Test

The test uses the thread local driver (`Thread.current[:driver]`) to load the page and assert that the title is
correct.
