## Code Walkthrough

### The Test

The test is the same as in the previous tip: the `driver` fixture is parametrized with the browsers, so pytest runs
`test_title` once for each of them, and each run gets its own browser in Sauce Labs.

### Running in Parallel

The [pytest-xdist](https://pypi.org/project/pytest-xdist/) plugin (in `requirements.txt`) runs tests in several
processes with the `-n` option. We add `-n 3` to the default options in `pytest.ini`, so the three runs of the test
happen at the same time.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
