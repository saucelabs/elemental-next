## Code Walkthrough

### One Run per Browser

Playwright has three browsers: Chromium, Firefox and WebKit (the engine of Safari). The `--browser` option of the
`pytest-playwright` plugin picks the browser, and when we give it more than once, each test runs once in each browser.
To not type the options every time, we add them to `pytest.ini`.

<TipCode codePath={"42-one-test-multiple-browsers-parallel/code/playwright-python/pytest.ini"} language={"ini"}/>

### In Parallel

The `pytest-xdist` plugin runs the tests in parallel workers. `-n 3` runs the three browsers at the same time, so the
run takes about as long as the slowest browser. Sauce Labs runs as many browsers at the same time as the concurrency
of the account allows.

### Running on Sauce Labs

The browsers run on Sauce Labs.

<TipCode codePath={"42-one-test-multiple-browsers-parallel/code/playwright-python/conftest.py"} language={"python"}/>

`conftest.py` replaces the `browser` fixture of the `pytest-playwright` plugin with a browser on Sauce Labs. The
plugin still creates the context and the `page` of each test, in that browser:

- Lines 5 to 10 hold the addresses of Sauce Labs, the credentials, and the version of Playwright. Sauce Labs needs the
  major and minor version (e.g., `1.61`), and it supports only some versions, so `requirements.txt` pins one of them.
- Lines 11 and 12 map each Playwright browser to its name on Sauce Labs.
- Lines 15 to 21 are a pytest hook that keeps the result of each test, so we can send it to Sauce Labs.
- Lines 27 to 39 create an HTTP client with the credentials (`playwright.request.new_context`) and ask Sauce Labs for
  the browser of the test on Linux, with the name of the test and of the build. Sauce Labs answers with redirects
  (`303`) while it starts the browser, so we follow them until we get its address (`wsEndpoint`).
- Lines 42 to 44 connect to the browser with `browser_type.connect`, give it to the test (`yield`), and close it when
  the test ends.
- Lines 47 to 50 tell Sauce Labs if the test passed, using its REST API, and print the link to the job.

### The Test

The test is the same test we would run on our machine: it visits the page and checks the title (lines 9 to 11). It
doesn't know which browser it runs in. pytest finds the `browser` fixture of `conftest.py` on its own, without an
import. Lines 5 and 6 skip the test when the Sauce Labs credentials are not set.
