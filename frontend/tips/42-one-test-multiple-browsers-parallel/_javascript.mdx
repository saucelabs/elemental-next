### Setup

The `before` hook skips the test if the credentials are not set.

### Running in Parallel

`runOn` does everything for one browser: it connects to Sauce Labs with the capabilities for that browser, loads the
page, asserts the title, and quits the browser (in a `finally` block, so it quits even when the assertion fails).
It's an `async` function, so calling it starts the work and returns a promise right away.

The test calls `runOn` for every browser and waits for all of them with `Promise.all`, so the browsers run at the
same time. If any of them fails, `Promise.all` rejects, and the test fails.
