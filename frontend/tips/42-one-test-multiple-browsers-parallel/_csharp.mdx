## Code Walkthrough

### The Test

The test is the same as in the previous tip: `Title` runs once for each `[DataRow]`, and each run creates its own
browser in Sauce Labs. MSTest creates a new instance of the test class for each run, so they don't share the
driver.

### Running in Parallel

The `[assembly: Parallelize(...)]` attribute in `AssemblyInfo.cs` turns on parallel execution for the whole
project, with 3 workers and at the method level. MSTest treats each data row as its own test, so the three runs
happen at the same time.

`csharp.csproj` in this case).
