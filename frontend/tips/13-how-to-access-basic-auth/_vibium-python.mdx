## Code Walkthrough

### Setting the Credentials

Line 4 holds the message the page shows when we log in.

The fixture (lines 7 to 11) starts the browser, gives the test its first page (tab), and closes the browser after the
test.

### The Test

Lines 14 to 17 are the test itself.

We put the user and the password in the URL (`https://admin:admin@...`). The browser sends them to the server, so it
never shows the login dialog. Then we check that the page shows the message.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.

the command-line. The first time, Vibium downloads Chrome for Testing.
