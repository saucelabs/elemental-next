## Code Walkthrough

### Setting the Credentials

Line 4 holds the message the page shows when we log in.

The `beforeEach` method (lines 10 to 13) starts the browser and gets its first page (tab). The `afterEach` method
(lines 15 to 17) closes the browser.

### The Test

Lines 19 to 23 are the test itself.

We put the user and the password in the URL (`https://admin:admin@...`). The browser sends them to the server, so it
never shows the login dialog. Then we check that the page shows the message.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the `package.json` file.
