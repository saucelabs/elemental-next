## Code Walkthrough

### Setting the Credentials

Line 4 holds the message the page shows when we log in.

The `beforeEach` method (lines 10 to 13) starts the browser and gets its first page (tab). The `afterEach` method
(lines 15 to 17) closes the browser.

### The Test

Lines 19 to 25 are the test itself.

Basic auth sends the credentials in the `Authorization` header of each request, as `Basic` followed by
`user:password` in Base64. We build that value with `Buffer`, and `page.setHeaders` adds the header to every request
of the page. The server sees the credentials, so the browser never shows the login dialog.

Then we visit the page and check that it shows the message.
