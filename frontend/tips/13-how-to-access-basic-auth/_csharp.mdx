## Code Walkthrough

### Setup and Teardown

The `SetUp()` method (marked with `[TestInitialize]`) creates an instance of WebDriver with Firefox, and the
`TearDown()` method (marked with `[TestCleanup]`) closes it.

### The Tests

The first test (`CredentialsInUrl`) loads the page with the credentials in the front of the URL
(`https://admin:admin@the-internet.herokuapp.com/basic_auth`), grabs the text of the page message
(`.example p`), and asserts that it is the one we expect.

The second test (`CredentialsCachedByTheBrowser`) loads the page with the credentials first, and then loads it again without them. The browser
reuses the credentials it cached, so the page loads and we can assert the message the same way.
