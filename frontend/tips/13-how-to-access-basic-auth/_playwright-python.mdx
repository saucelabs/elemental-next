## Code Walkthrough

### Setting the Credentials

Line 4 holds the message the page shows when we log in.

Playwright has an option for basic auth: `http_credentials`. The `pytest-playwright` plugin creates the browser
context with the options of its `browser_context_args` fixture. On lines 7 to 9 we override that fixture to add the
credentials, for every test in the file. Playwright then answers the login dialog of the browser for us, so we don't
put the credentials in the URL.

### The Test

Lines 12 to 15 visit the page that needs basic auth and check that it shows the message.

### Executing the Test

Before executing the test, we need to make sure the required libraries are declared on the `requirements.txt` file.
