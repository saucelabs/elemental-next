## Code Walkthrough

### Setting the Credentials

Line 3 holds the message the page shows when we log in.

Playwright has an option for basic auth: `httpCredentials`. On line 5, `test.use` sets it for every test in the file.
Playwright then answers the login dialog of the browser for us, so we don't put the credentials in the URL.

### The Test

Lines 7 to 11 visit the page that needs basic auth and check that it shows the message.
