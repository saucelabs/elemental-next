## Code Walkthrough

### Setup and Teardown

The `driver` fixture creates a Firefox instance, `yield`s it to the test, and quits it once the test is done.

### The Tests

The first test (`test_credentials_in_url`) loads the page with the credentials in the front of the URL
(`https://admin:admin@the-internet.herokuapp.com/basic_auth`), grabs the text of the page message
(`.example p`), and asserts that it is the one we expect.

The second test (`test_credentials_cached_by_the_browser`) loads the page with the credentials first, and then loads it again without them. The browser
reuses the credentials it cached, so the page loads and we can assert the message the same way.

### Executing the Test

Before executing the test, we need to install the required libraries. We can do this by running
`pip install -r requirements.txt` from the command-line. The `requirements.txt` file contains the libraries we
need to install.
