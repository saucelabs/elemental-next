## Code Walkthrough

### Setup and Teardown

The `beforeEach` hook launches Firefox before each test, and the `afterEach` hook quits it.

### The Tests

The first test (`passes the credentials in the URL`) loads the page with the credentials in the front of the URL
(`https://admin:admin@the-internet.herokuapp.com/basic_auth`), grabs the text of the page message
(`.example p`), and asserts that it is the one we expect.

The second test (`reuses the credentials cached by the browser`) loads the page with the credentials first, and then loads it again without them. The browser
reuses the credentials it cached, so the page loads and we can assert the message the same way.
