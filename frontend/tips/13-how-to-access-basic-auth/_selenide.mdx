## Code Walkthrough

### Importing Libraries

Lines 3 to 9 pull in the JUnit annotations and the Selenide methods we use (`open`, `$` and the `exactText`
condition).

### One Browser per Test

Browsers remember the credentials of a site, so line 11 adds `BrowserPerTestStrategyExtension`. It closes the browser
after each test, and each test starts without credentials.

### Example 1: Credentials in the URL

Lines 16 to 19 put the username and password in the URL (`https://admin:admin@...`). The browser sends them, and
the page shows the message we expect.

### Example 2: Credentials Cached by the Browser

Lines 22 to 26 visit the page once with the credentials in the URL, and then again without them. The browser
remembers them for the rest of the session, so the second visit works too.

### Example 3: Credentials Given to Selenide

Lines 29 to 32 pass the credentials to `open(url, domain, login, password)` instead. Selenide adds them to the
request for us, so the URL stays clean.
