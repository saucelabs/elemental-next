## Code Walkthrough

### Setting the Credentials

Line 11 holds the message the page shows when we log in.

Playwright has an option for basic auth: `HttpCredentials`. The test class extends `PageTest`, which creates the
browser context with the options that `ContextOptions` returns. On lines 13 to 19 we override that method to add the
credentials, for every test in the class. Playwright then answers the login dialog of the browser for us, so we don't
put the credentials in the URL.

### The Test

Lines 21 to 27 visit the page that needs basic auth and check that it shows the message.

### Executing the Test

Before executing the test, we need to make sure the required dependencies are declared on the project file (e.g.,
`playwright-csharp.csproj` in this case).
